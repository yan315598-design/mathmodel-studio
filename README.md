[![License](https://img.shields.io/badge/license-MIT-lightgrey)](#license)

数学建模竞赛的 AI 教练：从选题、建模、验算，到写论文、画图、模拟评审、打包提交，按阶段带你走完一篇可提交的论文。它不是帮你"生成一篇论文"，而是把 3-4 天的比赛拆成可检查的步骤，每一步有明确的产出、完成标准，以及必须停下来向用户确认的节点。

## 核心优势

- **知识库可核验**。华为杯 190 篇优秀论文逐题复核，33 篇逐篇深读；每条知识登记来源文件指纹，支持机器校验。
- **领域动作手册**。信号诊断、空间几何、调度优化、时空预测、物理机理混合、高维预测六个领域，每条动作标注普通做法的失效点和适用边界。
- **评委模拟终审**。提交前按评委视角模拟评审：资格硬规则任一不过即拦截，通过后按扣分清单逐项评分。
- **数字可回溯**。结果数字与产出文件绑定，源文件修改后摘要数字自动标记失效。
- **图表自动质检**。27 件自写模板统一配色，出图自动检查文字重叠、越界、图内标题。
- **问答式交互**。关键决策给编号选项，不敲命令、不改配置文件，进度自动保存。

## 使用教学：完整打一场

### 第一步：启动

对 AI 说"开始建模"。它会一次性询问五个启动信息：

> 竞赛（华为杯 / 华数杯 / 国赛 / 美赛 / 电工杯 / 亚太杯）· 题号 · 队员人数与分工 · 截止时间 · 题目 PDF 路径

题目未公布时回答"未公布"即可，后续补充。若工作目录中已有进度，会说"继续上次的进度"，自动从断点恢复。

### 第二步：按五幕推进

整个比赛分为五幕。每一幕由 AI 完成主体工作并给出产出与自评分，用户的核心操作是审阅产出、在关键节点做出选择（回复编号或字母即可）；任何高风险决策（选型拍板、阶段推进、终稿确认）都不会被跳过。

| 幕 | AI 完成的工作 | 用户的操作 |
|---|---|---|
| 一、备战与选题 | 将候选题整理成对比矩阵：每题考查要点、主要风险、与历年题目的相似度、适配队伍的胜算评估 | 审阅对比矩阵，选定题目 |
| 二、审题与选型 | 防读错题四查（边界 / 权利 / 目标 / 假设）；将题面要求整理成义务清单；为每问列出候选模型路线，附假设、验证方法与工作量 | 拍板每问主路线（可回复"听推荐"） |
| 三、建模求解 | 每问按"建模 → 求解 → 验证 → 解释"循环推进，验证通过后立即写入论文草稿卡；单问不合格只返修该问，不重做全局 | 审阅每问结果与验证证据，确认推进 |
| 四、论文成稿 | 将草稿卡组装成正文（不推翻重写）；摘要采用三遍制：先搭骨架、再按证据重写、最后润色 | 在编辑器中修改细节（见下文论文协作） |
| 五、终审提交 | 评委模拟评审并给出扣分清单；数字对账、图表断链、符号一致性检查；按提交清单打包提交件 | 按清单修改，确认打包 |

两道质量关卡自动执行：**每幕结束自评打分，不达标不推进**；**终稿前评委模拟评审，资格项任一不过即拦截**。遇到阻塞时不会强行编造，而是输出结构化决策单（已尝试的方案、当前最优结果、下一步选项），交由用户决定。

## 论文怎么写

正文以 Markdown 为唯一底稿，LaTeX 与 Word 都是它的下游产物：

```text
                  ┌─→ 自动转 LaTeX → 编译 PDF   （正式提交件）
  md（唯一底稿）──┤
    所有修改都在这  └─→ 导出 docx               （给 Word 队友圈批注）
                                   │
                   批注由 AI 读取后合回 ──→ md
```

三条纪律：

1. **改论文永远改 md**。不要手改生成的 PDF / docx——它们是产物，下次渲染会被覆盖。
2. **公式直接写 LaTeX 语法**。需要精细排版时在 md 里写原生公式与表格，渲染原样通过，无需学习新语法。
3. **终稿可锁版**。提交前最后几小时可锁定为纯 LaTeX 手调排版，此后不再从 md 组装（锁版前的 md 仍是完整底稿）。

写作队员的编辑器选型（均免费，三选一）：

| 编辑器 | 适合谁 | 说明 |
| --- | --- | --- |
| Obsidian（默认推荐） | 大多数人 | 个人使用免费、持续更新，实时预览，公式渲染好 |
| MarkText | 需要完全开源 | 开源免费、界面简洁；项目更新缓慢，装 0.17.1 够用 |
| VS Code | 队里已有代码环境 | 自带 Markdown 预览（Ctrl+Shift+V），无需另装软件 |

## 论文怎么导出

- **正式提交件（PDF）**：由 md 底稿自动转 LaTeX 并编译，六套自写竞赛模板（华为杯 / 国赛 / 华数杯 / 美赛 / 电工杯 / 亚太杯）均通过编译验证，无第三方模板许可风险。导出前自动做提交检查：页数、重复图题、匿名要求、空白页。
- **审阅件（docx）**：一键从 md 导出带时间戳的 Word 文档，供写作队友用批注圈改；批注内容由 AI 读取后合回 md 底稿，形成闭环。
- **提交打包**：终审通过后一键打包（zip + 校验和 + 备份），各赛提交物均为 PDF。

## 只用一部分也行

- **"帮我比较 A/B/C 题"** —— 只做选题对比，出矩阵后自行决定
- **"这道题和历年哪题最像"** —— 相似题检索，附当年的解法与翻车点
- **"给第三问画一张灵敏度图"** —— 说清数据和要支撑的结论即可出图，自动过质检
- **"写摘要"** —— 按对应竞赛获奖论文的摘要结构撰写，每个数字可追溯
- **"最后 6 小时，终审论文"** —— 极速模式：优先查摘要定量、图表解释、符号一致、结论对应题问
- **"继续上次的进度"** —— 读取进度文件，从断点接着做

## 三种强度

| 强度 | 大约耗时 | 适用 |
|------|---------|------|
| 快速 | ~30 分钟 | 选题试跑、赛前体检 |
| 标准（默认） | ~6 小时 | 主流程 |
| 冲刺 | ~12 小时 | 提交前最后阶段（评委模拟 + 红队 + 校准全开） |

不指定时按剩余时间自动推荐：剩余 60 小时以上用标准，最后 6 小时直接进入终审冲刺。
