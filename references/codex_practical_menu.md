# Codex 实战工作台菜单

本文件是 mathmodel-studio 在 Codex 中的实战入口单一参考。Codex 通常没有弹窗选择 UI, 所有入口都用 Markdown 编号菜单。

---

## 首屏菜单

用户说"开始建模"、"使用 mathmodel-studio"、"我要参加研究生赛/华数杯/国赛/美赛/电工杯/亚太杯"但没有给出明确阶段时, 直接输出:

```text
启动数学建模工作台。你可以回复数字进入对应任务。

【需要你选择: 当前要做什么】

  1) 完整建模流程 — 从 Stage 0 开始, 适合刚开赛或题目刚公布
  2) 比较 A/B/C 题 — 进入选题矩阵, 快速决定做哪题
  3) 写作/图表工作台 — 摘要、模型段、结果解释、图表规划与生成
  4) 终审论文 — 查摘要、图表、符号、结论和提交风险
  5) 继续已有进度 — 读取 state/decision_log.json 恢复 stage

回复数字 (1-5)。如果你已经有题目 PDF, 可以顺手把路径发给我。
```

```text
【需要你选择: Q1 竞赛】

  1) huaweibei 研究生赛（华为杯）— A-F，题号不固定映射题型

  5) 让我决定 — 根据你提到的竞赛名称判断，否则默认 cumcm
```

## 写作/图表工作台子菜单

用户选择写作工作台后, 用下面菜单:

```text
【需要你选择: 写作任务】

  1) 摘要 — 按竞赛模板写问题分解、方法、结果、稳健性、推广价值
  2) 问题分析 — 把题问转成模型任务, 写清难点和承接关系
  3) 模型段 — 写变量、目标函数、约束、算法步骤和求解说明
  4) 图表规划/生成/质检 — 规划论文图、生成数模图、检查图表风险
  5) 让我决定 — 根据当前论文缺口选择最该先写的一段

回复数字 (1-5), 并附上已有草稿或数据结果路径。
```

## 极速终审入口

当用户说"最后 6 小时"、"马上提交"、"极速终审"时, 不跑完整 5 视角长流程, 先执行 30-60 分钟高风险检查:

1. 摘要是否有分问题方法和不少于 3 个定量结果。
2. 每张核心图表是否有坐标、单位、图注和正文解释。
3. 符号表、公式、变量名、图表标签是否一致。
4. 结论是否逐条回应题目每一问。
5. 是否存在 anti_patterns 中的 high-severity 问题。

输出必须给 `提交风险: 低/中/高` 和 `必须立即修的 1-5 项`。
