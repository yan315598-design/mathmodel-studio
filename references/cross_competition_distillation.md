# 华数杯、国赛、研究生赛的联合蒸馏框架

## 结论

三个竞赛应放在同一套蒸馏体系中，但不能合并为同一个资料池。

- 共用：字段规范、问题解析、子问依赖、模型接口、验证闭环、论文章节功能、图表叙事、相似题检索协议和迁移边界。
- 独立：竞赛键、题面、附件、奖项身份、经验统计、评审规则、LaTeX 模板、案例索引和来源清单。
- 运行时：先加载跨赛通用层，再按 `huashubei`、`cumcm`、`huaweibei` 加载一条独立分支；`scripts/retrieve_cases.py --competition all --level both` 可联合检索，但不合并奖项或历史数值。

## 为什么不能直接混合

| 对象 | 是否共用 | 原因 |
|---|---:|---|
| 问题本质、输入输出、约束、逐问依赖 | 是 | 三类竞赛都需要把题面转成连续模型接口 |
| 模型路线比较、假设风险、必要验证 | 是 | 决定方案质量，与竞赛名称无关 |
| 摘要、背景、问题分析、正文、结尾的功能顺序 | 是 | 优秀论文的共同优势是证据闭环，不是固定措辞 |
| 结构—机制—结果—可信边界四类图表 | 是 | 适用于机理、优化、预测、评价和仿真题 |
| 题号对应题型 | 否 | 国赛和研究生赛的 A-F 题号不固定映射题型；华数杯历史 A/B/C 规律也只能作为本赛经验 |
| 数模之星、国一等奖项 | 否 | 奖项必须由本竞赛、本年份、本地目录或官方来源确认 |
| 页数、摘要长度、图表数阈值 | 否 | 样本范围、提交格式和评审习惯不同，只能在分支内使用 |
| 历史参数、结果数值、权重 | 否 | 即使问题相似，数据、单位、边界和目标口径也不同 |

## 共用数据契约

每个题目案例至少保存：

1. `problem_essence`：真正需要构造和验证的对象。
2. `question_dependency`：前问的哪个中间量成为后问输入。
3. `consensus_chain`：至少两篇论文支持的共同证据链；单篇路线必须显式标记。
4. `paper_route_comparison`：路线的适用条件、代价和失效风险。
5. `assumption_risks`：依据、简化、偏差和验证去向。
6. `required_solution_checks`：与主要失效风险一一对应。
7. `figure_story`：结构、机制、结果、可信边界四层。
8. `section_blueprint`：摘要、背景、问题分析、假设、正文和结尾的功能顺序。
9. `evidence_ids`：来源、页码、提取方式和奖项状态。
10. `transfer_boundary`：只迁移结构，历史数值、参数、结论和原句必须重做。

## 共用论文逻辑

```text
现实缺口
  -> 题面对象与口径
  -> 逐问输入/输出/约束
  -> 数据或机理证据
  -> 路线比较与选择
  -> 中间状态
  -> 结果
  -> 对应风险的验证
  -> 现实解释
  -> 适用边界
```

每个子问使用同一闭环：

```text
为什么需要本模型
  -> 输入输出
  -> 变量、目标和约束
  -> 推导或算法
  -> 必须打开的中间量
  -> 主结果
  -> 风险对应验证
  -> 回答题问
  -> 把哪个量交给下一问
```

## 四层检索与知识包

1. 竞赛内检索：优先返回同一分支中结构最相似的历史题。
2. 跨赛结构检索：只比较范式、子问依赖、风险和验证，不比较题号或奖项。
3. 方法卡检索：从通用模型库取算法候选，再由当前题的数据规模、解释需求和验证条件筛选。
4. 子问级检索：优先命中逐问依赖和提名论文全文子问；华数杯低证据 `S1-S4` 必须标明是蒸馏任务链。

检索输出必须保留 `competition`、`evidence_level`、`source_type` 和 `transfer_boundary`。进入 Stage 1/3/5/8/9 后用 `scripts/build_stage_pack.py` 只装载当前阶段字段，禁止把跨赛单篇路线写成当前竞赛共识。

## 结果证据链

论文中的每个子问都维护 `question → model → result → validation → figure → abstract_claim`。摘要只接收完整链；图表必须记录证据角色、唯一主张、上游数据和必要检查。统一评分契约位于 `config/rating_contract.json`，竞赛 overlay 只表达差异。

## 本次研究生赛证据边界

- 2021—2025 共 30 道题、190 篇优秀论文、12458 页。
- 2021 年本地目录明确标注 12 篇“数模之星提名奖”，A-F 每题 2 篇。
- 2022—2025 未发现同等本地目录证据，不能推测哪些论文属于数模之星。
- 页数和摘要长度可作描述统计；图表数量、章节识别和论证词频只作启发式定位。
