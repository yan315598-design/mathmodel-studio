# 建模规范知识库 (v1.0.0 自写重建)

数模论文的方法论底座：题型识别 → 选型主线 → 高频陷阱 → 必做验证。与 `references/model_catalog.md`（模型清单与失效边界）和 `references/reference_skill_bridge.md`（文献获取）分工：本文件管"怎么选对路子、怎么不踩坑"，不管模型清单与文献。

## 1. 题型识别：六大类与判别信号

| 题型 | 题面信号词 | 数据状态 | 核心交付 |
|---|---|---|---|
| 优化决策 | 最优/调度/分配/规划/最小成本/最大收益 | 参数给定或需估计 | 模型+求解+最优方案+灵敏度 |
| 预测预报 | 预测/预报/趋势/估计未来 | 历史时序或截面 | 模型+预测区间+精度检验 |
| 评价排序 | 评价/排序/打分/综合指数/优劣 | 多指标数据 | 指标体系+权重+排序+稳健性 |
| 机理分析 | 机理/原理/物理过程/运动规律 | 少数据多规律 | 微分/物理方程+解析性质+数值验证 |
| 统计推断 | 检验/相关性/显著/因果/影响因素 | 样本数据 | 假设检验+效应量+稳健性 |
| 图论网络 | 网络/路径/传播/匹配/覆盖 | 图结构数据 | 图模型+算法+结构性结论 |

判别纪律：
- 一题多问时**逐问独立判型**（常见组合：Q1 预测 + Q2 优化 + Q3 评价），不要给整题贴单一标签
- 判型证据写进 Stage 2 解析文档：引题面原句 + 数据状态，不允许凭感觉
- 拿不准时按"输出形式"判：要方案→优化，要数值→预测，要名次→评价，要规律→机理

## 2. 选型主线（每类的默认进攻路线）

### 优化决策
单目标先线性/整数规划（能精确求解就不启发式）；多目标先加权/ε-constraint 出 Pareto 再谈 NSGA-II；大规模组合优化（TSP/排程/装箱）再上遗传/模拟退火。**先证可行域非空、再求最优**——不可行解拿不了高求解分。
陷阱：约束漏写（变量非负、容量上限、逻辑互斥）；目标函数量纲混用（先归一化再加权）；启发式不报收敛曲线与多种子分布。
必做验证：约束违反检查 + 与一个朴素基线（贪心/均分）对比 + 关键参数 ±10-20% 灵敏度。

### 预测预报
数据 <50 点：灰色 GM(1,1)/指数平滑；中时序：ARIMA/SARIMA + 残差白噪声检验；大样本非线性：GBRT/随机森林/LSTM。
陷阱：训练集泄漏未来信息（时间序列必须按时间切分）；只报点预测不给区间；用 R² 自欺（时序看 MAPE/RMSE 与滞后特征）。
必做验证：留出集/滚动原点回测 + 残差诊断 + 预测区间覆盖率。

### 评价排序
先定指标体系（正向化/归一化），再定权重（主观 AHP / 客观熵权 / 组合），最后合成（TOPSIS/VIKOR/综合得分）。
陷阱：AHP 判断矩阵不过一致性检验（CR≥0.1 必须重建）；熵权法把"区分度"误当"重要性"；TOPSIS 不处理指标量纲就直接算贴近度；指标间强相关导致重复计权。
必做验证：权重敏感性（扰动 ±10% 看排名稳定性）+ CR 检验 + 与单一常识指标做相关性 sanity check。

### 机理分析
守恒律（质量/能量/动量/电荷）是建模的起点和自检终点；先写稳态/极限情形解析解，再上数值。
陷阱：方程维度不齐（每项量纲必须一致）；参数无来源（引用或标定，不许凭空）；数值格式不稳定（刚性系统换隐式/小步长）。
必做验证：量纲齐性 + 守恒残差 + 与已知极限情形/文献量级比对。

### 统计推断
先验分布与独立性假设写清楚；相关不等于因果；多重比较要校正。
陷阱：p 值狩猎（试到显著为止）；样本量小说大样本结论；把拟合优度当预测能力。
必做验证：检验前提（正态/方差齐/独立）+ 效应量与置信区间 + 稳健性（换方法/换子样本）。

### 图论网络
先定图语义（点/边/权各是什么），再选算法（最短路/最大流/匹配/社区发现）。
陷阱：把欧氏问题硬套图模型；忽略连通性/方向性；复杂度高估可解规模。
必做验证：小规模手算对照 + 度分布/连通性统计 + 与精确解或下界对比。

## 3. 数据处理规范

- 数据入境先登记：来源文件、行列数、字段含义、单位、时间粒度，进真源.md 数据冻结表
- 缺失值：先统计缺失率与模式（随机/结构性），再选策略（删除/插值/建模填补），写明理由
- 异常值：3σ 或 IQR 规则识别，**处理前后各保留一份**，删除须给业务理由
- 归一化：说明用 min-max 还是 z-score 及原因；不同问之间口径必须统一（口径不一致是本skill用户实战翻车点）
- 切分：时序按时间切，截面可随机切；测试集全程只在最终评估碰一次

## 4. 假设与边界纪律（配合 templates/shared/assumption_table.md）

- 假设分两级：关键假设（少了模型就垮）与简化假设（可放宽）；数量按结论需要，不设区间
- 每条假设三要素：内容 + 理由（文献/数据/常识三选一支撑）+ 放宽后的影响方向
- 建模边界自检（与 Stage 2 审题门四查对应）：①题目要求的最小交付是什么？②题面没有禁止但我用了的信息有哪些？③模型的失效边界在哪里（对照 model_catalog §12）？
- 答辩式自检：如果评委问"你这个假设凭什么"，能用一行证据回答才算合格

## 5. 量纲与单位纪律

- 所有参数带单位进符号表；公式两侧量纲必须齐（写一个查一个）
- 全文单位制统一（建议 SI）；时间单位（小时/天）、货币单位（元/万元）全文锁定一种
- 数值结果的有效数字与测量精度匹配，不要报 15 位伪精度

## 6. 常见全局反模式

| 反模式 | 后果 | 正确做法 |
|---|---|---|
| 题目边界没读清就建模 | 解错题，零分风险 | Stage 2 审题门三问 + 最小交付清单 |
| 模型名堆砌无接口 | 被扣分"拼装模型" | 每加一个模型说清它消费谁的输出 |
| 灵敏度只改代入值不重求解 | 评委一眼看穿 | 扰动后重新求解再比输出 |
| 结论数字与摘要/正文不一致 | 诚信质疑 | freeze_numbers 冻结 + consistency_audit 终检 |
| 无基线就称"更优" | 无证据主张 | 必有朴素基线对照 |
| 假设无支撑 | 模型站不住 | 每条假设配来源 |
