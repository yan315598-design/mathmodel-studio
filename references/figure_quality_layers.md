# 图表分层验收

正式图由 Agent 完成设计、渲染、机器检查、最终入文尺寸目检和必要精修。探索图允许快速生成；未知或未看图标为候选/草稿，不登记通过。通过后不强制重复轮次。

| 层级 | 验收内容 | 失败处理 |
|---|---|---|
| 科学硬约束 | 来源与冻结结果一致、单位/对象/划分正确、题面必交齐全、缺测保持缺测 | 不得交付为正式结论 |
| 通用交付 | 文件可开、图注引用闭合、最终版心字体可读/无遮挡、导出完整 | 修源后重渲检查 |
| 类型专属 | mask 原尺寸/编码；地图 CRS/时间/高度/单位；信号采样率/窗长/频率口径；网络依赖/空间尺度 | 按实际对象检查，不套统一 dpi |
| 设计建议 | 面板/节点数量、强调色数、卡片/母线/留白、对照布局 | 根据证据和版心调整，不作全局硬门 |

题面必交内容优先于图库预算、面板数量和风格建议。原始像素图/答案 mask 独立保留；展示副本不可覆盖原件或靠上采样声称获得细节。地图插值后的目标网格不是观测分辨率。无标签目标域只报告分布、预测或迁移诊断，不报告准确率。

展示栅格按最终物理宽度检查有效分辨率；SVG/PDF 检查实际对象（可能嵌有位图），扩展名不证明全矢量。图库预览仅供浏览，不决定正式原图质量。混合文件需检查嵌入图的实际显示尺度，自动检查不明则 unknown。

常规布局/色板/标签由 Agent 决定，已有锁定风格沿用。只有改变科学含义、显著增加计算成本、改变锁定风格或外部上传/发布时询问。D.1 仍按既有 schema 登记，真实的“你决定/连续实施”授权可作为 chat 来源；不得伪造回答。题面必交不能被 0 张选择省掉。

机制图保留可编辑源，Agent 可精修并经渲染目检产生新候选。旧 `*.draft.*` 不因重命名自动通过；缺科学依据或视觉能力时仍是草稿。figqa/figure_lint 的机器检查不代替科学或审美验收。

设计卡沿用既有登记，只在需要时补用途（可多选）、对象、去向、状态；旧记录缺字段为 unknown，不强制迁移。图型组合不受范例列表限制。
