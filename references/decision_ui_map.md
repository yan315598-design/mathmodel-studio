# 决策点 UI 映射表 (v1.0.0)

把 10 阶段全部关键决策点登记为统一的"选项卡"规范。Claude Code / ZCode 用 `AskUserQuestion` 工具（弹出选择界面）；Codex 用 markdown 编号菜单（见 SKILL.md 编号菜单协议）。两者选项内容必须一致——本表是唯一登记处。

**通用规则**：
- 每问 ≤4 个选项 + 1 个"让我决定（推荐 X，因…）"兜底（AskUserQuestion 的 options 对应 1-4，兜底固定放最后）
- 每个 option 带 label（≤5 字）+ description（一句话后果说明）
- 用户作答后 agent 立即写入 `cwd/state/decision_log.json` 并推进，不二次确认
- 自由文本题（路径/截止时间）不用弹窗，单行回复即可
