# 数据获取协议 (v2.0.0 新增)

> 触发场景：赛题需要题面附件之外的真实数据（统计年鉴、地理/气象/医学公开数据、行业数据等）。华为杯 C 题型与美赛 C 题最常见。本协议管"数据从哪来、怎么登记、怎么在论文里声明"；文献检索仍走 `reference_skill_bridge.md`（≤5 次硬上限），两者不混。

## 1. 数据源优先级

1. **题面附件** —— 永远优先，外部数据只做补充不做替代。
2. **权威公开源**：国家统计局/部委公开数据、WHO/World Bank/NASA/NOAA、官方行业年报。
3. **学术数据集**：UCI、Kaggle（注意许可）、论文附带仓库。
4. **网络抓取**：仅在上述不可得时，且必须满足 §3 安全约束。

**红线**：禁止编造数据填充模型。某数据源不可获取时，正确做法是 (a) 换可获取的替代源并在论文声明差异，或 (b) 明确声明使用合成数据及其生成机制，或 (c) 调整方法路线降低数据需求。三者都要写进论文的数据声明段。

## 2. 数据集登记（SSOT）

每引入一个外部数据集，立即登记到 `state/datasets.json`：

```json
{
  "datasets": [
    {
      "id": "ds_001",
      "name": "数据集名称",
      "source": "机构/网站名",
      "url": "https://...",
      "fetched_at": "2026-09-05T10:00:00",
      "local_path": "data/raw/xxx.csv",
      "sha256": "下载即算，防篡改与版本混淆",
      "license": "许可条款（如 CC-BY-4.0 / 政府公开数据）",
      "used_for": ["Q2 特征构造"],
      "preprocessing": "指向 data/processed/ 的处理脚本"
    }
  ]
}
```

- 原始文件存 `data/raw/`，**不手工修改**；清洗/变换输出到 `data/processed/`，全部经脚本完成（可复现）。
- 论文中每个使用外部数据的图表，其 `upstream_data` 必须能追到 `datasets.json` 的某个 id。

## 3. 网络安全约束（强制）

- 仅允许 `http`/`https` 协议；发起请求前校验 host，**拒绝 localhost、环回地址、私有网段（10/8、172.16/12、192.168/16）和保留地址**。
- 禁止 `curl ... | sh` 式盲执行远程脚本；需要工具时先下载、审查、再运行。
- 下载文件先入 `data/raw/` 并算 SHA-256，不直接进处理链路。

## 4. 论文中的数据声明

在问题重述或模型建立前的"数据来源"小节写清四件：

```text
数据来源：[机构/题面附件]，获取日期：[YYYY-MM-DD]，覆盖范围：[时空/样本范围]，
预处理：[脚本与规则]；缺失/异常处理见第 x.x 节。
```

- 用外部数据替换题面数据必须说明理由与差异影响。
- 合成数据必须给生成机制与参数，并在稳健性章节验证结论对合成机制的敏感度。

## 5. 与既有机制的衔接

- 数据快照的 SHA-256 接入 `scripts/freeze_numbers.py` 冻结链：论文数字 ↔ 数据文件哈希绑定。
- `scripts/run_manifest.py` 记录预处理脚本的运行哈希，数据漂移即级联失效。
- Stage 9 终审新增检查点：论文中每个外部数据集都有 `datasets.json` 登记项与来源声明，缺一即 block。
