> 拿到 A/B/C 三题后第一件事。目标：在 2 小时内做出科学选题决策，为冲国一奠定基础。
> 基于 6 届 18 题规律蒸馏。
> 加载时机：stage 1 选题，当用户说"华数杯选题"/"比较 A/B/C"/"帮我选题"时。

## 使用流程（2 小时内完成）

```
Step 1 (30min): 三题快速扫描 — 各读题 10 分钟, 填"五维评估表"

```

## Step 1: 三题五维评估表

读完每道题后，按下表打分（1-5 分）。**不要先入为主选 C 题**。

| 维度 | A 题 | B 题 | C 题 | 评分标准 |
|------|------|------|------|----------|
| **题型匹配度** | _ | _ | _ | 题目类型是否落在队伍擅长区间(物理机理/运筹优化/数据评价) |
| **数据熟悉度** | _ | _ | _ | 附件数据队伍是否处理过类似规模/类型 |
| **数学难度** | _ | _ | _ | 5=最难(NP难/多物理场), 1=最易(套路成熟) |
| **竞争度** | _ | _ | _ | 5=最卷(门槛低选题多), 1=冷门; C题通常4-5 |
| **工作量** | _ | _ | _ | 5=子问题多数据大, 1=子问题少; 影响时间分配 |

**填表示例**（以 2024 届为例）：

|------|----------|--------|--------------|

| 数据熟悉度 | 3 | 4 | 5 |
| 数学难度 | 5 | 5 | 3 |
| 竞争度 | 3 | 3 | 5 |
| 工作量 | 4 | 4 | 5 |

## Step 3: 选题决策矩阵（量化公式）

### 综合得分公式

```
Score(题) = 0.40 × 题型匹配度
          + 0.15 × 数据熟悉度
          + 0.20 × (6 - 数学难度)      [难度越低分越高, 但做出来才有分]
          + 0.25 × (6 - 竞争度)         [竞争越小分越高]
```

**注**：工作量不直接计入得分，但影响时间分配（工作量大需更早启动）。

### 决策规则

- **Score 最高题 + 队伍最强方向一致** → 直接选，无需犹豫。
- **Score 最高题与队伍强项冲突**（如算法队但 C 题得分高）→ 谨慎，竞争度权重可能失真，回归匹配度优先。
- **两题 Score 接近（差 < 0.5）** → 选队伍更有激情的那题（72h 需要持续动力）。

### 计算示例（2024 届，算法队）

```
Score(A) = 0.40×2 + 0.15×3 + 0.20×(6-5) + 0.25×(6-3) = 0.8+0.45+0.2+0.75 = 2.20
Score(B) = 0.40×5 + 0.15×4 + 0.20×(6-5) + 0.25×(6-3) = 2.0+0.6+0.2+0.75 = 3.55  ← 最高
Score(C) = 0.40×4 + 0.15×5 + 0.20×(6-3) + 0.25×(6-5) = 1.6+0.75+0.6+0.25 = 3.20

决策: 选 B 题 (VLSI)。Score 最高且与算法队强项一致。
```

## Step 4: 风险评估与一票否决

### 一票否决（出现即排除该题）

1. **队伍无人能理解题目领域知识**：如 2025B 5G 网络切片，若无通信背景 → 排除。
2. **数据量超出处理能力**：如 2024C 352 城×100 景点，若无人擅长大数据可视化 → 排除。
3. **物理/工程机理队伍完全不懂**：如 2025A 多物理场五环节，若无物理背景 → 排除。

### 逆向选择（看似难实则机会）

- **最难题往往竞争最小**：2024B VLSI、2025A 多孔膜、2025B 网络切片难度 5，但能"做出来"的队伍少，做完即有大奖希望。
- **冷门题是金矿**：A 题竞争度均值 3.0（低于 C 题 4.17），物理背景队伍选 A 性价比极高。
- **避免红海**：2024C 老外游中国选题极多，同质化严重，模型好也可能被淹没——除非队伍可视化/洞察能力极强。

### 历年获奖难度参考（来自赛题蒸馏）

| 题型 | 最易获国一 | 最难获国一 | 性价比最优 |
|------|-----------|-----------|-----------|
| A | - | 2025A 多物理场 | 2020-2023A (难度4竞争3) |
| B | - | 2024B VLSI / 2025B 5G | 2021B-2022B 经典运筹 |
| C | 2020C / 2022C | 2024C (最卷) | - (C题性价比最低) |

## 三题型选题 Checklist

### 选 A 题的队伍应满足
- [ ] 至少 1 人有物理/工科背景（力学/电子/热能/机械）。
- [ ] 能熟练推导偏微分方程/电磁方程/运动学方程。
- [ ] 会数值求解（有限差分/龙格-库塔/有限元）。
- [ ] 会多目标优化（NSGA-II/加权法）。

### 选 B 题的队伍应满足
- [ ] 至少 1 人精通 Python/MATLAB 编程。
- [ ] 熟悉整数规划（会用 Gurobi/CPLEX 或 scipy.optimize）。
- [ ] 会元启发式算法（遗传/模拟退火/粒子群，能自己写代码）。
- [ ] 能处理大规模数据（几百上千变量）。
- [ ] 能理解题目领域知识（VLSI/通信/物流等）。

### 选 C 题的队伍应满足
- [ ] 至少 1 人擅长统计/数据分析。
- [ ] 熟悉评价方法（熵权/TOPSIS/PCA）和分类模型（XGBoost/随机森林）。
- [ ] 会数据可视化（matplotlib/seaborn/folium 地图）。
- [ ] **必须能做差异化**（外部数据/统计检验/高级可视化），否则别选 C。
- [ ] 写作能力强（C 题同质化，写作和洞察是突围关键）。
