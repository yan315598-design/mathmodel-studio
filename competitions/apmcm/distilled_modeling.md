# APMCM 题型对应建模思路与算法

## A 题：几何建模 / 连续优化 / 工程估计

近两年样本包括飞行器外形优化、农业灌溉系统优化。推荐路线：

- 先提取几何、物理或工程变量，建立可解释的基础模型。
- 面积、体积、阻力、灌溉量等连续量先做量纲检查。
- 优化目标写清单目标或多目标，约束来自题目尺寸、资源或工程边界。
- 可用方法：数值积分、曲面拟合、多目标优化、遗传算法、粒子群、灵敏度分析。

## B 题：数据分析 / 预测 / 机器学习

近两年样本包括洪水灾害数据分析与预测、疾病预测与大数据分析。推荐路线：

- 先写数据字段、缺失值、异常值和类别分布。
- 预测题至少给训练/验证划分和误差指标。
- 分类题至少报告准确率、召回率、F1、AUC 或混淆矩阵。
- 可用方法：时间序列模型、随机森林、XGBoost/LightGBM、逻辑回归、SVM、神经网络、SHAP 或特征重要性。

## C 题：算法优化 / 物流运输 / 高级模型

近两年样本包括允许拼货与中转运输、Quantum Boosting 二分类。推荐路线：

- 先定义决策变量、约束和评价指标。
- 物流类题要明确节点、路径、时间窗、容量、拼货和中转规则。
- 高级模型题要先解释传统模型基线，再说明 Quantum/Boosting 的增益位置。
- 可用方法：混合整数规划、图搜索、遗传算法、模拟退火、禁忌搜索、集成学习、Boosting、量子启发式特征映射。

## 选题建议

- 建模强、几何/优化熟练：优先 A。
- 数据处理和机器学习强：优先 B。
- 算法实现强、能快速写启发式或高级模型：优先 C。
