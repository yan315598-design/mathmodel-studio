# 研究生赛优秀论文的高质量模式

## 1. 不是先选算法，而是先打开中间层

30 道题横跨信号、芯片、医学、气象、生态、运筹和空间美学。共同优势不是某个算法，而是把黑箱任务拆成可检查的中间状态：相关结构、载荷、残差、风险概率、网络状态、轨迹、视域或资源占用。

可复用顺序：

```text
原始对象 -> 可观察证据 -> 中间状态 -> 决策/预测 -> 验证 -> 现实解释
```

## 2. 前问产生后问真正需要的量

高质量论文不会让每问独立开工。例如：

- 相关矩阵题中，相关阈值和正交基继续服务压缩与端到端流程。
- 空气质量题中，天气型和独立站残差成为协同模型的基线。
- DBS 题中，单神经元和健康/病态差异指标成为刺激优化目标。
- UWB 题中，几何残差同时服务定位、干扰分类和动态轨迹。
- 机组排班题中，航段依次组装为执勤和任务环。

正文必须在每问结尾写出“交给下一问的变量”。

## 3. 路线比较写适用条件，不写算法名清单

每条路线至少回答：

1. 它利用了数据的什么结构？
2. 在什么样本量、噪声、维度和实时要求下合适？
3. 相比替代路线牺牲什么？
4. 最大失效风险是什么？
5. 用哪项验证识别该失效？

## 4. 摘要先给共同发现，再按问报告

提名论文的有效摘要动作通常是：

```text
现实痛点
-> 数据/机理发现
-> Q1 任务、模型、中间量、结果和验证
-> Q2...
-> 全文贡献和边界
```

模型名只有在说明动作时出现。不要用“采用 A、B、C、D 算法”替代问题链。

## 5. 假设必须服务模型并返回验证

假设按四项写：现实依据、简化对象、可能偏差、验证位置。题面规定、变量定义、软件设置不混入假设；“数据准确”“模型正确”不是可接受的无条件假设。

## 6. 图表形成四层证据

1. 结构：对象、坐标、流程、网络和变量接口。
2. 机制：相关、轨迹、波形、状态、资源占用或因素关系。
3. 结果：预测、优化、分类、方案和基线对比。
4. 可信边界：残差、收敛、敏感性、校准、失败案例和不确定性。

每张图表只承担一个主要判断，正文说明上游数据、可见证据和不能推出的结论。

## 7. 结果表同时保留主目标和代价

优化题不能只报目标函数；预测题不能只报平均准确率；机理题不能只给漂亮仿真。结果至少同时保留主指标、资源/成本、约束余量、基线、最差或分层表现。

## 8. 结尾区分三件事

- 全文结论：逐问回答，带条件和现实解释。
- 模型评价：正文已经验证的优缺点。
- 推广：需要哪些新数据、参数重估和外部验证。

三者不能合成一段，也不能把竞赛数据内验证写成工程部署、政策因果或临床结论。

## 9. 数模之星可学的是闭环密度，不是篇幅

全部论文页数中位数为 61 页，12 篇提名论文中位数为 51 页。提名论文并不依赖更长篇幅；应学习它们把数据发现、模型接口、图表、验证和结果解释压在同一条证据链上的方式。
