# 研究生赛写作题型分册（v2.2.0 新增）

> 通用规则在 `writing_voice.md`；本文件按**题型**给差异化重点：公式呈现重点 / 推导写什么 / 结果分析重点 / 证据归纳的动作与反例。证据 = 2021 提名 12 篇 + 2025 优秀 21 篇深读（`star_papers_deep.md`），只迁移结构不迁移数值。
> 用法：Stage 8 动笔某问前，先按题面给该问定题型（一题多问可跨题型，如 D 题监测+航路优化），只加载对应分册。选题映射参考 `distilled_modeling.md` 的题型章节。

## 分册 1：优化调度类（资源分配 / 排序 / 排班 / 选址）

证据：2025 A 四篇（NPU 核内调度）、2021 F（机组排班）等。

- **公式重点**：决策变量按对象层级组织（序列变量 / 分配变量 / 联合变量分开定义）；目标函数写"主指标 + 罚项"时罚系数必须给依据；**每条计费/成本逐项对齐题面口径**（哪个动作计多少、挂哪个单元、单位是什么）——2025 A 四篇的及格线，漏一类成本模型即错。
- **推导写什么**：NP-难/规模论证一句（为什么不能直接精确求解）→ 精确模型（ILP/MIP）作为"基准存在"→ 降级/启发式设计的每个算子对应哪条约束（修复算子逐条对约束编号，2025 A 某篇五层修复算子 R1-R5 与约束一一对应是范式）。
- **结果分析重点**：多算例 × 多指标主表（六算例 × 三指标是 2025 A 共识格式）；约束余量/违反数单独列；**可行性靠修复器统计证明**（修复次数分布），不靠罚函数值；不同算法横评必须同算例同种子；恶化 case 逐算例归因（分册 §结果反例）。
- **动作**：横评多算法后**主动择简并给理由**（2025 A 某篇横评后提交贪心方案并说明理由——简单方案的运行时间与可复现性本身是结果）；小规模精确解校准启发式（Gurobi 解小算例对照，2021 F 范式）。
- **反例**：只报目标值不报约束余量；启发式结果与精确解零对照；"改进率高"但基线自定义且不声明。

## 分册 2：预测回归类（速率/负荷/浓度/流量预测）

证据：2025 B 三篇（MIMO-OFDM 链路速率）、时空预测集群 5 题（2021B/2022E/2023F/2024E/2025D）。

- **公式重点**：链式模型（物理量 → 聚合 → 映射）逐环节写清单调性/物理一致性约束（isotonic、单调样条、单调约束学习器——2025 B 三篇共同动作）；损失函数里物理约束项要给"违反惩罚"的量级依据。
- **推导写什么**：特征为什么这样构造（指向数据发现，如主奇异值通道替换保持聚合-映射框架不动）；**防泄漏设计写进正文**（GroupKFold / OOF / 按设备划分——2025 B 某篇把泄漏防御写成独立小节是亮点，不是啰嗦）。
- **结果分析重点**：指标口径声明（回归 vs 分类 vs 双口径不可直接互比）；误差按场景/分组分解（不是只给总 RMSE）；域偏移态度显式（对齐了/假设回避了/列为改进方向，三选一写明）；预测区间或分位数表现随主指标同报。
- **动作**：数据体检章前置（缺失/异常/分布漂移全景表，2025 B 某篇范式）；基线从物理模型起步（EESM 拟合基线）再谈改进；融合失效的机制化处理（权重退化为零时模型如何退化，2025 B 某篇 α*=0 的处理）。
- **反例**：跨设备合并训练不声明域偏移；只报平均误差不报分组；把相关性提升写成因果。

## 分册 3：识别与重构类（图像/信号识别 + 几何/三维重构）

证据：2025 C 五篇（围岩裂隙识别与三维重构）。

- **公式重点**：识别指标定义（IoU/F1）与几何参数拟合式分开；**可推导参数固定化**（如周期与孔径周长强绑定直接固定，减少自由参数——2025 C 三篇共识、本题最可迁移建模动作）；拟合式必须报告拟合误差。
- **推导写什么**：从像素观测到几何参数的转换链（每步给误差来源）；不确定性如何跨问传递（JRC → 法向量方差 → 三维概率，2025 C 某篇蒙特卡洛传递是范式）。
- **结果分析重点**：技术栈横评带验证闭环（形态学 / 深度 / 折中三路线各自的验证设计——**同题同数据下三栈皆可自洽，评判核心是验证闭环而非技术栈**，2025 C 五篇横评结论）；**量程核查**（算出的指标是否落在物理合理区间，如 JRC 超 Barton 量程即应报警——四篇栽在这里，一篇用法向距离去趋势落回量程成为亮点）；无外部真值时用替代真值（巴顿标准轮廓线，2025 C 某篇唯一做到）。
- **动作**：每问流程图开路 + 结果表收尾（2025 C 五篇统一版式）；失效模式黄框标注（哪段图像识别失败直接标出）；负结果完整叙事（数据泄漏发现→修正→对比）。
- **反例**：识别精度高但下游几何参数无误差传播；加权和型综合评价"单因子趋零仍过阈值"病不检查；深度模型无消融仍宣称模块有效。

## 分册 4：监测诊断与迁移类（故障诊断 / 状态监测 / 域适应）

证据：2025 E 三篇（轴承故障诊断迁移学习）。

- **公式重点**：领域机理公式前置（故障特征频率 BPFO/BPFI/BSF 等写进符号表并贯穿筛选与复核）；域适应损失（MMD/对抗/矩匹配）给"为什么适配这类偏移"一句机制解释，不只堆公式。
- **推导写什么**：无标签设定下"什么叫诊断对了"的可计算定义（内聚性/匹配度/机理复核的数学表达——2025 E 三篇都自造了替代验证指标，这是本题型的核心推导）；预处理链（重采样/滑窗/类别平衡）每步的依据。
- **结果分析重点**：**无真值三重防线**显式分层（消融 + 内聚性/匹配度指标 + 机理复核——2025 E 某篇范式）；t-SNE 迁移前后对比是标配但必须配定量指标；逐样本结论表带"共识/分歧"标注（多方法对同一样本判级一致才算稳定，2025 E 某篇 16 样本表把方法间分歧如实标出）。
- **动作**：数据筛选决策全配统计量（采样率依据奈奎斯特、域差异依据 MMD、去噪依据残差 SNR——2025 E 某篇每个"选哪个"都有数）；Q4 类部署问题按事前/过程/事后三层全覆盖写。
- **反例**：目标域精度提升但源域下降不报；替代验证指标只定义不报告；迁移后样本判级与方法间分歧不展示。

## 分册 5：评价与主观指标类（美学/舒适度/公平性量化）

证据：2025 F 四篇（园林美学）、2023C（评审公平）、2025 相关评价题。

- **公式重点**：主观概念的每一维给可计算代理（视域集合、开合指数、适量度）；"过与不及都扣分"的量用核函数/区间表达（适量度高斯核范式）；权重组合（AHP/熵权/CRITIC）必须附**依据列**（每个权重为什么是这个值——2025 F 某篇权重表附依据列被深读点名为亮点）。
- **推导写什么**：代理指标与主观感受的对应关系论证（理论应然关系 + 学界共识互证是这类题的主验证方式，因为外部真值稀缺）；标定过程显式（100 分锚点如何定：官方路线校准 / 分位数裁顶 / 外部标准对照，三选一并写清）。
- **结果分析重点**：相似度/得分分布要有**区分度检查**（高维余弦饱和到 0.986、45 对全 >0.85 = 无区分度失败案例；20 维三重融合 0.52-0.85 是成功对照——2025 F 内部对照）；与官方/专家基准对照（有就必用，2025 F 某篇与官方推荐路线对比是最强验证）；灵敏度双扰动（指标 Kendall τ 同时扰动参数与方案）。
- **动作**：多模态/多指标融合前先报各模态单独表现；聚类分型给每型的可解释画像；泛化验证选题外对象（用非本题园林验证方法论）。
- **反例**：权重拍脑袋无依据列；所有方案得分挤在窄区间仍下排序结论；把评分模型输出写成"客观美学价值"。
