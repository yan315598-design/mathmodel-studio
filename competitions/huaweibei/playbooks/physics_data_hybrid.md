# 物理机理+数据驱动混合域 Playbook

证据锚点约定：**论文方法链提取** = `analysis/lit_survey/huaweibei_2024_methods.md`（2024 年优秀论文选 12 篇摘要级提取：每篇读取封面、摘要与问题分析前 5 页，方法名取论文自述）。本域证据主体为其中 A 题风电 2 篇、C 题磁芯 2 篇、F 题脉冲星 2 篇，跨题共性观察覆盖全部 12 篇；**我方实验** = 无（本域未做本地试点，本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域为八类外新增横切域（八类中无机理—数据混合类目，循 README 域命名纪律的例外通道），近邻风险类为动力系统（状态演化和干预机制）与高维预测；"何时机理为主、何时数据为主"对齐该文件"机理还是数据驱动"三分支。本文件条目均未附机制记录 id——证据层级为摘要级方法链提取，尚未做机制复核与 `../cases/mechanism_reviews.json` 入库。

## 触发条件

- 题面存在可写出的物理机理构件作骨架（经验公式、疲劳准则、损耗方程、时延方程、守恒定律），同时提供观测或仿真数据；任务落在"公式覆盖不全、纯数据不敢外推"的双重缺口上——载荷—疲劳损伤、损耗—温度工况、时延—计时建模等。
- 数据形态：带物理单位的工况参数表或时间序列；标准物理方法（如斯坦麦茨方程、雨流计数）在题面变量（温度、波形类型、实时性）上有明确缺口，且缺口可被残差诊断暴露。
- 典型问链：先建物理量（损伤/损耗/时延），再以之为目标或约束进优化或决策——机理建模是入场券，混合方式是差异化点；或物理推导为主、随机仿真验证收尾（计时/轨道类），动作集中在物理侧的结构化与自证。
- 数据退化场景（噪声、时延、缺失）常被单独立问或明示于题面，混合架构须预留处置位。
- 与以特征工程为主的纯数据题（无机理可倚）的分界：本题存在不可绕过的物理机理骨架，数据与仿真的角色是校准、修正与验证，不是替代物理。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取与跨题共性观察（获奖动作所超越的常规套路反面，及提取过程发现的口径问题）：

1. **离线标准算法直接套用于在线场景**：雨流计数按定义要到时间末端才能确定最大载荷循环，直接套用则任意中间时刻的累积损伤不可得，实时决策失去输入。（论文方法链提取 A1，以此为改造动机）
2. **单一路线提交、无对比论证**：本批 12 篇中 10 篇显式做多模型/多方案对比并以此作为选择依据；不对比的"选用某法"在评审处没有论证地位。（跨题共性观察）
3. **纯数据黑盒交付**：机理/物理+数据混合出现于 12 篇中 8 篇，是本批 Top1 手法；把模型输出翻译回物理语言（物理先验、守恒律自检、工况含义）是共同加分动作——纯黑盒提交缺这条线。（跨题共性观察）
4. **学习型优化器裸跑不处理约束**：RL 输出天然不尊重物理约束（功率上下界、平衡关系），裸跑产出违反约束的解；本批涉优化的 5 篇全部专门处理了约束满足。（论文方法链提取 A1 + 跨题共性观察）
5. **对物理分项的取舍不做量级论证**：时延各分项（几何传播、引力、动钟、自行）不逐项做数量级分析就默认忽略或全部保留——前者留系统误差，后者掩盖主导项。（论文方法链提取 F1/F2）
6. **盲拟合修正项**：不从残差诊断出发，直接对标准公式堆修正参数——拟合上了也说不清修正的物理动机与适用范围。（论文方法链提取 C1，以"物理驱动而非盲拟合"为对照）
7. **数据退化场景被一笔带过**：A 题两篇均对数据阻塞/时延/缺失单独立模（鲁棒优化、降噪+插值恢复），说明该场景已成考察惯例；只在假设里声明"数据完好"是漏洞。（跨题共性观察）
8. **跨来源数值直接比大小**：同题两篇折叠轮廓相关系数报告值差距悬殊，源于评价口径（仿真时长、归一方式）不同——不核口径直接引用或对比文献数值会得出错误结论。（提取备注）

### 补充：跨域借鉴（2022-E 草原放牧策略，动力系统分支）

- 机理微分方程与数据驱动双轨并行、角色分工：机理方程定模型结构，统计/时序模型当主预测，深度模型只当交叉验证器而非主力——基线失效：纯机理拟合不了观测中的剩余动态，纯数据模型无结构依据不敢外推，把深度大模型堆上当主力则两头不占。证据：2022-E 优秀论文方法链提取（`analysis/lit_survey/huaweibei_2022_methods.md`，2 篇）。
- 用生态"可逆最大界限"阈值把生态约束转成优化边界——基线失效：求最大放牧强度时若无生态阈值作边界，最优解会推进到退化不可逆区，"最大"与"可持续"直接冲突。证据：同上（2 篇）。

### 补充：跨域借鉴（2023-A WLAN 信道接入机制，物理机理分支）

- 先诊断经典模型的简化失效、再做增补状态的推广：指认标准 Bianchi 模型的理想化状态简化（不计最大重传次数、成功/失败传输态）在题设下失效，针对性增补状态后重新推导稳态与吞吐公式——基线失效：直接套标准 Bianchi 在隐藏终端、重传上限等题设下产出系统性偏差，且偏差源头不可指认。证据：2023-A 优秀论文方法链提取（`analysis/lit_survey/huaweibei_2023_methods.md`，2 篇）。
- 自研离散事件仿真器与理论推导双轨互证、逐问报告理论与仿真的定量误差——基线失效：只交解析稳态公式则简化假设的累计偏差不可见，只交仿真则无理论锚点、参数作用解释不了。证据：同上（2 篇均做）。

### 补充：跨域借鉴（2023-B DFT 矩阵整数分解，数值线性代数分支）

- 解析逼近与优化逼近双路线统一框架：解析侧用数论工具（Weyl 均匀分布、丢番图逼近）给任意精度可逼近性证明，优化侧用整数规划/进化算法求具体整数矩阵——基线失效：纯数值搜索只交付可行解，"多高精度可达"无存在性论证；纯解析又落不到具体整数解。证据：2023-B 优秀论文方法链提取（`analysis/lit_survey/huaweibei_2023_methods.md`，2 篇）。
- 先证明目标矩阵的 Kronecker 积可分解结构、把拟合对象降到低维因子矩阵再求解——基线失效：直接对大维矩阵做整数逼近，自由参数随维数平方增长、搜索空间爆炸，优化器不可用。证据：同上（2 篇均用）。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面均锚定提取记录中论文自述的动机或对比实验；提取为摘要级，机制细节以提取字段为准，我方未复算。

### A1 标准方法实时化改造（离线算法→在线滚动）

- 基线失效：雨流计数按定义需到时间末端才能确定最大载荷循环，直接套用离线算法则任意中间时刻的累积损伤都不可得，而功率分配决策必须实时依赖当前损伤——基线在在线决策场景整体不可用。（论文方法链提取 A1：以该实时性缺陷诊断为改造动机；A2 以滑动时间窗达成同目标）
- 机制：先写明标准方法的实时性缺陷，再做保留机理内核的最小改造——滑动时间窗内完成"计数—修正—累积损伤"，当前窗结束即产出可用损伤量；辅以时间修正系数刻画载荷循环顺序效应。
- 前提/接口：题面存在滚动决策需求（每个时刻须给出动作）；在线滚动结果与离线全量结果在同一数据上对齐，差值作为在线化代价显式报告。
- 反例：一次性规划（非实时决策）场景下改造无意义，徒增复杂度；窗长过短使大循环跨窗截断、损伤系统性低估，窗长敏感性必须报告；载荷循环顺序效应显著的谱下若改造丢掉顺序信息，会退回线性累积的失真。
- 迁移边界：迁移"诊断标准方法在题面场景的失效点→最小改造保机理内核→与离线口径对齐验证"的顺序；具体算法、窗长与修正系数按新题重定。
- 证据：论文方法链提取（2024A 两篇）｜source_checked

### A2 物理公式与数据拟合双轨同台对比择优

- 基线失效：载荷—功率映射只用一种手段（机理推导/少参数拟合，或高容量数据模型）提交时，"哪个更可信"无从论证——同题获奖论文把两类拟合器同台对比并给出选择依据；本批 12 篇中 10 篇以显式对比支撑方法选择。（论文方法链提取 A2 + 跨题共性观察）
- 机制：物理轨（机理推导加少量参数的最小二乘/直接搜索拟合）与数据轨（如双向 LSTM 等高容量模型）在同一数据划分、同一误差指标下并行，按精度、外推行为与可解释性综合择优，选择依据写成决策记录。
- 前提/接口：两轨共用同一训练/测试划分与指标口径；物理轨参数有物理含义可复查；对比表（两轨、口径、结果、择优结论）进正文。
- 反例：样本量少或评估集落在工况外时，高容量模型拟合好看但外推失真，仅按域内精度择优会选错；两轨精度接近时只比小数点，会漏掉物理轨的可解释与外推优势。
- 迁移边界：迁移"双轨并行+同口径对比+择优理由显式"的论证链；两轨具体模型按新题数据量与非线性结构选择。
- 证据：论文方法链提取（2024A2）｜source_checked

### A3 物理模型输出作为数据模型的先验特征（堆叠）

- 基线失效：纯数据驱动拟合损耗曲线精度可以很高，但可解释性差、工况外推无依据；纯物理公式（如修正的斯坦麦茨族）形式受限，抓不住数据中的剩余非线性——两单轨各有系统性短板。（论文方法链提取 C2：以兼顾可解释性与非线性拟合为动机）
- 机制：先跑物理模型（如 IGSE 类改进方程）得到物理一致的估计量，将其作为特征喂给梯度提升/树模型——数据模型学的是"物理估计的残差修正"，物理先验与量纲知识嵌进特征空间。
- 前提/接口：物理模型在新样本上可计算（参数已知或可插值）；先验特征与原始特征同表入模型；配"去掉先验特征"的消融证明增量。
- 反例：物理模型在部分工况外推失效时，错误先验会把数据模型带偏——先验特征须声明适用域；不做消融时"物理+ML"可能只是特征堆量，增量不可证。
- 迁移边界：迁移"物理估计进特征空间+消融证增量"的结构；具体物理方程与数据模型按新题选择。
- 证据：论文方法链提取（2024C2）｜source_checked

### A4 分材料/分工况分而治之建子模型

- 基线失效：不同材料、不同励磁波形下损耗规律的参数与形态差异大，大一统模型同时拟合全部子群体，精度被平均掉。（论文方法链提取 C1：分波形×分材料建 12 个子模型而非大一统，用分而治之保精度）
- 机制：按物理类别变量（材料×波形）切分数据，逐子类建独立子模型；子模型内规律同质、可选到最简形式；预测时按类别路由。
- 前提/接口：类别可判（题给字段，或先建波形分类器再分支建模）；逐子模型报告样本量与精度，汇总表同口径。
- 反例：子类样本过少时子模型过拟合，精度反不如带类别特征的大一统模型——须给"分 vs 统"对照；类别判错时误差=分类误差+子模型误差叠加，路由环节不可省验证。
- 迁移边界：迁移"按物理同质性分组、组内建模、按类路由"的结构；分组维度按新题的物理类别变量重定。
- 证据：论文方法链提取（2024C1）｜source_checked

### A5 从误差诊断出发设计修正函数族再择优

- 基线失效：对标准公式直接堆修正参数做盲拟合，拟合上了也说不清修正的物理动机、函数形式无据，换数据集即失效。（论文方法链提取 C1：从"标准方程缺温度因子"的误差诊断出发设计修正函数族，物理驱动而非盲拟合；C2 同思路多假设方程择优）
- 机制：先用残差诊断暴露标准公式的系统性缺口（如残差随温度单调漂移→缺温度因子），据此设计少量有物理动机的候选修正函数族（饱和型/多项式型/对数线性型等），同口径拟合后按精度与形式简洁度择优。
- 前提/接口：数据覆盖缺口变量的变化范围；残差诊断图先行（残差对候选因子的系统趋势图是第一张图）；候选族数量克制，逐族给动机句。
- 反例：数据未覆盖缺口变量全范围时，不同函数族范围外外推行为迥异，择优结论只在覆盖范围内成立；全族都不合适说明诊断方向错了，应回到残差重诊而不是继续加参数。
- 迁移边界：迁移"残差诊断→候选函数族→同口径择优"的顺序；诊断出的缺口变量与函数族形式按新题重定。
- 证据：论文方法链提取（2024C 两篇）｜source_checked

### A6 学习/优化器输出的物理约束分层校正

- 基线失效：强化学习等学习型优化器的动作输出不天然尊重物理约束（功率上下界、总量平衡、调节幅度），裸跑直接产出违反约束的解。（论文方法链提取 A1：以"解决 RL 输出违反物理约束"为设计动机）
- 机制：三层防御——网络结构层（特殊层使输出天然落在合法形态）、放缩限幅层（动作放缩到物理上下界）、安全层校正（输出后按约束复算并投影回可行域）；各层覆盖的约束子集显式声明、逐约束可审计。
- 前提/接口：约束清单来自题面且闭合（建议编号化）；每层声明覆盖范围；输出后逐约束复算违反计数入结果表，校正层触发率单独报告。
- 反例：只靠罚函数软约束时学习器在罚项与奖励间讨价还价，违反不归零；层数叠多会压缩动作空间使学习不收敛；投影校正可能掩盖学习本身未收敛的事实——触发率与目标值须同报。
- 迁移边界：迁移"结构层保形+限幅层保界+校正层兜底、逐约束审计"的分层思路；层数与实现按新题约束结构选配。
- 证据：论文方法链提取（2024A1；跨题共性观察：涉优化 5 篇均专门处理约束）｜source_checked

### A7 物理分项结构化建模与逐项量级自证

- 基线失效：时延类建模把公式平铺罗列——各分项贡献不量化，"哪项可忽略"无凭据：默认忽略留系统误差，全部保留又掩盖主导项；数值结果也缺独立正确性证据。（论文方法链提取 F1/F2：分尺度建体系+逐项数量级分析；F2 另以守恒律对轨道计算自检）
- 机制：按物理来源把总量分解为分项子模型（几何传播项、引力项、动钟项等，按时间尺度/空间尺度分类建体系），逐项用题给参数做数量级分析定去留，可忽略项给量级证据后显式舍弃；再配守恒律或解析特例对计算结果自检。
- 前提/接口：每分项有独立物理推导；量级分析用本题参数算得，不沿用文献默认值；"分项、量级、去留、理由"四列决策表进正文。
- 反例：换工况（轨道高度、频段）后原可忽略项可能升为主导项，量级结论不跨题沿用；分项间有耦合时逐项独立估计会错估总量级，须留联合敏感性验证。
- 迁移边界：迁移"分类建体系+逐项量级定去留+守恒律自检"的结构；分项清单与量级结论按新题参数重算。
- 证据：论文方法链提取（2024F 两篇）｜source_checked

按四层证据组织图组：

- **结构层**（问题长什么样）：物理因果链拆解图（对象—机理—变量，如"风速→载荷→损伤→决策"的对象链）；数据与物理量的量纲对账表；残差诊断图（标准公式残差对候选缺口因子的系统趋势——混合动机的第一张图）。
- **机制层**（机制为何这样设计）：混合架构接口图（物理模型、数据模型、约束层的数据流：先验进哪个模型、约束挂在哪层、修正族在哪择优）；修正函数族/方案族对比表（候选、物理动机、精度、择优结论成列）；分项量级去留表。
- **结果层**（结论证据）：双轨同口径对比表与误差分布；逐子模型精度汇总表（含样本量与类别路由正确率）；优化输出逐约束违反计数表（校正前后对照）；工况组合寻优结果（因素方差分析辅助定位最优工况组合）。
- **可信边界层**（哪里不可信）：先验特征消融表（去物理先验的精度差）；窗长/关键参数敏感性；缺口变量覆盖范围外的外推行为对照；噪声/时延/缺失注入下的鲁棒性对照。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且每处在正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性边框/背景色块；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 物理公式用错/量纲错 | 量纲检查、解析特例与守恒律复算（A7 自检通道前移到建模期） |
| 盲拟合（修正无据） | 残差诊断图先行；修正函数族同口径对比择优，动机与结论同表（A5） |
| 单轨选择无依据 | 物理轨/数据轨同划分同指标对比，择优理由显式（A2） |
| 物理先验无实效 | 先验特征去留消融，增量入表（A3） |
| 子模型过拟合/路由错 | 分 vs 统对照、逐子模型样本量与分组交叉验证、路由正确率（A4） |
| 在线化代价未知 | 在线滚动与离线全量结果对齐差 + 规模—耗时曲线（A1） |
| 约束违反 | 输出逐约束复算违反计数，校正前后对照，触发率单独报（A6） |
| 分项去留无凭据 | 逐项数量级分析表 + 参数变化下联合敏感性（A7） |
| 数据退化场景失守 | 噪声/时延/缺失注入下单独成节验证并给前后对照 |
| 工况外推失真 | 缺口变量覆盖范围声明 + 范围外样本独立评估 |
| 评价口径混用 | 同指标跨方案先统一口径再比；引用文献数值注明口径（翻车点 8） |

## 写作重点

- **混合动机先于混合架构**：摘要与问题分析先给"单轨为何不够"的证据（残差诊断、双轨对比、分项量级），再引出混合方式——"为什么混合"比"混合了什么"更值钱。
- **每个物理构件给接口**：物理模型输出什么、以什么身份（先验特征/约束/修正项/子模型路由）进入下一层，接口说不清的混合是拼贴不是架构。
- **择优与消融成表**：函数族择优、双轨对比、先验消融都以表格呈现选择依据；显式对比是本批获奖论文的主流元方法，"选用某法"无对比表不构成论证。
- **物理语言回收结论**：模型输出翻译回物理量与工况含义（最优工况组合、主导分项、损伤量级），摘要主张与物理证据逐条对齐，不用模型指标代言物理结论。
- **问链继承声明**：物理量模型（损伤/损耗/时延）是后问优化的输入，其误差以什么口径进后问（目标项/约束上界/初值）须显式声明，避免前问近似被无声当作精确值。
- **实时性写进主张**：凡涉在线决策，摘要同时报决策质量与在线化代价（对离线口径的差），不写"实时"二字了事。
- **口径纪律与数字对账**：引用文献或跨方案数值前先核评价口径（同题两篇相关系数悬殊即口径不同的实例）；摘要关键数与正文表逐一对账。
- **退化场景不缺席**：噪声/时延/缺失的处置单独成节并给前后对照，不在假设里一笔带过"数据完好"。

舍弃记录：三动作未单列入库——"守恒律自检（角动量/机械能对轨道计算复算）"并入 A7 机制与验证设计（同属物理量级自证家族，单列则五要素与 A7 大面积重复）；"SVD 降噪+相位差时滞判断+样条插值恢复"属数据质量处理动作，提取层无失效面对照，非本域机理—数据咬合核心；"等效正弦频率扩展到任意波形"为磁芯题专用物理技巧，迁移边界过窄（仅正弦励磁类损耗题适用），不单列。ANOVA 工况寻优为统计分析动作而非机理—数据咬合动作，并入图表组合结果层叙述。
