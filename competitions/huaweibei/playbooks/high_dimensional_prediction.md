# 高维预测域 Playbook

证据锚点约定：**论文方法链提取** = `analysis/lit_survey/huaweibei_2023_methods.md`（2023 年 12 篇优秀论文摘要级提取：每篇读取封面、摘要与目录前 5 页，方法名取论文自述）中 E 题出血性脑卒中 2 篇，加 `analysis/lit_survey/huaweibei_2024_methods.md`（2024 年 12 篇同口径提取）中 B 题 WLAN 吞吐量 2 篇；跨题共性观察覆盖两批各 12 篇。**我方实验** = 无（本域未做本地试点，本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域即八类风险之一的"高维预测"（特征多、样本有限、类别不平衡），优先路线（嵌套特征筛选、树/核/集成、概率校准）与必做验证（分组验证、泄漏审计、校准、适用域）沿用该文件既有约定。本文件条目均未附机制记录 id——证据层级为摘要级方法链提取，尚未做机制复核与 `../cases/mechanism_reviews.json` 入库。

## 触发条件

- 题面给出个体级"宽表"：每行一个患者/实验/会话等样本单元，特征列数十到上百（检查指标、信号统计量、链路参数），样本量与特征数同量级甚至更少——特征/样本比高，维数压力是第一约束。
- 主问是对每个样本的类别或连续量做判别/预测（疾病结局、血肿扩张、网络吞吐量），常要求风险概率或性能估计而非仅类别标签；机理不可写出或只作特征先验，主战场在特征空间与样本结构。
- 类别分布常失衡（重症结局、扩张事件等少数类），或标签为复合/有序结构（多字段组合、等级量表）——编码不当会引入伪序关系。
- 样本间非独立：同一患者多次随访、同一次实验的多个观测共享环境与状态，分组嵌套结构天然存在，iid 假设不成立。
- 常见中间变量陷阱：训练集可观测的中间量（帧统计量、链路状态类量）在测试集不存在，题面要求只用可得特征完成预测。
- 与时空预测域的分界：逐样本判别/回归，不做场或路径的演化预测，时间只是采样属性（随访间隔）不是预测对象；与物理机理+数据驱动混合域的分界：无可写出的机理骨架，特征工程与样本结构主导；与信号诊断域的分界：目标是个体结局/性能量，不是设备信号的状态判别。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面（含同题同伴路线对照）：

1. **特征筛选止步单变量统计或逐对相关手动删除**：高维宽表上冗余关系成网状，逐对决策漏掉传递性冗余（A 与 B、B 与 C 高相关而 A 与 C 不高）；只按方差/显著性筛留下的变量信息互相重复，重要性被稀释。（2023E 同题两篇对照：一篇 SPSS 相关性筛选走到底，一篇两级过滤+等价类合并）
2. **样本等权训练**：随访/测量间隔不同的样本信息新鲜度与噪声水平不同，等权训练让间隔长、信息偏旧的样本同等主导模型。（2023E 权重函数动作的反面）
3. **只交硬分类标签**：题目要"扩张概率/风险分级"级别的量化时标签答不了，样本间置信度差异被抹掉，分级决策失去输入。（2023E 置信度输出动作的反面）
4. **默认 K-means 且簇数拍脑袋**：球状等方差假设与真实簇形态（长条、密度差异、流形）不符时强行分型无意义；簇数无证据则分型结果换一版代码就变。（2023E 多聚类算法对比动作的反面）
5. **类别不平衡裸训练**：少数类被多数类淹没，整体准确率虚高而少数类召回近乎为零，模型"看起来好用"实则答不了题。（2023E Borderline-SMOTE 动作的反面）
6. **逐行独立构造特征**：同组样本（同一实验/同一患者）共享环境与状态，逐行独立丢掉组结构，"本样本相对同组的处境"这层信息消失。（2024B 跨样本联合特征动作的反面）
7. **复合/有序标签直接数值编码**：把多字段组合标签当连续数编码引入不存在的伪序关系，距离型模型学到假结构。（2024B 复合标签独热编码动作的反面）
8. **只报单一汇总指标**：误差分布的偏态与尾部被均值/准确率掩盖，最差样本错多少、多大比例超业务阈值不可见。（2024B CDF 评估动作的反面）
9. **端到端直奔目标**：目标依赖的中间观测变量在测试集不存在，端到端模型学不到"可得特征→中间量→目标"的链条，测试时也无从注入结构。（2024B 级联动作的反面）
10. **模块堆叠不归因**：过滤、加权、过采样、集成一次全上，每个模块贡献无从指认，实际有害的模块被埋在管线里。（2023E 消融动作的反面）

### 补充：跨域借鉴（2023-C 创新竞赛评审方案，评价维度）

- 用矩阵范数理论推导证明某目标函数恒为常数，据此把双目标优化降为单目标——基线失效：直接上多目标算法求帕累托前沿，其中一维目标是常数，白算一个无效维度且"权衡"叙事失真。证据：2023-C 优秀论文方法链提取（`analysis/lit_survey/huaweibei_2023_methods.md`，2 篇中 1 篇显式动作）。
- 自造对准题面目标的评价指标体系（均衡性、交叉值等），并以官方最终结果为"匹配度"外部锚点给全部方案择优——基线失效：直接套现成综合评价公式与题面特有目标（专家分配的均衡与交叉）错位；多方案并出时无外部基准只能内部自评，择优无凭据。证据：同上（2 篇）。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面锚定提取记录中论文自述的动机、同题同伴路线对照或跨题共性观察；提取为摘要级，机制细节以提取字段为准，我方未复算。

### A1 嵌套特征筛选：无区分力过滤 + 并查集等价类去冗余

- 基线失效：逐对算相关系数手动决定删谁（2023E 同题同伴即 SPSS 相关性筛选路线）——高维下冗余呈网状，逐对决策漏掉传递性冗余且删留标准不可复现；单变量过滤只去无区分力列，留下的高相关列互相稀释重要性。
- 机制：两级嵌套——第一级按方差显著性剔除无区分力特征，第二级把高相关特征对交给并查集合并等价类、每类保留代表列；去冗余从逐对决策变成集合运算，筛选结果可复走。
- 前提/接口：筛选只在训练折内做防泄漏；相关阈值敏感性随结果报告；输出"等价类—代表列"清单供后续解释与写作引用。
- 反例：高相关但物理含义不同的列机械合并丢信息（如指示变量与复合得分相关但承载不同语义）；皮尔逊类相关只捕捉线性冗余，单调非线性冗余漏网，须以互信息或树重要性交叉复核。
- 迁移边界：迁移"先降无区分力、再按等价类去冗余"的嵌套顺序；相关度量与阈值按新题分布重定，代表列选择规则按业务可解释性定。
- 证据：论文方法链提取（2023E 两篇对照）｜source_checked

### A2 特征权重函数按采样质量差异化加权

- 基线失效：所有样本等权——"发病至首次检查时间间隔"不同的样本，特征所含病情演化信息的新鲜度与噪声水平不同（间隔长则特征偏旧），等权训练让低信息样本同等影响模型。
- 机制：以采样间隔类代理变量构造权重函数对样本差异化加权，采样质量从隐变量变成显式输入，信息新鲜的样本权重大。
- 前提/接口：存在可度量的采样质量代理量（时间间隔、测量滞后、设备/版本差异）；权重函数形式在验证口径上选，函数要简单、参数要少；权重分布随结果报告，防个别样本权重过大主导训练。
- 反例：代理量与噪声实际无关时加权引入偏差；权重函数在验证集上过拟合后换折即翻车；权重极化时模型实际只学了小部分样本，等价于丢数据。
- 迁移边界：迁移"采样质量可度量则可加权"的思想；代理量按新题换（随访间隔、测量轮次、标注来源），衰减形式随数据重估。
- 证据：论文方法链提取（2023E）｜source_checked

### A3 分类器置信度输出概率（配校准检验）

- 基线失效：只报类别标签——题目问风险量化时硬分类答不了；同类样本间的置信度差异被抹掉，"哪些立即干预、哪些观察"的分级决策失去输入。
- 机制：KNN/SVM/RF/GBDT 多分类器横向对比择优后，以最优分类器的置信度输出作为概率交付物；概率与类别解耦，风险分层基于概率阈值而非标签。
- 前提/接口：所选分类器有可用置信度接口；原始置信度须经校准检验（可靠性曲线/Brier）才能作概率主张；概率阈值按任务代价（漏判 vs 误判）另选，不平衡下不默认对半开。
- 反例：未校准置信度当概率用会系统性偏乐观或偏悲观（深树投票概率趋向两端）；只报排序类指标不报校准时，排序能力好但概率值不可信，风险量化主张仍不成立。
- 迁移边界：迁移"交付概率 + 校准证据 + 代价阈值"三件套；校准方法按新题样本量选，阈值随决策代价重定。
- 证据：论文方法链提取（2023E）｜source_checked

### A4 聚类分型：多算法同台 + 内部指标择优 + 簇数有据

- 基线失效：默认 K-means 且簇数拍脑袋——算法假设（球状、等方差）与数据形态不符时分型无意义；无簇数证据的分型结果不可复现，后续分组建模建在流沙上。
- 机制：肘部法则先给簇数候选，GMM/DBSCAN/BIRCH/谱聚类多算法同台，以轮廓系数与 DBI 等内部指标择优，降维可视化辅助展示分型结构——把分型从"默认配置"变成"数据形态与算法假设匹配"的论证。
- 前提/接口：聚类前特征已筛选并标准化（量纲主导距离）；多算法在统一口径上比较；分型作为后续分组建模的输入，分型前后误差对照必须报告，证明分型带来真实收益。
- 反例：高维下欧氏距离集中失效，须先降维再聚类而降维方式影响分型，口径要声明；内部指标只衡量紧致与分离，不保证分型有业务含义，须补组间差异检验。
- 迁移边界：迁移"形态假设→算法匹配→指标择优→分型后分组建模"的链条；算法池、指标与簇数证据随新题数据重配重算。
- 证据：论文方法链提取（2023E）｜source_checked

### A5 边界过采样 + 异质集成处理不平衡

- 基线失效：不平衡下直接训练——少数类被淹没，整体准确率虚高而少数类召回接近零；单一模型对各区域判别面各有强弱，无互补利用。
- 机制：Borderline-SMOTE 只对决策边界附近的少数类样本合成过采样（扩增"难分样本"而非全体复制）；Stacking 以元学习器融合多个异质基分类器，学习"哪种样本信哪个基模型"。
- 前提/接口：过采样只发生在训练折内，测试折与最终测试集绝不参与合成（经典泄漏点）；基模型须异质（不同归纳偏置才有互补）；分层抽样保持各折类别比例。
- 反例：在测试信息上合成样本则交叉验证分数虚高到不可信；边界少数类实为噪声或标注错误时边界过采样放大噪声；基模型同质时 Stacking 收益趋零只添复杂度。
- 迁移边界：迁移"边界过采样 + 异质集成"的组合；合成比例与近邻参数按新题重调，基模型池按数据形态另配；样本极小时可退回类别权重或欠采样。
- 证据：论文方法链提取（2023E）｜source_checked

### A6 跨样本联合构造组内特征

- 基线失效：逐行独立构造特征——同一次实验的样本共享干扰环境与信道状态（SINR 与同组其他样本相关），逐行独立丢掉组结构，模型看不到"本样本相对同组的处境"。
- 机制：先识别分组键（实验号/患者号/会话号），在组内联合构造特征——组内统计量、组内排名、相对差等，把样本间相关性从干扰项变成信息源。
- 前提/接口：分组键在训练与预测阶段都可识别；组内特征只用本组信息构造，防跨组泄漏；组大小分布随结果报告（小组的组内统计量不稳）。
- 反例：预测样本所在组在训练中未出现（新实验/新患者）时组内特征无定义，须设计回退路径；组内聚合不小心包含标签信息时构造出组内变体的目标泄漏特征。
- 迁移边界：迁移"找分组键→组内联合构造→新组回退"的结构；分组键与组内统计量按新题领域定。
- 证据：论文方法链提取（2024B）｜source_checked

### A7 CDF 视角评估误差分布

- 基线失效：只报单一准确率或平均误差——误差分布有偏有尾时均值掩盖尾部行为（最差样本错多少、多大比例超业务阈值）；两个模型均值相当而尾部风险悬殊时单一指标无法区分。
- 机制：以累积分布函数呈现预测误差的完整分布，任意阈值下的样本覆盖率同图可读，中位行为与尾部行为并见；配合分位数表入表交付。
- 前提/接口：误差定义先声明口径（绝对/相对/业务量纲）；跨模型对比用同一坐标系与同一划分；分位数报告注明支撑样本量。
- 反例：CDF 只描述已观测误差，不能外推更极端分位；测试样本少时尾部抖动大，尾部结论慎下；两曲线接近时不做显著性检验，差异可能只是抽样噪声。
- 迁移边界：迁移"分布视角评估误差"的结构；CDF/箱线图/分位数表按篇幅与评审习惯选，阈值口径按业务定。
- 证据：论文方法链提取（2024B）｜source_checked

### A8 级联预测：先补中间变量、再预测目标

- 基线失效：端到端直奔目标——吞吐量依赖的中间观测变量（帧统计量、链路状态类量）在测试集不存在，端到端模型学不到"可得特征→中间量→目标"的链条，测试时也无从注入结构，中间变量的解释作用一并丢失。
- 机制：识别目标的因果中间层，第一层用可得特征预测中间变量，第二层以中间变量预测值为输入预测目标——级联结构与数据生成过程对齐，测试时缺失的中间层由第一层补全。
- 前提/接口：中间变量在训练集可观测且与目标机理关联明确；两层分别验证并量化误差传播（第一层误差会被第二层继承）；级联 vs 端到端同口径对照入表。
- 反例：中间变量选错（与目标只有相关无机理）时级联放大误差，第一层噪声层层传递；两层都复杂时级联是两倍过拟合面，可能不如带正则的端到端。
- 迁移边界：迁移"识别缺失中间层→级联补全→误差传播量化"的结构；中间变量按新题领域机理识别，层数按因果链深度定（通常两层）。
- 证据：论文方法链提取（2024B 两篇）｜source_checked

### A9 逐模块消融归因管线贡献

- 基线失效：特征过滤、加权、过采样、集成模块一次全上——最终分数无法归因到任何模块，评审追问"过滤贡献多少、加权贡献多少"时无凭据；实际有害的模块被埋在管线里无人发现。
- 机制：以完整管线为基准，逐一去留单个模块重训重评，每个模块的边际贡献单独成表；模块从"感觉有用"变成"数字说话"，负贡献模块如实剔除。
- 前提/接口：消融配置共用同一数据划分与指标口径（划分变了贡献不可比）；调参预算在各配置间公平分配；模块间有交互时补关键交叉消融。
- 反例：每个消融配置都重新调参到最优会引入调参噪声，贡献差异可能来自运气；模块多而数据小时消融差异落在噪声区间，应报"无显著差异"而非硬排座次。
- 迁移边界：迁移"逐模块消融 + 贡献成表"的归因纪律，管线（含 A1-A8 任意组合）交付前必做；消融粒度按模块数与算力定。
- 证据：论文方法链提取（2023E）+ 跨题共性观察（2024 批 12 篇中 10 篇显式做对比/消融）｜source_checked

- **结构层**（问题长什么样）：宽表对账表（样本单元 × 特征数 × 缺失率 × 类别分布与不平衡比）；特征相关热力图/网络（高相关块与等价类划分）；样本嵌套结构示意（样本→患者/实验分组）；复合标签取值组合与序关系口径说明。
- **机制层**（机制为何这样设计）：特征筛选流程图（无区分力过滤→等价类合并→代表列）；权重函数曲线（采样代理量→权重）；分型-分组建模架构图；级联架构图（可得特征→中间变量→目标，两层接口与误差传播位标注）。
- **结果层**（结论证据）：多分类器/多聚类算法对比表（统一划分与指标口径）；概率校准可靠性曲线；CDF 误差分布图（多模型同坐标系，配分位数表）；消融贡献表（模块×边际增量）；分型前后误差分层对照表。
- **可信边界层**（哪里不可信）：分组划分 vs 随机划分误差对比（泄漏量级证据）；分类别误差表（少数类单列）；关键参数敏感性（相关阈值、权重函数形式、过采样比例、簇数）；未见分组单元上的误差退化评估。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性边框/背景色块；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应（"分组验证、泄漏审计、校准、适用域"对齐 distilled_modeling 本域必做验证）：

| 域风险 | 对应验证 |
|---|---|
| 组结构泄漏 | 按患者/实验/会话等原始单元分组划分，同组样本不跨折；分组 vs 随机划分对照入表，两者差距即泄漏量级（A6） |
| 管线内泄漏 | 特征筛选、权重标定、过采样只在训练折内完成；嵌套交叉验证给无偏估计（A1/A2/A5） |
| 高维过拟合 | 学习曲线（样本量-误差）+ 简单基线对照；树/集成打不赢线性基线就不保留复杂度 |
| 概率误导 | 可靠性曲线/Brier 校准检验；概率阈值按决策代价另选，不默认对半开（A3） |
| 不平衡掩盖 | 分类别指标单列（少数类召回/精确），整体准确率不单独作结论（A5） |
| 分型无据 | 内部指标 + 组间差异检验双证据；分型前后误差对照（A4） |
| 级联误差传播 | 两层分别验证 + 级联 vs 端到端同口径对照（A8） |
| 评分口径单一 | CDF/分位数族多口径报告尾部行为；跨模型统一划分与指标（A7） |
| 模块无实效 | 逐模块消融、贡献成表，无增量如实报告（A9） |
| 适用域外样本 | 新患者/新实验等未见单元上误差单独评估，不与域内混报 |

## 写作重点

- **特征工程主线可复走**：从原始宽表到入模特征集的每步（过滤、等价类去冗余、加权、编码、组内构造）成表成图，评审能沿文档重走一遍；等价类清单与权重函数显式交付。
- **概率交付**：结论句写概率与风险分层而非裸标签；校准证据与概率主张同现；阈值与漏判/误判代价挂钩写明。
- **不平衡透明**：少数类指标单列、过采样边界与合成比例写明；"整体准确率高"不作卖点。
- **结构证据先行**：先给数据结构证据（嵌套分组、类别分布、相关网络、采样间隔分布）再谈模型；每个建模选择回指结构特征，避免"直接选用某模型"的悬空论证。
- **消融当收据**：模块贡献表进正文；摘要只主张有消融支撑的改进，负贡献模块的剔除过程如实写。
- **级联写误差传播**：两层误差分开报、级联收益对照端到端成表；不把级联结构当理所当然。
- **口径纪律**：跨模型、跨表数值先统一划分与指标口径再比；CDF 分位数注明样本量；不搬其他论文的数值作对比。

舍弃记录：任务候选池九条全部入库（A1-A9），无候选被裁；另有提取池若干项不单列——"肘部法则定簇数"与降维可视化（t-SNE 类）为 A4 的前置构件与展示手段；"网格搜索 + K 折交叉验证"属规范调参与验证纪律，并入验证设计各行的口径要求；"目标编码 + 虚拟变量数值化"与"复合标签独热编码"（2024B）属编码层序数敏感处理，其失效面（伪序关系误导距离型模型）入翻车点第 7 条，编码操作本身并入机制层叙述；"PCA 降维归因"（2023E）提取层无基线失效对照；"随访数据时间-空间解耦量化成多指标"（2023E）为该题随访结构专用处理，泛化面窄，并入结构层数据形态叙述。
