# 空间几何 Playbook（华为杯）

对齐 `../distilled_modeling.md` 八类风险之"空间几何"（路径、视域、网络、三维关系）。本层回答"这个域里高手具体做了什么动作、基线为什么不够"，不替代缺口驱动选型：命中本域后，动作清单只作为 stage 3 候选生成输入之一。

证据基础与标注约定：

- **论文深读** = F 题优秀论文副本重点页阅读（经 `../cases/mechanism_reviews.json` F×2 入库；未逐式完整审计、未核验获奖身份，不搬其数值与原句）。
- **我方实验** = 绮园 Q1 局部试点（本域唯一本地复核证据）或诊断文档中的本地微型复核（下称"诊断"）。试点报告与诊断文档均为内部审计产物，分发版不含；已固化结论以 `../cases/mechanism_reviews.json` 入库条目（F×2）为准，文内"诊断 §N"为该内部文档的节号定位，按归纳归属对待。
- **双向** = 论文深读与我方实验兼有。
- 试点覆盖局限（凡标 locally_tested 的条目均受此限）：单园（绮园）、二维代理、情景端点（未核验真实出入口）、81 条共享候选的非完备搜索。下文不再逐条重复。

## 触发条件

- 题面给出几何边界、地图、图纸线段/多边形坐标、栅格或三维结构，问路径设计、视域、遮挡、空间分区、覆盖、美学量化或可达性。
- 数据形态常见：坐标表（注意图纸单位，如毫米）+ 平面参考图 + 点位/类别属性；"游览""视线""景观变化""开合"等现实概念需要转成可计算对象。
- 与调度优化域的区分：决策对象是空间位置与几何关系，不是时间上的资源配置；主体是排班/储能/流量时走调度域 playbook。

## 常见翻车点

1. **题意识别了，没落实成求解义务。** 红队记录已指出视域、遮挡、真实出入口、道路拓扑风险，实际求解却退化为最大连通分量上的有限最短路候选加距离收益；审题记录、选型承诺、代码与答题状态之间缺乏强制对应。（诊断 §一、§3.1–3.3）
2. **中间数学对象缺失。** "靠近景物"≠"看到景物"≠"移步后看到不同景物"，三个概念被压成一个距离量：最近元素从水体换成建筑，距离相同则节点收益完全相同；绮园反例：目标值上升，景观类别变化次数与转折数反而下降。（诊断 §3.2，我方微型复核）
3. **求解范围比选型承诺窄，还沿用更强的名字。** 有限端点 Dijkstra 候选不搜索同起终点稍长的备选路线，起终点未约束为经图纸核验的真实出入口，输出模型名仍称"束搜索"。（诊断 §3.3）
4. **用节点占比冒充覆盖。** 最大分量节点占比（留园约 38.3%、豫园约 26.4%）不是可游览面积或道路长度占比；在截断图上满足长度预算只证明截取图上合格，不证明真实可游览。（诊断 §3.3）
5. **验证打在替身上。** 玩具验证器验证的是另一个动态状态搜索与玩具目标，不是生产求解器的有限候选实现；测试只确认"能运行"，不构造目标会偏好的错误行为。（诊断 §3.4）
6. **指标接口与口径漂移。** 稀疏节点收益只在间隔抽取的节点上计算、未取到的按零计，折线细分与采样密度可改变得分；参考论文副本自身前两页评分口径矛盾，汇总量必须先统一口径再比较。（诊断 §3.2、§4.3）
7. **有限证据写成过强结论。** 代理目标提高被写成"换景效果提高"；论文声称全局最优却无最优性证书；节点占比达标被当作全园覆盖。（诊断 §3.2、§3.3、§4.3）

## 惊艳动作清单

### 动作 1：几何边界 → 可通行图（中轴/中心线 + 碰撞清理与断裂诊断）

证据来源：双向；review_status：locally_tested（中心线+碰撞清理+分量诊断路径经试点复核；Voronoi/中轴变体仅论文深读，未本地复算）。

- 基线在哪失效：图纸线段与道路边界不等于"人在哪里能走"。原始骨架含落在建筑面内的节点与和实体边界交叉的边（试点清理移除 23 节点、12 边）；清理后仍余 22 个分量，绮园最大分量占原节点 79.37%。直接在原始图或单一最大分量上求解，可行性与覆盖都无从谈起。（试点；诊断 §3.3）
- 机制：先把几何变成可通行网络（论文深读路径：Voronoi 中轴走廊加障碍相交检查；试点路径：中心线加实体碰撞清理），再对断裂做来源诊断——区分真实隔离与抽取错误，局部叠图核验桥接与障碍；未修复部分作为明确情景或待补义务保留，不把降级版本标记为充分答题。
- 前提/接口：单位先统一（试点原图坐标毫米，试点图换算为米）；输出米制图给搜索层；端点选择与出入口核验解耦——度为 1 的点不必然是真实门口（论文深读风险）。
- 反例：起终点落在小分量上的园会被"最大分量"近似整个丢掉；一处桥接缺失即可把真实连通的园切成多分量。
- 迁移边界：节点占比不能当覆盖面积或道路长度使用；试点未完成出入口配准，"图算法端点"只能称情景端点；断裂修复是未完成义务而非可选项。

### 动作 2：射线/视景矩阵处理遮挡

证据来源：双向；review_status：locally_tested。

- 基线在哪失效：最近距离不能区分遮挡——墙后景物按距离照样计分（mechanism_reviews F×2 入库的 baseline_gap）；试点消融显示去掉实体遮挡后固定路线相对该情景最佳的目标差距为 13.90% 且重选路线改变，证明遮挡假设实质影响决策而非装饰。（试点）
- 机制：等弧长采样点用前后切线定向，扇形视场内多条射线从近到远记录首个不透明实体之前的可见类别，汇总为归一化类别描述向量（试点实现）；论文深读同源机制为射线视景矩阵。
- 前提/接口：必须显式声明哪些类别不透明（试点：实体建筑不透明；假山高度不明，另设全不透明情景；植冠是投影范围不是树干墙；半开放建筑按题面通透处理）。输入为米制坐标与采样方向，输出描述向量交给序列度量。
- 反例：墙后很近但不可见的景物（试点合成反例通过）；假山改判不透明后固定路线相对该情景最佳差距达 26.03% 且重选改变——遮挡假设敏感性必须报告。
- 迁移边界：二维代理，无高度、材质、洞口与季节；描述向量是人为归一化的多标签描述，不是像素面积分布也不是审美概率；单园验证。

### 动作 3："可见≠邻近"概念分层

证据来源：双向；review_status：locally_tested。

- 基线在哪失效：距离收益把"周围有什么"当"能看到什么"——水体换建筑、距离相同则收益不变；转折数与景观类别变化次数在路线选定之后才计算、不进目标。（诊断 §3.2）
- 机制：把现实概念拆成三层可检验数学对象——空间邻近（距离场）→ 实际可见（带遮挡与方向的视景描述）→ 序列变化（移步后描述的差异），层与层语义不同、不可互相替代（论文深读"三个转换"+ 试点落地三层并做同候选对照）。
- 前提/接口：层间只通过声明的量传递（距离场/描述向量/差分序列），上层不得偷用下层未定义的信息；每层结论措辞与该层证据强度对齐。
- 反例："沿路一直看同一种近景"与"沿途看到丰富不同的近景"在距离收益下不可区分；原地掉头能在序列层刷高变化量但并未揭示新景物。
- 迁移边界：分层动作本身通用；但试点对照中，视景目标相对同候选距离基线的路线增益为零——分层提升的是可解释性与可追责性，不自动带来选择增益，两者必须分开报告，不许把前者写成后者。

### 动作 4：沿路径等弧长序列变化度量

证据来源：双向；review_status：locally_tested。

- 基线在哪失效：单点景观丰富不等于沿途变化；稀疏节点收益对离散化密度敏感，同一物理路线可能因采样方式改变得分。（诊断 §3.2）
- 机制：固定弧长间隔采样（试点默认 2 米）消除折线细分的影响（合成反例：折线加密不改变等弧长采样点）；相邻描述向量按总变差距离差分，沿途累计为变化总量，再减去重复长度罚项；同步报告每百米变化，避免把多走路产生的累计量误报成质量改善。（试点）
- 前提/接口：采样间隔、视距、重复罚系数是情景参数，须披露并做敏感性；与候选集、长度预算共用同一比较接口。
- 反例：原地掉头或重复经过同一景物可刷高累计变化；采样间隔 4 米时重选路线改变、固定路线相对该情景最佳损失 2.53%；重复罚取 0.2 与 0.5 时改选更短路线（试点敏感性表）。
- 迁移边界：累计量受长度、采样与掉头影响；"短、少重复、变化多"的取舍应显式给 Pareto 关系而非冻结唯一权重；罚系数未经专家或游客标定；非完备候选搜索。

### 动作 5：特征聚类 + 空间约束分区（GMM+MRF）

证据来源：论文深读；review_status：source_checked。

- 基线在哪失效：只有全园均值会抹掉空间组织；仅按特征相似聚类会在地图上产生不合理碎片。（mechanism_reviews F×2；诊断 §4.2）
- 机制：构造局部单元特征 → GMM 软归属回答"哪些单元在特征上相似"→ MRF 以邻接与阻隔回答"分区如何反映空间连续性"，分区再解释为景观主题进入开合/幻境分析。组合动机可解释：数据相似性不足以表达空间组织，故引入空间约束。
- 前提/接口：单元特征/软归属与邻接图共用同一单元索引；MRF 能量单位与邻接权重的含义须定义。
- 反例：隔墙两侧特征相似但不应划成连续分区；窄小真实区域可能被连续性正则平滑消除。
- 迁移边界：未本地复算、未做去 MRF 对照——组合必要性须以"去掉 MRF、调整邻接权重"的对照检验，不能因公式更多认定更好；ICM 通常只提供局部优化（源文"近似全局最小"表述过强）；不默认所有评价题套用 GMM-MRF。

### 动作 6：几何机理反演链（坐标往返/守恒/特例校验）

证据来源：我方实验；review_status：locally_tested。

- 基线在哪失效：验证打在玩具替身而非正式实现（诊断 §3.4）；空间域的坐标单位（毫米/米）与折线细分方式极易引入隐性口径错误（诊断 §3.2、试点）。
- 机制：对正式生产函数构造合成特例与往返、守恒校验——墙后水体不可见、改变朝向能改变前视野、相同场景变化为零、互斥场景差异为一、折线加密不改变采样点、重复边计长、同端点可保留稍长绕行；另做坐标原件哈希与保存结果复算核对（试点验证通过 15 项、失败 0）。
- 前提/接口：校验对象是生产函数本身，不另写理想化玩具算法代替；测试必须容许暴露"该方法不适用"，不得把预期趋势写成通过条件。
- 反例：只确认"能运行"的验证空转——不构造目标会偏好的错误行为（如掉头刷分），就发现不了代理漏洞。
- 迁移边界：合成正确性、几何代理可行性、审美有效性是三级独立证据，须分开报告；15 项通过仅限本轮实现，换实现须重跑。

## 图表组合

按四层证据组织图组，各层承担不同论点：

- **结构层（几何底图）**：原骨架、碰撞清理、保留分量的几何诊断图，配合参考平面图叠图核验；候选集"长度-累计变化"散点暴露取舍空间。（试点图 3 型）
- **机制层（视景序列）**：可见性描述沿游线的分布 + 相邻样本差异曲线 + 高变化点的局部视域与截断射线（试点图 2 型）。高变化点按计算值排序选取，caption 中说明选取规则，不得命名为"豁然开朗"等未经照片对照的主观事件。
- **结果层（路径对照）**：同一平面、相同坐标尺度下，距离基线与视景目标的入选路线对照（试点图 1 型）；十园汇总表之外，代表性园林局部放大负责解释机制，正文给出带名称的路线图与关键变化点，不能只有总表。
- **可信边界层（残差与敏感性）**：遮挡假设（假山透明/不透明、去遮挡消融）、采样间隔、视距、重复罚的重选路线与决策损失表——报告"固定方案相对各情景最佳的差距"，不只报排名变化；分区题补空间残差地图与去 MRF 对照。

图内标注纪律（与 README 一致）：数据图（Type 3）图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)；参考线与关键点标记全文 ≤3 处且每处在正文有对应论证句；技术路线图/流程图的标题条属版式组成部分，豁免；多面板各 panel 允许 ≤6 个中文字符当量的轴含义短标签。

## 验证设计

验证动作与域内风险一一对应：

| 域内风险 | 验证动作 | 试点示范/状态 |
|---|---|---|
| 图构建失真（断裂、碰撞、丢分量） | 对生产函数的几何特例与守恒校验（动作 6 反例组） | 试点通过 15 项 |
| 单位与坐标口径错误 | 坐标往返一致性：毫米↔米换算、坐标哈希、保存结果复算 | 试点已执行 |
| 二维遮挡代理失真 | 遮挡假设敏感性：假山透明/不透明、去遮挡消融，报告设定内决策损失 | 26.03%/13.90% 级别的差距实证存在 |
| 视景/路线真实性 | 人工典型点抽查：对照照片或手工可见性标签 | 试点未做，属待补义务；自定指标上升不构成独立验证 |
| 采样与尺度依赖 | 多尺度稳健性：间隔 1/2/4 米、视距 30/40/50 米；同一物理路线加密采样重编号后结论是否保持 | 间隔 4 米时重选改变 |
| 模块组合虚增增益 | 同图、同端点、同候选、同预算公平对照，允许零增益结果 | 试点三种评分同选 28 号 |
| 分区组合必要性 | 去 MRF、调邻接权重的对照 | 当前仅论文深读，未本地执行 |

## 写作重点

- **概念分层叙事是本域加分点。** 每问按"具体难点 → 可计算定义 → 为什么这样组合 → 求解与边界 → 针对性验证 → 直接回答题问"组织；把"现实概念 → 可检验数学对象"的中间层写显式（邻近/可见/序列三层各是什么量、数据能否区分、什么行为能推翻它），配反例而非通用算法介绍。
- **有限证据的措辞边界。** 允许并应写明"本轮未带来额外路线收益，作用在于把收益追溯到可见类别与发生位置"；合成正确性、几何代理可行性、审美有效性三级分开陈述；情景端点不写成真实出入口，节点占比不写成覆盖率；单园、二维、非完备搜索的局限在正文与摘要同步保留；"收敛、最优、提升、稳健"逐词核对对应证据文件后方可使用。
- **汇总与局部并重。** 十园汇总图表负责完整答题，代表性局部放大负责解释机制；路线呈现须落到带名称的路线图与关键变化点。

机制库对应：动作 2/3/4 对应 `huaweibei_2025_F_visibility_sequence`（locally_tested），动作 5 对应 `huaweibei_2025_F_spatial_partition`（source_checked）。

## 舍弃记录

- 覆盖几何：现有证据仅支持"节点占比被误当可游览覆盖"的失效诊断（诊断 §3.3、试点硬问题），无任何来源给出覆盖度量的机制（视域并集、集覆盖、扫描等）及其反例，五要素不齐，本版舍弃；该失效诊断已并入动作 1 的反例与迁移边界。
