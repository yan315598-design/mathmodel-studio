# 调度优化域 Playbook

证据锚点约定：**论文深读** = `papers/manual_paper_reviews.json` 33 篇深读记录中调度域 6 篇（`papers[10]`–`papers[15]`：2021_F 机组排班 2 篇 + 2025_A NPU 核内调度 4 篇），逐篇提取笔记 = `analysis/playbook_extract/scheduling_actions_raw.md`；**我方实验** = 无（本域未做本地试点，本文件不出现 locally_tested 条目）。全部条目为 source 层：深读记录复核过论文内容，我方未复算论文算法，不搬数值与原句。域级索引入口 = `papers/domain_index.md`（2021 届深读记录的 derivation_logic/solver_logic 等字段为写作模板，不作逐篇结论引用，警示见该文件顶部）。风险语言对齐 `../distilled_modeling.md` 八类之"调度优化"（依赖、容量、资格和时序共同限制）。

## 触发条件

- 题面主体是"在依赖、容量、资格、时序约束下给有限资源排任务或排顺序"：排班、机组航班匹配、排产、任务调度、缓存/内存分配等；目标常为成本、完工时间、覆盖率、利用率与公平的加权组合。
- 数据/题面形态：任务清单 + 资源清单 + 规则条款（连接时间、资格、生命周期、拓扑依赖 DAG、容量上限）；多问递进，前问输出天然是后问输入。
- 与空间几何域的区分（见 `spatial_geometry.md` 触发条件）：决策对象是时间与资源上的配置，不是空间位置与几何关系。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下全部来自论文深读发现（论文自警或深读点名）：

1. **完全无外部基线**：同题一篇全文无任何基线对比，有效性验证仅自比（后问只报相对自身前问的改进）——"自己比自己好"不构成解质量证据。（论文深读）
2. **启发式结果无最优性锚定即下结论**：一篇自认"启发式快不代表接近最优"仍照常交付；一篇缺精确解与启发式解差距的定量报告；6 篇里仅 1 篇做了与精确最优的对齐。（论文深读，跨篇观察）
3. **摘要与正文数值对不上**：headline 百分比与正文表不符、改进率符号与口径混乱、跨表同指标数值矛盾，多篇被深读点名不可引用——交稿前数字对账缺失。（论文深读）
4. **固定加权系数当可复用结论**：加权目标不给业务优先级，权重敏感性缺失或仅标"待补"，跨题直接沿用旧权重。（论文深读，多篇自警）
5. **简化假设高估可行性**：如"无延误 + 周期边界状态"假设被论文自警会高估排班可行性，普通做法常忽略这两点。（论文深读）
6. **题设滑移**：后问叙述框架悄悄扩大（如从单序列滑移为多序列协同），与题设不符仍按原题口径宣称。（论文深读）
7. **约束散在散文、修复不可追溯**：罚函数一锅炖，解的违反项无法回指题面条款，修复逻辑与约束没有对照关系——与编号法典实践对照的反面。（论文深读）
8. **实时性证据缺位**：启发式只报目标值不报规模—耗时，求解时间预算无上限；对照做法是大小规模运行时间与实测复杂度作兜底论证。（论文深读）

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面找不到论文实证锚点（基线比较/消融/自警）的条目，第一要素改用"理论风险（推断）"表述并降为 proposed，不把从机制反推的通用失败模式冒充论文实证。

### A1 最优性锚定：小规模精确解校准大规模启发式

- 基线失效：启发式只报目标值与运行时间，解质量无从评价——同域有论文自认快不代表接近最优、有论文被深读点名缺精确解与启发式解差距的定量报告，6 篇里仅 1 篇与精确最优对齐。（论文深读，跨篇观察）
- 机制：先建精确模型（ILP/MILP），在保留约束结构的小规模实例上求精确最优，同实例对齐启发式解并报告间隙；大规模不可精确求解时显式写明降级理由（如决策变量规模），精确模型保留为可行性与解质量的参照而非摆设。
- 前提/接口：同一套模型定义（变量/目标/约束）喂给精确求解器与启发式；小规模实例须让各类约束均被激活；对齐结果以同实例目标值差写入结果表。
- 反例：小规模实例缺某类约束时校准不可迁移；精确模型本身建模有误时锚点错误并传导至大规模结论；只报"与最优一致"不报规模口径，读者无法判断对齐范围。
- 迁移边界：迁移锚定纪律（精确先行、小规模对齐、降级理由显式、间隙入表）；论文的规模划分、系数与数值不迁移。
- 证据：论文深读｜source_checked｜机制记录 huaweibei_2021_F_optimality_anchoring

### A2 复杂连接规则预计算为可行对稀疏矩阵

- 理论风险（推断，非论文实证——深读记录只载论文采用了该机制，未载其反面被运行或观察）：可换航班、任务环连接这类带时间窗与资格的连接规则若直接进求解器，约束规模随任务对膨胀、求解器难利用结构；逐解检查则让启发式大量时间耗在非法组合上。
- 机制：把连接规则的判定前移到建模前，离线枚举生成可行对稀疏矩阵，求解阶段只触碰合法组合——规则复杂度从求解循环里挪出去。
- 前提/接口：连接规则可两两判定（给定任务对即可判合法）；稀疏矩阵与目标函数共用任务索引；规则变更时重算矩阵而非改求解器。
- 反例：依赖全局状态或前序决策的规则（动态容量、随排程变化的资格）无法两两预计算；可行对过密时矩阵不降规模反增内存。
- 迁移边界：迁移"规则前移、求解只碰合法组合"的分工；具体规则、阈值与矩阵结构按新题重新生成。
- 证据：论文深读（机制锚点：papers[11].reusable_patterns「把复杂连接规则预计算为稀疏矩阵」+ modeling_body_by_q[*].model_chain；失效面无锚点，为推断）｜proposed

### A3 非线性逻辑线性化保住可解结构

- 理论风险（推断，非论文实证——深读记录只载线性化动作本身，未载不做线性化的对照）：0-1 决策的乘积耦合（任务环—人员指派）、公平的 max 偏差这类非线性逻辑，若直接建模会逼成非线性整数规划或被丢弃换启发式硬扛，失去精确求解与锚定的可能。
- 机制：乘积项用辅助 0-1 变量线性化；min-max 公平用偏差上界变量线性化后并入加权目标——非线性语义保住，模型仍是 ILP 可解结构。
- 前提/接口：线性化带来的变量/约束增量须评估规模代价；公平口径（最大偏差而非人均方差）随目标函数一起声明。
- 反例：连续变量的强非线性耦合无法精确线性化，近似线性化会移动最优解位置；辅助变量本身可能把模型推到不可解规模——这恰是"先精确后降级"须显式记录的情形。
- 迁移边界：迁移"先问能否线性化、再问是否降级"的顺序；具体线性化技巧按新题的耦合结构选择。
- 证据：论文深读（机制锚点：papers[10].reusable_patterns「非线性逻辑用辅助变量线性化」、papers[11].reusable_patterns「公平目标用最大偏差线性化」；失效面无锚点，为推断）｜proposed

### A4 邻域操作内置合法性（拓扑合法区间）

- 基线失效：通用元启发式生成非法解再用罚函数或修复兜底——搜索大量耗在不可行域，罚系数调参引入新自由度，修复算子与约束脱节。
- 机制：把合法性做进邻域定义：任务的可移动区间取前驱最晚位置与后继最早位置之间，每次移动天然满足拓扑序，元启发式全程可行、免修复。
- 前提/接口：约束可表达为区间性质（拓扑序、时间窗）；邻域算子与模型共用同一前驱/后继结构；目标函数变更不破坏邻域合法性。
- 反例：累积型约束（总容量、全局资源）不是区间性质，仍需修复或解码层；约束逐问递进时邻域定义须随新约束重推，沿用旧邻域会静默放行非法解。
- 迁移边界：迁移"合法性内置于邻域而非事后罚"的思想；合法区间的前驱/后继语义按新题依赖结构推导。
- 证据：论文深读｜source_checked

### A5 约束与修复编号化、一一对应可审计

- 基线失效：约束散在散文与代码注释里，罚函数一锅炖——评审无法把某个解的违反项追溯到题面条款；本域多篇被深读点名摘要与正文数值对不上，正说明缺可审计结构。
- 机制：全局约束编号成法典（每问再编号特殊条款），约束违反度分类与修复算子分层编号且一一对应——模型约束、验收测试与代码修复三者可互相引用、逐项对账。
- 前提/接口：约束清单来自题面逐条款登记并闭合；每个修复算子声明其针对的违反类与调用时机；验收表按编号逐项给结果。
- 反例：只编号不接验收测试是装饰；软约束/偏好项没有"违反—修复"二分，强行编号制造假精确；条款理解错时编号系统忠实放大错误。
- 迁移边界：迁移"约束管理从散文变编号系统"的形态；编号方案按新题条款重排，不沿用旧编号。
- 证据：论文深读｜source_checked

### A6 多算法互为基线横评，横评后主动选简并写明理由

- 基线失效：单算法提交无外部参照（同域一篇全文无基线仅自比）；固定选某类分配规则被同题横评直接证伪——不同算例上没有一种规则通吃。
- 机制：多算法（贪心族/邻域搜索/进化族）同实例同口径横评互为基线；横评证据链同时回答两件事——规则类方法何时失效（支撑自适应或演化机制的动机）、最简可行者是谁；最终可主动提交最简单算法并把理由（时限、可复现、基线清晰）写成决策而非妥协。
- 前提/接口：横评共用同一实例集、同一指标口径与同一运行预算；选简理由与横评表同现，缺横评的"选简"只是妥协。
- 反例：口径不一的横评比不横评更误导（本域跨篇同题数值口径矛盾被深读点名）；在未横评的算例上宣称最简即最优不成立。
- 迁移边界：迁移"互为基线 + 选简写成决策"的论证链；算法族、算例集与口径按新题重组，横评结论不跨题引用。
- 证据：论文深读｜source_checked

### A7 数据先行：先画像定优化杠杆，再选算法

- 理论风险（推断，非论文实证——深读记录只载论文做了画像先行，未载不画像的反面对照）：若按算法习惯直接动手（上来就元启发式），优化方向与数据中成本的实际来源脱节——全部算子均匀对待，力气花在不主导成本的环节。
- 机制：先对数据做结构画像（操作类型分布、DAG 的社区/模块化/出入度），识别成本与冲突集中在哪类对象，再决定算法与算子的发力点；画像结论同时进入正文作为建模动机。
- 前提/接口：画像指标可从题给数据直接计算；画像到算法选择的因果链要在正文显式写出，不能只并列贴图。
- 反例：画像与算法选择脱钩（贴了分布图仍均匀使力）时画像沦为装饰；非图结构数据套用 DAG 指标无意义，须换对应形态的画像。
- 迁移边界：迁移"证据决定模型"的顺序（对齐 distilled_modeling 通用链第 2 步）；具体画像指标按新题数据形态选择。
- 证据：论文深读（机制锚点：papers[13].reusable_patterns「Q1 用操作类型分布→优化杠杆的数据先行论证」、papers[15].reusable_patterns「数据先行：Gephi 四指标画像」；失效面无锚点，为推断）｜proposed

### A8 问间对象链工程化交接（前问输出=后问输入，含问间自基线）

- 理论风险（推断，非论文实证——深读记录只载问间交接与自基线做法，未载独立建模被观察到失效）：各问独立建模、前问结论不落盘、后问从头再来时——答案间不一致，后问失去可继承的约束与参照。
- 机制：问题链即对象链（如"航段—执勤—任务环"三层，前问编组直接构成后问输入）；中间结果定义落盘格式供后问读取；后问可把前问解作为约束上界或参照基线（问间自基线），让继承可执行、可审计。
- 前提/接口：每问输出声明 schema（字段/单位/粒度）；下游只通过该接口取数；前问为近似解时须声明继承方式（硬约束/上界/初值）。
- 反例：前问近似解被无声当作精确约束，误差向后传播且不可追溯；格式未定义的文件交接在后问重解析时口径漂移。
- 迁移边界：迁移对象链与接口化交接的形态；具体对象层次与落盘格式按新题问题结构定义。
- 证据：论文深读（机制锚点：papers[10].reusable_patterns「航段—执勤—任务环分层对象」、papers[12].modeling_body_by_q[1].transition（前问解作后问基线）、papers[13].reusable_patterns（结果落盘格式）；失效面无锚点，为推断）｜proposed

### A9 同题多篇深读交叉核对（社区共识参照）

- 基线失效：单篇自报数值不可信——本域同题多篇被深读点名摘要与正文表不符、跨表口径矛盾，评审不能默认任何单篇数字成立。
- 机制：同题存在多篇深读时，先核对各篇指标定义口径，再交叉比对同名指标的报告值，形成社区共识解参照，用于校准我方实现的量级是否落在合理区间。
- 前提/接口：同题有多篇深读覆盖同一问与同一指标；先统一口径再比数；参照值只进验证叙事，不进当前题结果。
- 反例：口径不一致（个别篇定义不同）时数值吻合是巧合、不吻合无法裁决，须回到定义层；共识只是参照不是真值，多篇同源互相沿用时交叉核对给假信心。
- 迁移边界：只迁移"先对口径再对数"的核对动作；仅限有同题多篇深读材料的场合，数值一律不搬运。
- 证据：论文深读（跨篇观察；核对动作本身我方未执行）｜proposed

## 图表组合

按四层证据组织图组：

- **结构层**（问题长什么样）：任务—资源—依赖三元结构图（DAG 拓扑、时序窗、容量形态）；数据画像图（操作类型分布、度分布——A7 的杠杆证据）；问间对象链流程图（哪层对象、经什么接口传给下一问）。
- **机制层**（机制为何这样设计）：精确到降级的决策链示意（降级理由与锚定位置标出）；约束编号与修复/验收编号的对应关系图；贯穿小实例的逐步手算表（读者可复算，见写作重点）。
- **结果层**（结论证据）：多算法同实例横评表（同口径）；小规模精确解与启发式解的对齐表（间隙入列）；规模—耗时曲线（实时性证据）；逐算例前后对比表——恶化算例保留并给归因列。
- **可信边界层**（哪里不可信）：目标权重与关键阈值（连接时间、公平权重）敏感性表；多初值/种子稳定性；退火/进化族的收敛曲线；恶化算例的场景边界声明。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且每处在正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性元素；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 启发式解质量无锚 | 小规模精确解对齐 + 间隙入结果表；不可精确求解时给显式降级理由与可得下界（A1） |
| 约束遗漏/不可行 | 约束编号法典逐项验收：逐约束复算、边界与周期状态检查（A5） |
| 局部最优 | 多初值 + 多算法互为基线横评（A6） |
| 目标权重主观 | 加权目标给业务优先级声明；权重与关键阈值同报敏感性 |
| 假设高估可行性 | 延误、周期边界状态等假设单独验证，不默认成立 |
| 实时性 | 规模—耗时曲线与求解时间预算上限，大小规模分别报 |
| 数值口径混乱 | 摘要与正文表逐一对账；跨表同指标先统一口径再比 |
| 题设滑移 | 每问约束条款与题面对照（编号引用），后问不悄悄改前问口径 |

## 写作重点

- **最优性叙事是本域差异化点**：先精确后降级——精确模型、降级理由、小规模对齐与间隙显式呈现；摘要可主张的是锚定过的解质量，不是无参照的"接近最优"。
- **加权目标写清优先级与口径**：业务优先级、公平口径（最大偏差等）随目标函数声明；固定权重的结论标注不可跨题复用。
- **恶化不粉饰**：逐算例归因并保留场景边界（如能效优先）的解释；被弃用的更差子方案给弃用理由，不占结论位。
- **可复算样例**：统一小实例贯穿约束说明与关键算法手算，读者能逐步复核——比大段算法描述更可信。
- **数字对账**：本域多篇被深读点名摘要与正文数值不符；交稿前摘要关键数与正文表逐一对账。
