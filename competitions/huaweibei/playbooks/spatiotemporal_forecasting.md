# 时空预测域 Playbook

证据锚点约定：**论文方法链提取** = `analysis/lit_survey/huaweibei_2023_methods.md`（2023 年 12 篇优秀论文摘要级提取：每篇读取封面、摘要与目录前 5 页，方法名取论文自述）中 D 题双碳路径 2 篇、F 题降水预报 2 篇，加 `analysis/lit_survey/huaweibei_2024_methods.md`（2024 年 12 篇同口径提取）中 D 题暴雨成灾篇（动作主线取成灾机理篇）；跨题共性观察覆盖两批各 12 篇。**我方实验** = 无（本域未做本地试点，本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域即八类风险之一的"时空预测"（时间、空间和外部条件共同影响未来），优先路线（残差校正、时序模型、图模型、物理基线）与必做验证（时间外/空间外验证、分步长、极端情景）沿用该文件既有约定。本文件条目均未附机制记录 id——证据层级为摘要级方法链提取，尚未做机制复核与 `../cases/mechanism_reviews.json` 入库。

## 触发条件

- 任务落在"未来"：对区域环境或地理量（碳排放路径、降水场、灾害脆弱性等）的未来取值或演化形态做预测，时间、空间与外部条件（政策杠杆、气候背景）共同影响走向。
- 数据形态两类：一是长时序统计年表（年度粒度、样本少、缺测常见，人口-经济-能源-排放类变量）；二是时空立方体（雷达体扫/格点场，按等高面或深度分层，时间片密集），或叠加地形、土地利用等地理信息的栅格/矢量数据。
- 题面常为复合问链：先预测演化（何时达峰、回波怎么走、脆弱性怎么变），再做规划设计（情景与杠杆）或提取条件规则（成灾临界条件）——预测结果是后问规划的输入，不是终点。
- 空间结构参与定义问题：等高面、地形、土地利用、行政分区是建模变量或分层依据，不是背景板；仅时间维但受外部条件驱动的路径预测（碳达峰类）也命中本域。
- 与综合评价域的分界：本题主问是对未来的预测/预报，评价体系只作前置或辅助；与信号诊断域的分界：对象是环境/地理量的时空演化，不是设备状态的故障判别。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面（含同题同伴路线对照）：

1. **变量筛选只走统计相关性**：年表级小样本上 ANOVA/Spearman 类筛选不稳定，且筛出的变量集与后问情景杠杆对不上号——情景要调能效、非化石能源占比时，变量表里没有对应分解位。（2023D 同题两篇对照：一篇统计筛选建指标体系，一篇恒等式先验筛选，后者的体系直接对接情景杠杆）
2. **组合预测等权或简单平均**：成员精度差异被抹平，低精度成员等权拖累组合结果，且"为什么这样组合"无从论证。（2023D 高手动作"组合权重不用简单平均"的反面）
3. **情景组不经推算直接设定**：不先跑自然情景定锚，情景之间无共同参照，"距目标还差多少干预"无从量化；情景只给结果数字不给杠杆参数，路径建议不可操作。（2023D 反向设计动作的反面）
4. **大一统模型混训全部空间层**：不同等高面的回波形态与动力过程差异被平均，层间结构信息稀释，融合权重也无从安放。（2023F 分层训练+加权融合动作的反面）
5. **预报模糊不处置或盲堆模块**：逐点误差训练使预报场趋向均值化，强回波被平滑掉；堆注意力/GAN/残差模块却不指认每个模块针对的病灶，改进无从归因。（2023F 两篇均以"模糊效应"为模块设计起点）
6. **黑盒模型只报指标**：题目问"什么条件下暴雨成灾"，只报准确率或特征重要性答不了条件问题，可读的临界条件组合才是交付物。（2024D 白盒化动作的反面）
7. **物理与数据二选一**：纯深度学习无独立对照，误差无法归因、外推无依据；纯物理关系在复杂相态、复杂地形处失效时无从修正。（2023F/2024D 双轨动作的反面）
8. **评分只报 RMSE 或口径不一**：降水预报的稀疏事件结构下 RMSE 被无雨区主导，看不出事件命中能力；CSI/ETS 族指数随阈值、分级、时窗变化，跨方案不统一口径不可比。（2023F 领域指数体系动作的反面）

### 补充：跨域借鉴（2024-E 高速公路应急车道，时空决策分支）

- 交通流三参数建模后再判级：视频计数先换算成速度/流量/密度三参数并归一化，用经典速度-密度模型（Greenberg 类）做预测，再以速度/密度双阈值判拥堵分级——基线失效：直接对原始计数设经验阈值判拥堵，不经三参数交通流关系换算，判级随观测口径与密度水平漂移（同一速度阈值在疏密交通下含义不同）。证据：2024-E 优秀论文方法链提取（`analysis/lit_survey/huaweibei_2024_methods.md`，2 篇）。
- 启用决策三件套：阈值由数据分布经最大似然估计导出（不拍脑袋）、决策依据整理成"依据×紧急情形"规则体系（算法只负责量化阈值）、启用前后用多指标对照量化收益——基线失效：阈值经验拍定则启用时机无凭据；只报单一收益指标或无前后对照，"启用有用"的主张不可信。证据：同上（2 篇）。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面锚定提取记录中论文自述的动机、同题同伴路线对照或跨题共性观察；提取为摘要级，机制细节以提取字段为准，我方未复算。

### A1 结构恒等式作变量筛选先验（Kaya 型）

- 基线失效：纯统计筛选（2023D 同题同伴路线：单因素 ANOVA + Spearman 相关性筛选）只对数据相关性负责——年表小样本上筛出的变量集既不保证覆盖驱动因子的物理结构，也接不住后问情景杠杆，情景要调的量在变量表里找不到分解位。
- 机制：先把目标量写成恒等式分解（如碳排放按人口、人均产出、能源强度、能源碳强度四因子分解），再在分解框架内筛变量——每个入选变量在恒等式中有明确位置，指标体系与情景杠杆天然对齐；统计检验降为辅助证据。
- 前提/接口：目标量存在可写出的结构分解式（能源-排放类、平衡/守恒类）；分解式先于筛选进入指标体系；输出体系直接供预测建模与情景设计继承。
- 反例：目标量无干净分解式时硬套恒等式会引入错误约束；分解因子间高度共线（年表小样本常态）时恒等式不解决共线本身，须配正则化（如岭回归配岭迹图定参）。
- 迁移边界：迁移"先找结构分解、再在结构内筛变量"的顺序；具体恒等式按新题领域换（能源-排放、水-能源-粮食纽带等），变量与杠杆的映射按新题重推。
- 证据：论文方法链提取（2023D 两篇对照）｜source_checked

### A2 组合预测权重按精度最优求解

- 基线失效：多模型组合用简单平均或等权，成员精度差异被抹平——低精度成员与高精度成员同权，组合可能被差成员拖累，且权重无论证地位。
- 机制：把组合权重当决策变量、组合精度最优为目标函数，用群智能优化（PSO）求解——权重从约定变成解；与岭迹图定参同属"参数由证据驱动而非拍定"家族。
- 前提/接口：先备好误差来源不同的预测成员（线性/灰色/ARIMA/LSTM 异族），成员各自先验证；权重在留出验证口径上优化，防权重过拟合；组合权重与成员贡献表进正文。
- 反例：成员高度同质（同族模型换超参）时优化权重收益趋零；在训练集上优化权重则泄漏、组合精度虚高；样本极少的年表上权重极易过拟合，验证口径必须独立。
- 迁移边界：迁移"权重是优化解而非约定"的思想；优化器与目标函数按新题选，对齐 distilled_modeling"集成需给成员贡献、组合权重、消融"的既有要求。
- 证据：论文方法链提取（2023D）｜source_checked

### A3 情景组由自然情景反推 + 政策杠杆显式参数化

- 基线失效：情景组不经推算直接设定——不知道"政策延续"轨迹落在哪，情景间无共同锚点，"距目标差多少干预"无从量化；情景只给数字不给杠杆，写不出"哪个杠杆动多少"的可操作路径。
- 机制：先跑自然情景（政策延续）得到基准轨迹与关键节点（如碳达峰时间），以此为锚反推设计情景组（基准/雄心/滞后等）；每个情景由杠杆取值（能效提升幅度、非化石能源占比）显式参数化，情景差异即杠杆差异。
- 前提/接口：自然情景模型先行且已验证；杠杆参数与指标体系对齐（杠杆可调当且仅当变量表有对应位）；情景表按"情景名-杠杆取值-目标量轨迹"三联交付。
- 反例：杠杆取值超出历史数据覆盖范围过多时，情景轨迹是外推不是预测，可信度须单独声明；情景多而锚点单一时差异讲不出机制故事，反成凑数。
- 迁移边界：迁移"自然情景定锚 → 情景组围绕锚点反推 → 杠杆显式参数化"的结构；锚点量、杠杆清单、情景数按新题目标与数据重定。
- 证据：论文方法链提取（2023D 两篇）｜source_checked

### A4 按空间分层分别训练 + 加权融合

- 基线失效：单模型把全部等高面混在一起训练——不同高度层回波形态与动力过程差异大，大一统模型平均了层间结构，层内模式被稀释；且层间融合权重无处安放。
- 机制：按空间结构分层（等高面/深度层/区域），每层独立训练（层间可用不同架构，如 U-Net 与 ConvLSTM 并用），再按层精度/贡献加权融合——分而治之保层内模式，融合收全局精度。
- 前提/接口：数据有明确分层结构且每层样本量足够独立训练；各层在统一验证口径上评估；融合权重在验证口径上标定并报告。
- 反例：层间样本量悬殊时小样本层独立训练过拟合更重，融合反引入噪声；层数多而每层数据薄时分层不可行，应退回大一统加层指示特征。
- 迁移边界：迁移"按空间结构分层建模、层内异构、层间加权"的结构；分层依据与融合权重按新题数据形态重定。
- 证据：论文方法链提取（2023F 两篇）｜source_checked

### A5 病灶驱动的模糊效应缓解（逐模块消融）

- 基线失效：ConvLSTM/U-Net 类模型以逐点误差直接训练，在降水场这种演化多模态的目标上输出趋向均值——预报场模糊、强回波被平滑；两篇论文均把"模糊效应"列为改进模块针对的具体病灶。
- 机制：先指认病灶再上模块，模块与病灶一一对应——GAN 数据增强扩充罕见强降水形态、注意力（CBAM 类）聚焦空间-通道关键区、差值/残差模块约束输出与输入的差分结构；模块贡献以去模块消融验证。
- 前提/接口：病灶先有可视化证据（预报场与真值场的模糊对比图）再谈改进；模块逐个加入、逐个消融；评估配事件命中指数族而非只 RMSE。
- 反例：不指认病灶的模块堆叠（注意力+GAN+残差一次全上）无法归因各模块贡献；GAN 增强样本分布偏移过大时反而教坏模型；病灶不存在的题上这些模块全是负资产。
- 迁移边界：迁移"病灶证据 → 针对性模块 → 逐模块消融"的顺序；具体模块按新题病灶选配，不整包照搬。
- 证据：论文方法链提取（2023F 两篇）｜source_checked

### A6 树模型分裂阈值翻译成可读规则

- 基线失效：决策树/XGBoost 只报准确率或特征重要性，题目问的"什么条件下成灾"无从作答——黑盒指标回答不了条件问题，可读的临界条件组合才是交付物。
- 机制：把树模型分裂阈值沿路径翻译成"若某地形条件且某气候条件则高危"式的条件组合规则；规则方向再用气象物理定律（如 Clausius-Clapeyron 升温-持水关系）交叉解释，物理解释与数据验证双轨互证。
- 前提/接口：特征有明确物理含义与量纲（阈值才可读）；树深受控防规则爆炸；规则表回代数据验证，每条报支持样本数与命中精度。
- 反例：特征未做物理编码时阈值只是数字不可读；树过深时规则条数爆炸、单条支持样本过少，规则失去统计地位；阈值跨数据集不稳健，须报阈值敏感性。
- 迁移边界：迁移"模型输出 → 可读条件规则 → 物理定律解释交叉"的白盒化结构；规则粒度与解释所用的定律按新题领域换。
- 证据：论文方法链提取（2024D）｜source_checked

### A7 物理机理与数据驱动双轨并行对照

- 基线失效：只用一种——纯深度学习预报/估测无独立对照，误差无法归因（数据问题还是模型问题），外推无依据；纯物理关系（Z-R 关系类定量估测、热力学关系）在复杂相态、复杂地形处失效时无从修正，自身精度也无从验证。
- 机制：物理轨（双偏振雷达变量 → 雨滴谱反演 → 相态判别 → Z-R 关系定量降水估测；Clausius-Clapeyron 关系解释极端降水随升温的变化）与数据轨（深度学习估测/预报、树模型结论）同题并行、互为对照——物理轨给数据轨独立参照与解释方向，数据轨给物理轨修正证据与适用范围。
- 前提/接口：物理关系可由题给或领域参数落地计算；两轨在同一数据、同一指标口径上对比；两轨分歧大的样本单独取出分析，是误差归因的富矿。
- 反例：物理关系参数不适用本题条件（Z-R 类关系系数随气候区与雨型变化）时对照基准本身错；两轨只在总量层面一致、空间分布分歧大时"一致"结论不成立，须逐点/逐区对照。
- 迁移边界：迁移"双轨并行、同口径对照、分歧归因"的结构；具体物理关系按新题领域换。
- 证据：论文方法链提取（2023F/2024D）｜source_checked

## 图表组合

按四层证据组织图组：

- **结构层**（问题长什么样）：时空数据形态全景（时序长度 × 空间分层 × 变量清单的对账表，含缺测与插值口径）；目标量的时间演化图（趋势与变化点）与空间分布/格局图（等高面回波形态、区域差异、土地利用离散方向），样本设计选择（如弱回波过滤）在此声明口径。
- **机制层**（机制为何这样设计）：恒等式分解结构图（变量位置与杠杆映射）；情景设计示意图（自然轨迹锚点 + 各情景杠杆参数）；分层训练-融合架构图（层内模型与融合权重位）；病灶-模块对应表（病灶证据 → 模块 → 消融增量成列）。
- **结果层**（结论证据）：双轨同口径对照表（物理轨 vs 数据轨，逐区域/逐事件）；组合预测成员贡献与权重表；情景路径轨迹图（各情景目标量轨迹与关键节点标记）；可读规则表（条件组合 + 支持样本数 + 命中精度）；分步长/分区域误差分层表。
- **可信边界层**（哪里不可信）：时间外/空间外划分下的域内 vs 外推误差对比；分步长误差曲线（预测时长增长时的退化）；杠杆超出历史覆盖范围的情景外推段单独标注；融合权重、树深、过滤阈值等关键参数敏感性。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性边框/背景色块；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 时空外推 | 时间外/空间外独立划分评估，域内精度不代言外推能力；外推段误差单列 |
| 分步长退化 | 逐预测时长报误差曲线，不只用整段汇总指标 |
| 组合权重过拟合 | 权重在独立验证口径上优化；等权 vs 优化权重对照入表（A2） |
| 模块无实效 | 病灶证据先行 + 逐模块去留消融，无增量如实报告（A5） |
| 规则不稳 | 规则回代覆盖率与命中精度 + 阈值敏感性（A6） |
| 物理对照失效 | 物理关系参数适用性先行声明；两轨分歧样本单独分析（A7） |
| 评分口径 | 事件命中指数族 + 跨方案统一口径再比较；样本过滤阈值与评分口径联动声明 |
| 情景外推 | 杠杆超出历史覆盖范围的外推段单独标注可信度，不与域内预测混报（A3） |
| 分层融合代价 | 分层 vs 大一统同口径对照入表，层样本量与融合权重一并报（A4） |

## 写作重点

- **三段接口叙事**：变量从哪来（结构先验筛选）→ 怎么预测（组合/分层/双轨）→ 预测拿来干什么（情景规划/条件规则）——每段显式继承前段输出，问链不被写成各自独立的小作文。
- **情景写法**：先给自然轨迹锚点再展开情景组；每个情景写杠杆参数而非只写结果数字；"距目标差多少"由锚点量化给出。
- **失效先行**：改进模块（模糊缓解、注意力、增强）之前先放病灶证据图；没有失效证据的模块不进摘要。
- **双轨写分歧**：物理轨与数据轨的分歧点分析比"两轨一致"更有信息量，分歧样本的归因是加分项。
- **白盒化交付**：规则表带支持样本数与物理含义，阈值可读可复算；黑盒指标不进结论句。
- **口径纪律**：评分指数族注明阈值/分级/时窗口径；跨方案、跨来源数值先统一口径再比；摘要关键数与正文表逐一对账。
- **预测与规划分账**：预测精度主张限定在数据覆盖域内；情景轨迹属于外推推演，两类的可信度表述分开，不用预测指标为情景背书。

舍弃记录：任务候选池七条全部入库（A1-A7），无候选被裁；另有提取池四项不单列——"固定反射率阈值过滤弱降水样本"属样本设计选择，提取层只见选择未见失效对照，并入验证设计评分口径行与图表组合结构层；"双偏振变量 → 雨滴谱反演 → 相态判别"物理链为 A7 物理轨内部构件，双偏振数据形态过窄不具独立迁移面；"熵值法脆弱性指数 + ARIMA/SVR 预测"为评价与时序预测的常规组合，提取层无基线失效对照；"标准差椭圆分析土地利用"为地学空间描述动作，无失效对照，并入结构层空间格局图叙述。
