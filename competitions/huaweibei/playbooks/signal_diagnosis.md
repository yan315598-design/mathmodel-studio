# 信号诊断域 Playbook

证据锚点约定：**论文深读** = `papers/manual_paper_reviews.json` 信号诊断域 3 篇（`papers[26]`–`papers[28]`，2025 E 题，域级索引入口 `papers/domain_index.md`）；优秀论文 vs 我方工作区的对照差距归纳为内部审计产物，分发版不含。**我方实验第 N 轮** = E 题五轮 A/B 对比报告为内部审计产物，分发版不含，已固化结论经 **机制记录** = `../cases/mechanism_reviews.json` 入库（已入库条目附 id）。风险语言对齐 `../distilled_modeling.md`：本域为八类外新增域，近邻风险是高维预测的类别不平衡与数据泄漏、时空外推的工况外推。

## 触发条件

- 对象为旋转/往复机械的振动、声学、电流等高采样率时序信号，任务是故障类型判别或故障元件定位（内圈/外圈/滚动体/保持架等）。
- 存在域差：源域（台架或公开数据集，有标签）与目标域（实车/实测，无标签或极少标签）在采样率、转速、载荷、测点上不一致；或题面明示变转速、变工况。
- 数据形态：文件级长时序切片；类别不均衡（个别故障类仅个位数文件）；题面常留"源域可选用其他公开数据集"之类改变问题难度的权利口子。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

1. **零预测类退化被忽略**：少数类（N 类仅 4 文件）学习失败后最终标定零输出，两侧都如实"披露"却照常交付，与论文共识（共识含 5 个 N）系统性偏离。（我方实验第三轮）
2. **对齐度量好不等于诊断正确**：MMD/A-distance 改善显著，逐文件标签与论文共识一致率仍极低；对齐证据只证明分布靠近，不证明标签正确。（我方实验第三轮）
3. **工作/数据目录确认缺失**：写作轮首个 agent 误入对照工作区，对他人产物做了审计而己方零产出；目录确认必须写进派发协议。（我方实验第四轮）
4. **负面结果不敢写、不会处置**：差距不在诚实而在机制——事后给理由留终审，不如事先登记失效触发条件、命中即切预案并联动修正下游前提；零增量结果本身是可交付证据。（我方实验第二、三轮）
5. **题面权利口子被放过**：题面明示源域可选其他公开数据集，两侧默认用题给源域、在模型层补偿转速差；红队驳回换源域的理由（避免分布漂移）在同转速数据面前不成立。（论文深读，含我方行为反例）
6. **数据筛选有规则无论证**：筛选按规则执行（剔采样率/点位）但不给面向下游任务的定量依据（对目标域分布距离、SNR、共振带）。（论文深读，对照我方差距）
7. **降噪前提未先验证**：题面明示源域有噪声，却直接进特征提取，不先回答"原始信号够不够用"。（论文深读）
8. **切片级划分泄漏虚高**：同文件切片跨训练/测试集，指标虚高约三个百分点（文件级划分对照实测）。（我方实验第二轮）

### 补充：跨域借鉴（2022-A 移动场景超分辨定位）

- 相干源 DOA 算法先横评后选型：把四种解相干算法（空间平滑、ESPRIT 类、Toeplitz 矩阵重构类）拉到同一 RMSE 口径按场景与信噪比比武，再按工况择优——基线失效：单一子空间类算法在相干信源下协方差秩亏、低信噪比下退化，且各算法失效域不同，单一选型横跨不了全部工况。证据：2022-A 优秀论文方法链提取（提取过程记录为内部审计产物，分发版不含；A 题前 2 篇中 1 篇经核为异常归档，有效样本 1 篇）。
- 阵列退化的结构性鲁棒：对天线阵元老化做子阵分解 + 滑窗类平均的结构性处置，而非只做加噪声鲁棒实验——基线失效：阵元老化使整阵流形失配、DOA 估计系统性漂移，"加噪声重跑"式的鲁棒检验不针对这类结构性退化。证据：同上（有效样本 1 篇）。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。

### A1 同工况公开数据集换源域

- 基线失效：两侧默认题给源域，最大技术难点（源目标三倍转速差）只能在模型层补偿，比数据层解决弱；我方红队驳回该选项的理由在同转速数据面前不成立。（论文深读）
- 机制：把源域换成与目标域同转速/同量级的公开数据集，配下采样对齐采样率，在数据层直接消掉转速错位，域适应负担骤减。
- 前提/接口：题面明示允许（审题门"权利查"逐条登记用或不用+理由）；换库须标出处并复核转速、采样率、标签语义与本题对齐。
- 反例：公开库与目标域只是名义同转速但载荷/传感器位置差异大时，换源域不解决域差；标签语义对不上（故障定义不同）会引入系统性错标。
- 迁移边界：迁移"先在数据层消难点、再到模型层"的决策顺序；具体数据集、转速、下采样率按新题重新确认。
- 证据：论文深读｜source_checked

### A2 面向下游任务的定量域筛选

- 基线失效：我方筛选是规则清单（剔除某采样率/某点位通道），有执行无论证，评审看不出每步筛选对结果的作用。（论文深读，对照我方差距）
- 机制：每个筛选决策都对准"缩小与目标域分布差"给定量依据——采样率按奈奎斯特/共振带覆盖论证，测点/通道按对目标域的分布距离（如 MMD）选小者，点位组合按包络谱残差 SNR 定。
- 前提/接口：目标域可计算同口径统计量（谱、分布距离）；每步筛选产出"候选对比 → 依据 → 决定"的可追溯记录。
- 反例：只按源域信噪比或数据量筛，与目标域无关的依据不构成论证；筛掉的通道若恰含目标域关键频带，下游机理核验会暴露缺失。
- 迁移边界：迁移"筛选准则必须面向下游任务给定量依据"的义务形态；具体度量（MMD/SNR/带宽）按新题数据形态选择。
- 证据：论文深读｜source_checked

### A3 两阶段降噪证据链（失效→部分有效→闭环）

- 基线失效：强噪声下传统包络谱只见微弱倍频、冲击特征被淹没；单阶段模态分解有模态混叠与端点效应，恢复不彻底。（论文深读；题面明示源域有噪声时优先评估）
- 机制：先量化失效证据，再上一阶分解重构（模态分离）+ 二阶自适应寻优解卷积（冲击增强），最后用特征频率及谐波在同一口径包络谱上闭环验证；两模块职责不同，参数由寻优目标函数驱动而非人工设定。
- 前提/接口：原始时域信号进、重构信号出；故障为冲击型且存在可识别特征频率；输出接同口径包络谱闭环验证。
- 反例：轻噪声数据上两阶段可能过度平滑真实冲击（本题源域仅"轻微噪声"时须先证失效再上机制）；渐发磨损类无特征频率不适用；寻优目标选错会收敛到虚假周期。来源论文附录代码与正文多处不一致，机制未独立复核。
- 迁移边界：只迁移"失效→修复→闭环"的论证顺序与自适应寻参思想；信号类型、噪声水平、特征频率、任何参数与代码均按新题重定。
- 证据：论文深读｜source_checked｜机制记录 huaweibei_2025_E_two_stage_denoising

### A4 转频归一化 / 阶次谱对齐

- 基线失效：源目标转速不同导致特征频率在绝对频率轴系统性错位，绝对频率路线机理核验近乎全败（0/9），直接迁移失效。（我方实验第三轮 baseline，R0/R1 消融）
- 机制：包络谱按频率/转频插值到阶次轴，特征频率在两域对齐到同一阶次（阶次=每转冲击次数是转速不变量），把转速差从模型负担变成输入表示的几何对齐。
- 前提/接口：转速已知或可估（名义值+副口径复核）；时域切片+转速 → 包络谱 → 阶次插值 → 特征向量进诊断/迁移模型；目标域近似恒转速。
- 反例：转速估计错则全轴错位；变转速段内插值会涂抹谱峰；渐变磨损类不适用。且阶次对齐改善机理核验，不自动改善标签正确率（我方主路线与论文共识一致率仍低）。
- 迁移边界：迁移"表示层对齐优于模型层硬扛"的思想；阶次范围、插值点数、谐波族设计按新题重定。
- 证据：双向（我方 R0/R1 消融为主，论文深读确认转速差为首要难点）｜locally_tested｜机制记录 huaweibei_2025_E_order_spectrum_alignment

### A5 包络谱 + 理论特征频率机理核验

- 基线失效：单模型输出不可证伪，softmax 置信不等于真实正确率（我方实验第三轮）；数据筛选缺独立物证通道（论文深读）。
- 机制：由轴承几何参数与转速算理论特征频率及其倍频族，在包络谱上核验峰位匹配，形成独立于模型的物证证据通道；可用于筛选点位（残差 SNR）、排序候选路线、交叉核验模型标签。
- 前提/接口：轴承几何参数与转速已知或可查；判据先在源域标定强弱，再用于目标域；输出为逐文件机理证据（匹配阶次、一致/冲突标记）。
- 反例：判据弱时（我方源域标定准确率不足七成）只能降级为定性证据，不能裁决标签；跨域物理判据可能大面积失败（0/9 降级）；机理与模型强冲突时若无裁决规则，冲突只能标注不能解决。
- 迁移边界：迁移"模型之外保留物证通道"的结构；判据阈值、谐波族设计按新题源域重新标定。
- 证据：双向（我方实验第三轮两侧机理核验器实跑 + 论文深读）｜locally_tested

### A6 多方法族投票 + 置信分层

- 基线失效：目标域无真值时单模型直迁输出无法验证、无法交付"不能同等确信"的事实。（我方实验第三轮）
- 机制：多个方法族（直迁/对齐变换/域对抗/机理规则等错误来源不同的路线）同口径平行跑，文件级标签 2/3 多数投票，按证据项数分层交付（high/medium/suspect），机理强冲突文件单列。
- 前提/接口：各方法族错误不完全相关；机理判据先标定强弱；标签空间闭合；分层结果写进标签文件字段供下游引用。
- 反例：方法族共享同一错误前提时集体投错——我方两侧均零 N 输出，投票无法恢复从未学到的类；与论文共识一致率极低（1/16），证明该机制能暴露不确定性、不能保证标签正确。
- 迁移边界：迁移"无真值下多证据分层交付"的结构；投票阈值、分层阈值、机理判据按新题重新标定；不能替代真值验证。
- 证据：我方实验｜locally_tested｜机制记录 huaweibei_2025_E_unlabeled_voting_calibration

### A7 文件级划分防泄漏

- 基线失效：切片级划分让同文件切片跨训练/测试集，指标虚高约三个百分点（我方双口径对照实测）。（我方实验第二轮）
- 机制：按原始文件划分训练/测试（文件是物理独立的采集单元），并做切片级 vs 文件级双口径对照，量化泄漏虚高幅度作为可信边界证据。
- 前提/接口：数据以文件为采集单元、文件级标签可得；对照两口径同模型同超参，差值写入结果表。
- 反例：文件内混合工况（同文件含多状态段）时文件级划分仍不彻底，需配合文件级标定+切片投票一致性检查；文件数极少时留一文件交叉代价高，须报样本量。
- 迁移边界：迁移"划分单元=物理采集单元+双口径对照"的纪律；划分粒度按新题数据组织形式重定。
- 证据：我方实验（第二轮）｜locally_tested

### A8 少数类零预测阻断（含代价敏感前置）

- 基线失效：个别类样本极少（N 类 4 文件）时训练后该类学习失败、最终标定零输出，两侧仅披露未阻断照常交付，与论文共识系统性偏离。（我方实验第三轮）
- 机制：输出层逐类预测计数硬检查，任一合法类零预测即触发复核（类权重/重采样重训、阈值调整或降级交付口径并写入局限）；评估用宏平均口径只是观测，不是修复。
- 前提/接口：合法类清单来自题面且闭合；计数检查挂在标定出口处，阻断结果与处置动作登记进台账。
- 反例：我方两侧已用 per-class 口径评估仍零 N——只换评估口径无效；类清单本身漏类（真实存在但题面未列）时阻断失效；代价敏感重训在我方实验中未验证生效。
- 迁移边界：迁移"退化输出必须阻断而非仅披露"的纪律；重平衡手段与复核流程按新题验证后采用。
- 证据：我方实验（第三轮失效面实证；阻断与代价敏感修复面未验证）｜proposed

## 图表组合

按四层证据组织图组，复用"失效→部分有效→闭环"三图链思想（机制层核心）：

- **结构层**（问题长什么样）：源/目标域形态对照（采样率、转速、点位、类别计数的表或图）；原始信号时域+频谱全景，标出域差与噪声水平所在频带。
- **机制层**（机制为何这样设计）：三图链——同口径包络谱下依次给"基线方法失效（噪声淹没、仅微弱倍频）→ 单阶段部分有效 → 完整机制闭环（特征频率及谐波齐出）"；降噪/对齐/筛选的每个机制决策配一张依据图（对目标域分布距离对比、残差 SNR 对比）。
- **结果层**（结论证据）：横向对照表（含失败路线与处置角色）；目标域逐文件物证图（原始 vs 处理后 + 包络谱并排，每个标定文件给证）；混淆矩阵与方法族一致率矩阵。
- **可信边界层**（哪里不可信）：切片级 vs 文件级双口径泄漏对照；置信分层分布与机理-模型冲突文件清单；窗长/转速/种子灵敏度（如短窗因频率分辨率不足失效的反例）。

**图内标注纪律**（数据图 Type 3 强制）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性元素；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 切片泄漏 | 文件级划分 + 切片/文件双口径对照，量化虚高幅度入结果表 |
| 对齐度量误导 | 目标域留出口径证据（机理一致率、分层稳定度）为准；MMD/A-distance 只作过程证据，不进正确性主张 |
| 零预测退化 | 标定出口逐类预测计数硬检查，零预测类触发复核并有处置记录 |
| 机制无实效 | 每个引入模块先证基线失效，再配去模块消融；无增量如实报告（有零增量合法交付先例） |
| 机理判据失效 | 判据先在源域标定强弱；弱判据降级为定性证据并写入局限 |
| 转速口径 | 名义转速 + 副口径双跑对照，报敏感度 |
| 工况外推 | 目标域独立评估，不用源域指标代言；域内改善与跨域改善分开报 |

## 写作重点

- **机理核验叙事**：数据筛选、降噪、对齐的每个决策写成面向下游任务的定量论证链，不是规则清单；摘要不因对齐度量改善而声称标签正确。
- **负面结果写法**：失败路线与零增量结果进正文与对照表并给处置角色；预登记触发条件命中即执行的处置留痕（含模型族变更对下游前提的联动修正），比事后辩护更可信。
- **无真值交付**：分层标签交付，suspect 文件逐条给具体弱证据；少数类零输出"不能排除漏检"须进摘要；未完成的问不作宣称。
- **数字对账**：一致性检查工具不校验数字转录（我方一稿数字转录错误全部漏网），摘要与正文关键数字须与结果文件逐一对账后再交稿。
