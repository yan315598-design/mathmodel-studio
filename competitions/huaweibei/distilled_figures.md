# 研究生赛图表逻辑

## 版面与图量（候选版）

研究生赛版面远宽于短赛制竞赛：190 篇样本文档页数中位约 61 页（E 题方向中位约 69 页）；图表检出数中位约 29、上四分位约 43（empirical.json, analysis_only 口径，**仅作参照不设门槛**）。

含义：
- 每问的图表按"四层证据"覆盖——结构、机制、结果、可信边界四种证据角色都要有落点（可以是一张复合多面板图承载多角色）；某角色不适用要说明理由，不是省略。
- 目标域/测试集逐样本或逐情景的物证图组（如 16 个目标文件逐个四联图）在版面充裕时优先做，它把模型输出落到物理证据上。
- 不按独立图张数考核：评审看每种证据角色是否有论证、每张图是否支撑唯一主张。图多但每张无论证价值同样是负分。

## 四层证据

### 1. 结构图

回答“对象如何连接”：坐标、流程、网络、状态、子问接口和数据源。

必须包含：输入、输出、中间量、方向、约束边界。结构图不承担性能结论。

### 2. 机制图

回答“为什么模型合理”：相关矩阵、奇异值谱、波形、状态轨迹、因素交互、资源占用、视域序列或空间权重。

正文写三件事：可见模式、对应模型选择、不能推出的因果或外推结论。

### 3. 结果图表

回答“题问得到了什么”：预测—实测、优化方案、混淆矩阵、排班表、路径、三维重构或 Pareto 前沿。

所有结果须带基线、单位、统计口径和约束；优化题同时报代价与余量，预测题同时报分层误差。

### 4. 可信边界图

回答“什么时候会失败”：残差、收敛、敏感性、校准、最优点邻域、压力情景、空间误差和失败案例。

没有这一层，论文只有展示，没有证据闭环。

## 图表卡片

为每张图表记录：

```text
唯一主张：
上游数据/变量：
选择此图而非其他图的原因：
正文出现位置：
读者应看到的模式：
不能推出的结论：
```

### 图内标注纪律

对齐优秀论文/期刊惯例，数据图**图内不放图名与结论文字，图名和结论写进图下方 caption**（“图 X：…”由 LaTeX/Word 排版）：保留轴标签（含单位）、刻度、图例与多面板标号 (a)(b)(c)；不放图题（suptitle / 单面板 set_title）、结论句与大段说明。多面板 panel 允许 ≤6 个中文字符当量的轴含义短标签（如 ROC/PR/残差），超出移入 caption。技术路线图/流程图/框架图等示意图豁免（标题条是版式组成部分）：figqa 走 `--allow-box-labels`，该参数只豁免示意图盒内文字、不关闭 figure_lint R8；若示意图仍被 figure_lint R8 检出（如 matplotlib 直出示意图），用 `--allow-infigure-title` 逃生门跳过。与 `playbooks/README.md` 的"图内标注纪律"同口径。

## 常见组合

### 机制引入题的论证链（失效→修复→闭环）

引入降噪/增强/修正类机制时，图组按论证推进组织，不是结果陈列：

1. **失效图**：简单基线在原始数据上的量化失效（如强噪声下包络谱只见微弱倍频）——回答"为什么非要这个机制"。
2. **部分有效图**：机制的初步效果与残留缺口（如一阶分解后倍频部分恢复）——回答"机制做了什么、还差什么"。
3. **闭环图**：机制补全后的决定性证据（如特征频率及其谐波全部显著）——回答"缺口确实被补上"。

三张图共享同一数据与口径，缺第一张图机制必要性不成立，缺第三张图有效性不成立。适用：信号处理、图像增强、误差修正、任何"在基线上加机制"的场合。

### 预测题

数据分布 -> 时间/空间机制 -> 预测对照 -> 残差/校准 -> 极端案例。

### 优化题

对象网络 -> 状态/资源甘特图 -> 方案表 -> 基线/Pareto -> 约束余量与敏感性。

### 动力与仿真题

等效结构 -> 状态轨迹/相图 -> 参数热图 -> 最优/稳定区 -> 步长和扰动收敛。

### 高维学习题

特征漏斗 -> 相关/嵌入 -> 预测/分类 -> 特征贡献 -> 适用域和校准。

### 空间与三维题

地图/坐标 -> 路径或视域 -> 三维/网络结果 -> 空间残差 -> 多尺度或匹配概率。

## 表格优先情形

- 需要读出准确方案、参数、单位、置信区间和约束余量。
- 需要横向比较多模型、多场景、多指标。
- 需要逐问验收题面要求。

图优先展示关系、过程、分布和空间；表优先展示精确结果。不要把同一数据重复画图又制表，除非二者承担不同判断。

## 图后解释句式

```text
图中[可见模式]表明[中间判断]，因此采用/保留[模型动作]；
该结论仅在[数据范围/工况]内成立，[风险]仍由[后续验证]检查。
```

禁止只写“由图可知模型效果较好”。
