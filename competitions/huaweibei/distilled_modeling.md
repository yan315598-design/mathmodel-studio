# 研究生赛建模蒸馏

## 先分类风险，再选模型

研究生赛 A-F 题号不对应固定题型。先识别主要风险：

| 风险类型 | 真正问题 | 优先路线 | 必做验证 |
|---|---|---|---|
| 计算与存储 | 精度门槛下减少算子、位宽、搬运或存储 | 低秩、稀疏、近似分解、共享中间量、复杂度优化 | 逐算子账本、最差精度、运行时间、消融 |
| 时空预测 | 时间、空间和外部条件共同影响未来 | 残差校正、时序模型、图模型、物理基线 | 时间外/空间外验证、分步长、极端情景 |
| 动力系统 | 状态演化和干预机制 | 微分方程、状态空间、仿真、控制优化 | 守恒、步长收敛、参数扰动、经典特例 |
| 调度优化 | 依赖、容量、资格和时序共同限制 | MILP/网络流/动态规划、分层启发式 | 逐约束验收、小规模最优、最优间隙、实时性 |
| 高维预测 | 特征多、样本有限、类别不平衡 | 嵌套特征筛选、树/核/集成、概率校准 | 分组验证、泄漏审计、校准、适用域 |
| 多源融合 | 设备/站点/尺度/语义不同 | 坐标对齐、分层权重、图模型、教师—学生校准 | 留站/留源、分辨率边界、消融、不确定性 |
| 空间几何 | 路径、视域、网络、三维关系 | 图论、可见性、几何反演、空间统计 | 坐标变换、多尺度、几何特例、人工典型点 |
| 综合评价 | 多指标、权重和排序 | 指标构造、客观/主观权重、聚类/Pareto | 权重敏感性、等级稳定性、外部一致性 |

## 通用建模链

### 1. 题面对象化

把每问写成：

```text
已知数据 D_i
-> 状态/特征 Z_i
-> 模型或决策 M_i
-> 输出 Y_i
-> 验收 V_i
-> 传给下一问 T_i
```

若 `T_i` 为空，检查各问是否被错误地独立建模。

### 2. 数据或机理先验

模型之前至少给一项可观察证据：分布、相关、奇异值谱、时序、拓扑、物理守恒、资源瓶颈或空间结构。证据决定模型，不是模型训练后再找解释。

### 3. 候选路线比较

每问至少比较两类：

- 可解释基线：规则、解析式、线性/整数规划、简单时序、物理公式。
- 主模型：处理主要非线性、耦合或规模问题。
- 必要时的专用修正：只为残差诊断暴露的失败对象增加。

### 4. 中间状态打开

中间量需可画、可表、可验。例如：

- 信号题：谱、残差、稀疏系数、置信度。
- 预测题：分量、时空权重、误差分层、校准概率。
- 优化题：资源占用、库存/缓存状态、约束余量、下界。
- 动力题：状态轨迹、相图、能量/物质平衡、稳定区。
- 空间题：路径、视域、邻接、连通概率、残差地图。

### 5. 求解器与模型分开写

模型说明变量、目标、约束和机制；求解器说明初始化、编码、迭代、停止、可行性修复、随机种子和时间预算。不能用“采用遗传算法”替代模型。

### 6. 验证对应风险

| 主要风险 | 对应验证 |
|---|---|
| 数据泄漏 | 按患者、设备、过程、会话、原始文件或空间块划分 |
| 过拟合 | 嵌套交叉验证、学习曲线、简单基线 |
| 优化不可行 | 逐约束复算、守恒、边界状态 |
| 局部最优 | 多初值、多算法、小实例精确解 |
| 物理失真 | 量纲、守恒、经典特例、参数范围 |
| 时空外推 | 时间外、空间外、工况外和极端事件 |
| 概率误导 | 校准、置信区间、拒识和覆盖率 |
| 分辨率虚高 | 有效分辨率、留站验证、多尺度敏感性 |

## 不同路线的选择规则

### 机理还是数据驱动

- 需要外推、解释和守恒：机理为主，数据模型校准残差。
- 数据量足、关系复杂、只需域内预测：数据模型可主导，但保留物理基线。
- 机理参数不全：灰箱模型，把可知机制写进损失、约束或状态转移。

### 精确优化还是启发式

- 小规模：MILP/CP/DP 给最优解或下界。
- 大规模：分解、滚动、列生成或启发式。
- 最佳实践：小规模精确解校准大规模启发式，逐约束验收而非只比较目标值。

### 单模型还是集成

- 先比较简单基线；只有残差显示不同模型互补时才集成。
- 集成需给成员贡献、组合权重、消融和额外复杂度。
- 针对个别对象的专用模型应条件触发，不把所有模块强行串联。

## 迁移边界

可迁移：问题对象、模型接口、风险—验证配对、图表角色、段落顺序。

不可迁移：历史变量取值、阈值、权重、结果、类别标签、最优参数、结论原句和奖项身份。
