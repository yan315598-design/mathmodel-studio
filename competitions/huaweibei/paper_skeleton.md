# 研究生赛论文骨架

## 摘要

现实缺口 -> 共同数据/机理发现 -> 逐问模型闭环 -> 定量结果与基线 -> 跨问整合 -> 适用边界。

## 1. 问题重述与背景

- 背景：现实后果、现有缺口、本题数据和本文交付。
- 重述：把题面转成输入、输出、约束、评价指标和未知量，不复制长题面。
- 问题关系：用一张图展示子问接口和共用状态。

## 2. 问题分析

每问依次写：

1. 真正困难和主要失效风险。
2. 题面提供的信息能否识别目标。
3. 至少两条候选路线及取舍。
4. 选择路线及其验证计划。
5. 前问输入和后问输出。

## 3. 假设、符号与数据

- 假设：依据—简化—偏差—验证去向。
- 符号：只列正文会复用的量，注明单位、维度、索引和集合。
- 数据：来源、时间空间粒度、缺失异常、划分方式、泄漏防线和单位统一。

## 4. 各子问正文

每问使用同一内部结构：

```text
4.i.1 为什么需要该模型
4.i.2 输入、输出、变量、目标和约束
4.i.3 关键推导或算法
4.i.4 求解设置与可复现信息
4.i.5 中间状态
4.i.6 主结果与现实解释
4.i.7 与主要风险对应的验证
4.i.8 本问回答及传给下一问的量
```

公式前解释对象和机制，公式后解释量纲、计算方式和如何读出结论。

## 5. 全局稳健性

- 参数敏感性；
- 数据、时间、空间或工况外验证；
- 随机算法多种子；
- 约束余量和极端情景；
- 模型、特征、数据源和损失函数消融；
- 不确定性区间和失败案例。

## 6. 结论、评价与推广

### 结论

按题问逐项回答，每项包含结果、条件和现实含义。

### 模型评价

只写正文已经验证的优势和限制，不用“准确性高、适用性广”等无证据套话。

### 推广

说明换数据、地区、设备、尺度或任务时需要重估什么，不能迁移什么，还需什么外部验证。

## 图表顺序

结构图 -> 数据/机制图 -> 中间状态图 -> 主结果表图 -> 可信边界图。图表不按“能画什么”安排，而按论证需要安排。
