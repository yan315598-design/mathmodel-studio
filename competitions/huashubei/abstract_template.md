# 华数杯中文摘要黄金模板（按题型）

> 基于 18 篇优秀论文蒸馏。每条规律带论文页码引用。
> 摘要是华数杯评分第一关，评委 30 秒内定档。国一摘要必须：模型命名 + 定量结果 + 方法链。

---

## 通用要求（三题型共享）

- **必须出现题号对应的核心对象**，不能只写"本文研究该问题"。
- **必须按子问题写方法**，避免模型列表堆砌。
- **必须有定量结果**：没有数值的摘要默认不合格。
- **不夸大**："首次""显著优于"除非正文有对比证据。
- **长度**：A 题 600-900 字，B 题 600-900 字，C 题 550-750 字；国一偏长。

---

## A 题摘要模板（物理工程机理建模）

### 5 段式黄金模板（精确到句子功能）

| 段落 | 功能 | 字数占比 | 句式模板 |
|------|------|----------|----------|
| ①背景段 | 1-2 句：题目背景 + 核心矛盾 + 本文总体方法 | 10-15% | "针对【对象】的【核心矛盾】问题，本文建立了【模型总名】，以【目标】为目标展开研究。" |
| ②问题一 | 方法链（3-5 个动词串联）+ 1 个关键结果 | 25-30% | "针对问题一，首先【方法A】，其次【方法B】，然后【方法C】，最后【算法D】求解。求解结果：【关键数字】。" |
| ③问题二 | 在问题一基础上的"增量"方法 + 关键结果 | 20-25% | "针对问题二，在问题一基础上，引入【新约束/新目标】，建立【新模型名】，通过【算法】求解，结果：【数字】。" |
| ④问题三/四 | 策略/创新点 + 路径/工艺结果 | 25-30% | "针对问题三，提出【自创策略名】，运用【算法】进行路径规划，最优【指标】=【数字】。" |
| ⑤收尾升华（加分） | 方法论高度 + 推广价值 | 5-10% | "本文【方法论总结】，为【领域】提供了【理论支撑/决策依据】。" |

### A 题摘要范例骨架（可套用）

```
针对【物理对象】的【核心矛盾，如"末端误差与能耗冲突"】问题，本文围绕【优化目标】建立了【模型总名，如"六自由度机械臂运动学-能耗双目标优化模型"】。

针对问题一，首先【绘制零位简图】，建立【空间直角坐标系】，采用【改进 D-H 方法】推导【正逆运动学方程】，最后利用【蚁群算法】求解，得到最小末端误差为【11.39mm】，最优坐标为【（146，123.68，30.02）】。

针对问题二，在问题一基础上引入【质心概念简化重力势能】，建立【能耗优化模型】，论证【动能项为定值，故仅需优化势能】，通过【算法】求解，最优能耗为【17.389J】。

针对问题三，提出【基于"可达点"的抓取策略】，运用【A*寻路算法】进行【避障路径规划】，最优路径长度为【XX】，能耗为【XX】。

本文利用【机理与数据双轮驱动/多算法组合】方法，为【机器人路径规划领域】提供了【理论支撑】，整体框架可推广至【其它多自由度系统】。

关键词：【物理对象】；【模型1】；【算法2】；【自创策略名】；【应用领域】
```

## B 题摘要模板（运筹优化）

### 结构：单页满字，方法链总览 + 逐问定量

```
针对【运筹场景，如"VLSI 电路单元自动布局"】问题，本文围绕【优化目标，如"线长最短+密度均匀"】建立了【模型总名】。

针对问题一，将布局抽象为【矩形坐标优化问题】，以【HPWL 半周长线长】为目标，建立【单目标优化模型】，采用【改进模拟退火算法】求解，最小线长为【XX】，较初始布局降低【XX%】。

针对问题二，在问题一基础上引入【布线密度约束】，建立【双目标优化模型】，通过【查找表修正 HPWL 逼近 RSMT，偏差从 30213 降至 117】，采用【Min-Max 标准化代价函数】求解，最优解线长【XX】、最大密度【XX】。

针对问题三/四，提出【Adjusted-HPWL 修正方法】，分析【T 字/十字弯折面积重叠误差】，采用【双算法交叉验证（模拟退火+粒子群，精确度 93.4%/93.3%）】求解。

为验证算法有效性，本文采用【Ackley 标准基准函数】测试，收敛次数【145】优于单一 SA（2370）和 PSO（213）。

关键词：【运筹对象】；【模型名】；【算法名】；【自创指标/策略】；【应用领域】
```

### B 题摘要关键要素

- **必须给决策变量定义**：摘要里点明"以 XX 为决策变量"。
- **必须给优化目标值**：线长、成本、利用率、QoS 等。
- **算法创新点要命名**：SA-PSO、Adjusted-HPWL、迁移适宜度指标。
- **基准验证是加分利器**：Ackley/Rastrigin 函数收敛次数对比。

## C 题摘要模板（数据评价/预测/规划）

### 结构：总—分（按子问题）—总，清洗结果前置

```
【1-2 句】研究背景与意义。【如"维护婴儿成长是社会发展的重要任务"】
【1 句】本文总体方法。【"建立分类模型及优化模型，通过 MATLAB 求解"】

【C 题特色：数据预处理摘要】本文首先对数据进行预处理，【剔除婚姻状况为 3、6 的数据，共剔除 10 个异常样本】，保留有效样本【XX】个。

针对问题一，建立【有序逻辑回归分类模型】，以【身心指标】为特征，分类准确率达【XX%】。

针对问题二，运用【梯度提升树/随机森林】模型，三种年龄婴儿分类准确率分别达【64.29%, 69.23%, 72.00%】。

针对问题三，建立【单目标最值优化模型】，以【治疗费用最小】为目标，从矛盾型变为中等型最少费用【28159 元】。

针对问题四/五，【方法 + 结果】。

为验证模型可靠性，本文从【交叉验证/消融实验/统计检验】角度进行检验，结果显示【稳健性结论】。

综合来看，本文模型具有【优点1】、【优点2】，为【应用领域】提供了【决策依据】。

关键词：【应用对象】；【模型1】；【算法2】；【评价方法3】；【应用领域】
```

### C 题摘要定量结果表达

- 评价题：权重值、TOPSIS 贴近度、排序结果（TOP50 城市名）。
- 分类题：准确率、F1、AUC（按类别分别报告）。
- 路径题：路线（城市序列）、总时长、总成本。
- 统计检验：p 值（`2025_C_1`：深睡眠 p=0.009，睡眠效率 p=0.020）。

### C 题摘要特殊加分

- **清洗结果前置**：把剔除异常值数量写进摘要（`2023_C_1`）。
- **p 值入摘要**：统计检验题把 p 值写进摘要（`2025_C_1`）。
- **诚实报告负面结果**：`2025_C_2` 摘要写"实验未能支持优化光照假设"——国一的自信。
