# 华数杯图表样式蒸馏（优秀样本观察）

> 基于 18 篇优秀论文蒸馏。图表数量与获奖等级正相关。
> 图表是区分国一与国二的关键。每条结论带论文页码引用。

---

## 1. 图表数量观察与使用边界

| 题型 | 样本观察（非门槛） | 最丰富范例 |
|------|----------|------------|
| A 题 | 样本图表普遍密集（约 19 项上下） | `2024_A_1` 27 图 13 表 |
| B 题 | 部分样本图表较密集，约 20 项以上 | `2025_B_2` 34 图（样本观察，非门槛） |
| C 题 | 样本图表密集（约 15 图、8 表上下） | `2025_C_1` 29 图 11 表 |

**规律**：图表数量是结果不是原因——国一样本图表普遍较多（样本观察），但每张图按论证需要组织，不设下限；图表过少通常意味着证据链不完整（缺机制/过程/边界证据），而不是"张数不够"。

---

## 2. 图表三大功能（每张图必须属于之一）

1. **说明结构**：技术路线图、算法流程图、物理示意图、网络拓扑图。
2. **展示结果**：收敛曲线、帕累托前沿、预测对比、误差图、参数曲线。
3. **比较方案**：柱状图、雷达图、热力图、地图、3D 曲面。

不属于这三类的图删掉。

---

## 3. A 题图表范式（物理工程）

### 3.1 必备图类型

| 图类型 | 用途 | 范例 |
|--------|------|------|
| 全文技术路线图 | 问题分析章 | `2024_A_1`、`2025_A_1` |
| 物理示意图 | 展示几何/结构/受力 | `2024_A_1` 机械臂零位简图、`2023_A_2` 织物结构 |
| 3D 可视化 | 展示空间姿态/曲面 | `2024_A_1` 末端轨迹 3D、`2023_A_2` 热导率曲面 |
| 收敛曲线 | 算法迭代过程 | `2025_A_1` 差分进化收敛 |
| 参数曲线 | 物理量随参数变化 | `2023_A_1` 温度时间曲线 |
| 优化前后对比 | 证明改进有效 | `2024_A_1` 路径对比 |
| 栅格图 | 避障/布局 | `2024_A_1` 底座栅格 |
| 特征重要性 | 数据驱动部分 | `2025_A_1` XGBoost 特征 |

### 3.2 A 题物理示意图画法

- 用矢量图（PDF/SVG），不用位图。
- 标注尺寸、角度、坐标系。
- `2024_A_1` 机械臂简图：标注六关节角度、连杆长度、末端坐标。
- `2023_A_2` 织物结构：经纬纱线交织示意 + 弯曲角标注。

### 3.3 A 题图表美化要素

- 物理示意图配色简洁（2-3 色，区分部件）。
- 3D 图加坐标轴和视角说明。
- 收敛曲线横轴迭代次数、纵轴目标值，标出最优解位置。
- 多子图统一字号和配色。

## 4. B 题图表范式（运筹优化）

### 4.1 必备图类型

| 图类型 | 用途 | 范例 |
|--------|------|------|
| 全文思路流程图 | 问题分析章 | `2025_B_2` |
| 算法流程图 | 模型求解章 | 所有 B 题论文 |
| 原始 vs 优化对比图 | 证明改进有效 | `2024_B_1` 布局对比 |
| 收敛曲线 | 算法性能 | `2025_B_2` |
| 帕累托前沿 | 多目标 | `2023_B_2`、`2024_B_2` |
| 灵敏度图 | 参数扰动 | `2023_B_2` 九联图 |
| 资源分配图 | 解的呈现 | `2025_B_1` 资源块分配 |
| 基准函数收敛对比 | 算法验证（国一利器） | `2025_B_2` Ackley |
| 3D 散点/布局 | 解空间 | `2023_B_2` 3D 散点 |

### 4.2 B 题算法流程图画法

- 标准 flowchart：开始 → 初始化 → 迭代（含判断框）→ 输出。
- 用 `graphviz` 或 `draw.io` 画，矢量输出。
- 关键步骤加注释（如"满足终止条件？"）。

### 4.3 B 题帕累托前沿画法

- 横纵轴为两个目标值。
- 标出 Pareto 最优解集（散点）。
- 用虚线连接形成前沿。
- 高亮决策点（加权法/TOPSIS 选出的）。

### 5.1 必备图类型

|--------|------|------|

| 地图类 | 空间分布（2024C 杀手锏） | `2024_C_1` 352 城分布 |
| 雷达图 | 多维评价 | `2024_C_1` 城市多维评分 |
| 时序图 | 预测对比 | `2025_C_1` 睡眠时序 |
| 评价结果图 | 排序/分级 | `2024_C_1` TOP50 城市 |
| 路径图 | 规划结果 | `2024_C_1` 游玩路线 |
| 混淆矩阵 | 分类结果 | `2023_C_2` |
| 3D 曲面 | 多参数响应 | `2025_C_1` 权重响应曲面 |
| p 值热力图 | 统计检验 | `2025_C_1` |

### 5.2 C 题地图类图表（2024C 杀手锏）

- 用 `folium` / `kepler.gl` / `pyecharts` 画交互式地图。
- 标注城市/景点坐标。
- 颜色编码评价值（如 TOP50 城市高亮）。
- 路线用连线 + 动画。
- `2024_C_1` 地图是区分国一的关键。

### 5.3 C 题数据可视化高级玩法

- **降维可视化**：PCA/t-SNE 投影 2D 散点，颜色编码类别。
- **多维雷达图**：6-8 维指标一图展示。
- **热力图矩阵**：相关性/混淆/p 值。
- **3D 曲面**：两参数对目标的响应曲面。
- **权重演化图**（`2025_C_1`）：展示权重随迭代变化。

## 6. 通用美化规则（区分国一与国二）

### 6.1 配色

- 控制在 3-5 种主色。
- 避免彩虹色（jet 色表），用 viridis/plasma/seaborn 默认。
- 多子图统一配色。
- 对比图用对比色（蓝-橙最佳）。

### 6.2 标注

- 坐标轴**必须有名称和单位**（`xlabel("时间 (s)")`）。
- 图例清晰，不遮挡数据。
- 关键点标注数值。
- 图题写成"图 X 【描述】"。

### 6.3 字号与分辨率

- 正文字号 10-12pt，图内字号不小于 8pt。
- 矢量图优先（PDF/SVG），位图至少 300 DPI。
- matplotlib 用 `plt.rcParams` 统一设置：
  ```python
  plt.rcParams['font.sans-serif'] = ['SimHei']  # 中文
  plt.rcParams['axes.unicode_minus'] = False
  plt.rcParams['figure.dpi'] = 300
  ```

### 6.4 图后解释（必须有）

每张图后 1-3 句，标准句式：
- "由图 X 可见，【变量】随【变量】变化呈现【趋势】，说明【结论】。"
- "对比图 X (a)(b) 可知，【改进后】优于【改进前】。"
- "图 X 显示，算法在第 XX 代收敛，说明参数设置合理。"

**没有解释的图等于没画**——评委不知道你想说什么。

---

## 7. 表格规范

- 表头**必须带单位**（"温度 (℃)"、"成本 (元)"）。
- 数值保留位数一致（全表 2 位小数或 4 位小数统一）。
- 大表（>10 行）放附录，正文只保留关键行。
- 三线表（toprule/midrule/bottomrule），不用竖线。
- 方案比较表：列出指标列，最优值加粗。
