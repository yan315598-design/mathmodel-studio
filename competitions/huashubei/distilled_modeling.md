## 1. A 题：物理工程机理建模 + 优化

### 1.1 建模主线（6 篇高度一致）

```
物理定律推导 → 控制方程 → 数值离散 → 目标函数 → 优化算法 → 结果验证
```

### 1.2 高频物理领域与方法库

#### 传热学（2020A 相变防护服 / 2023A 隔热织物 — 两次考查，最高频）

- **核心方程**：傅里叶定律 `q = -k∇T`；一维热传导方程 `∂T/∂t = α∂²T/∂x²`。
- **多层结构**：热阻串联 `R = Σ L_i/k_i`（2020A 三层织物）。
- **瞬态仿真**：有限差分时间步推进（`2023_A_1 p8` 向后隐式格式，稳定性优于显式）。
- **相变潜热**：等效热容法或焓法（2020A 相变材料放热曲线）。
- **参数反演**：单纤维热导率无法直接测，用整体热导率反推（`2023_A_1` 黄金分割搜索，`2023_A_2` LBM 模型）。

#### 电磁/电路（2021A 无线充电）

- **核心方程**：RLC 谐振频率 `f = 1/(2π√LC)`；互感耦合系数 `k = M/√(L1·L2)`。
- **传输效率**：`η = P_out/P_in`，与频率、阻抗匹配、线圈偏移几何相关。
- **几何积分**：线圈偏移互感需数值积分（`2021A` 线圈半径 r、高度 h、偏移 a）。

#### 半导体器件（2022A 环形振荡器）

- **核心公式**：MOSFET 饱和区电流 `I_D = ½μC_ox(W/L)(V_GS-V_TH)²`；线性区电流公式。
- **反相器延迟**：`t_pd ∝ C_L·V_DD/I_D`。
- **振荡频率**：`f = 1/(2N·t_pd)`（N 级反相器环）。
- **多目标**：速度（频率）/ 面积（W·L）/ 功耗三目标优化。

#### 运动学+几何（2024A 机械臂 — 近年热点）

- **D-H 参数法**：六自由度连杆齐次变换矩阵 `T = Rot_z(θ)·Trans_z(d)·Trans_x(a)·Rot_x(α)`（`2024_A_1 p5`）。
- **正运动学**：末端位姿 = 各关节矩阵连乘。
- **逆运动学**：给定末端位姿反解关节角（解析法/数值法/优化法）。
- **避障**：底座栅格 + A*/蚁群路径规划（`2024_A_1` 可达点策略 + A*）。
- **能耗**：`E = Σ τ_i·dθ_i`；`2024_A_2` 论证动能项为定值，只需优化势能。

#### 多物理场耦合（2025A 多孔膜 — 最新趋势，最难）

- **五环节耦合**：蒸发 → 析出 → 布朗运动 → 碰撞 → 增大（`2025_A_1`）。
- **参数辨识**：耦合模型参数多，用差分进化/粒子群全局搜索（`2025_A_1` 差分进化，`2025_A_2` 粒子群）。
- **机理-数据双驱动**（最高级）：耦合动力学模型（机理）+ XGBoost（数据）互证，`2025_A_1` 是 6 篇中唯一实现。

### 1.3 A 题优化方法选择

| 问题特征 | 推荐方法 | 论文实例 |
|----------|----------|----------|
| 一维参数搜索 | 黄金分割法 | `2023_A_1` 单纤维热导率 |
| 多目标（2-3 个） | 分层序列法 / 加权法 / NSGA-II | `2022A` 三目标 |
| 路径规划 | 蚁群 / A* | `2024_A_1` |
| 参数辨识（高维非线性） | 差分进化 / 粒子群 | `2025_A_1` / `2025_A_2` |
| 非线性方程组 | 龙格-库塔 / 有限差分 | `2025_A_2` 四阶 RK |

### 1.4 A 题创新点构造（按价值排序）

1. **机理-数据双驱动**：物理模型与 ML 模型互证（`2025_A_1`，6 篇唯一）。
2. **模型命名 + 改进**：给模型起名，并在标准模型上做针对性改进（`2023_A_2` LBM 模型）。
3. **自创策略**：`2024_A_1`"可达点"策略贯穿三问。
4. **多算法组合**：`2025_A_1` 差分进化 + 蚁群 + XGBoost 三段式。
5. **评价指标创新**：构造题目未要求但合理的评价量。

### 1.5 A 题避坑

- ❌ 纯数据黑箱回归（A 题评委看重机理）。
- ❌ 物理方程写错（量纲检查不过 = 出局）。
- ❌ 假设过宽（"假设材料各向同性"用于各向异性织物）。
- ❌ 数值结果无物理意义校验（关节角超出物理范围，`2024_A_1/A_2` 疑似错误）。

## 2. B 题：运筹优化 / 组合优化

### 2.1 建模主线（五步法）

```
问题抽象 → 决策变量定义 → 目标函数 → 约束条件 → 算法求解
```

6 篇 B 题论文**无一例外**都单设"决策变量"小节，这是 B 题的基本功。

### 2.2 高频问题类型与方法库

#### 经典组合优化（2020B 切割 / 2021B 装箱 / 2022B 生产计划）

- **二维切割下料**（2020B）：列生成法、切割模式枚举、MILP。
- **三维装箱**（2021B）：0-1 整数规划、三舱载重比例约束、启发式装载。
- **随机规划**（2021B）：95%/70% 可靠性 → 机会约束规划（CCP）。
- **多级生产计划**（2022B）：BOM 展开、批量大小（Lot-Sizing）、滚动计划、检修调度。

#### 工程系统优化（2024B VLSI / 2025B 网络切片 — 近年趋势，最难）

- **VLSI 全局布局**（2024B，NP 难）：
  - HPWL（半周长线长）线长估计：`HPWL = (x_max-x_min) + (y_max-y_min)`。
  - RSMT（直线斯坦纳最小树）更精确但计算贵。
  - 密度约束：网格化均匀分布。
  - `2024_B_1` 创新：查找表修正 HPWL 逼近 RSMT，偏差从 30213 降到 117。
- **5G 资源调度**（2025B）：
  - 资源块整数分配 + 功率控制 + 干扰 + 能耗多目标。
  - 排队论（M/M/1）或离散事件仿真。
  - `2025_B_1` 创新：跨周期 mMTC 优化 + 迁移适宜度指标。

#### 领域物理模型 + 优化（2023B 配色）

- K-M 光学模型：K/S 加和性、CIELAB 色差 ΔE。
- `2023_B_2` 矩阵化 K-M 推导，是数学严谨性的范例。

### 2.3 B 题算法选择决策树（从 6 篇归纳）

```
决策变量少 (≤3) + 约束简单 + 可枚举
  → 枚举 + 预剪枝
    (2025_B_1 问题一: x∈{1,2}, 仅3种方案)
    (2023_B_1: 蒙特卡洛 200 万次随机 + 筛选)

决策变量中等 + 非线性 + 单目标
  → 商业求解器 / scipy 库函数
    (2023_B_2: scipy.optimize.minimize SLSQP)
    (2024_B_1: 改进模拟退火, Min-Max 标准化代价函数)

大规模 + NP 难
  → 元启发式 (遗传 / 模拟退火 / 粒子群 / 禁忌搜索)
    (2024_B_2: 模拟退火 + 遗传算法双算法互校)
    (2025_B_2: SA-PSO 融合)

多目标
  → NSGA-II 或 ε-约束法 + 帕累托前沿
    (2023_B_2: NSGA2 geatpy + 动态线性加权 + TOPSIS)
    (2024_B_2: 拥挤距离 NSGA-II)
```

### 2.4 B 题创新点构造（按价值排序）

1. **算法融合 + 基准验证**（最高价值）：`2025_B_2` SA-PSO 融合 + Ackley 函数验证（收敛 145 vs SA 2370 vs PSO 213）。**用标准基准函数证明算法有效，是 B 题国一杀手锏**。
2. **模型修正/改进**：`2024_B_1` 查找表修正 HPWL；`2024_B_2` T 字/十字弯折面积修正 Adjusted-HPWL。
3. **自定义评价指标**：`2025_B_1` 迁移适宜度指标凸组合加权。
4. **策略性求解设计**：`2025_B_1` 预剪枝将 O(4^N) 降至 O(N)；系统化实验设计（4 组基础 × 4 次重复 → 3 组两两组合 → 遗传交叉验证）。
5. **双算法交叉验证**：`2024_B_2` 模拟退火 + 粒子群，精确度 93.4%/93.3% 互校。

### 2.5 B 题避坑

- ❌ 纯理论无代码（B 题评委看重"能不能跑出大规模实例"）。
- ❌ 伪代码与实际代码脱节（`anti_patterns.md`）。
- ❌ 灵敏度流于表面（只扰动 1 个参数，不画曲线）。
- ❌ 算法对比不足（只用 1 种算法，无基线对比）。
- ❌ 决策变量类型不明（连续/整数/0-1 混淆）。

## 3. C 题：数据评价 / 预测分类 / 规划调度

### 3.1 建模主线（因题型而异）

```
评价类:    数据清洗 → 指标体系构建 → 客观赋权 → 综合评价 → 排序/分级 → 推广
分类预测类: 数据清洗 → 特征工程 → 模型训练 → 交叉验证 → 可解释性 → 应用
回归类:    数据清洗 → 相关分析 → 多元回归/正则化 → 显著性检验 → 多目标优化
路径规划类: 数据清洗 → 评价选点 → TSP/VRP 建模 → 启发式求解 → 路线输出
专业计算类: 标准参数计算 → 约束优化 → 统计检验 (2025C 新趋势)
```

### 3.2 综合评价体系（2020C / 2024C — C 题最高频类型）

#### 黄金搭档：熵权法 + TOPSIS

**6 篇 C 题评价类论文无一篇用 AHP**——评委明确偏好客观赋权。

- **熵权法**（客观定权）：
  - 标准化 → 计算信息熵 `E_j = -kΣ p_ij·ln(p_ij)` → 权重 `w_j = (1-E_j)/Σ(1-E_j)`。
- **TOPSIS**（逼近理想解排序）：
  - 正负理想解 → 欧氏距离 → 相对贴近度 `C_i = D_i⁻/(D_i⁺+D_i⁻)`。
- **组合用法**（`2024_C_1`）：KMO 检验 → PCA 降维 → 熵权法定权 → TOPSIS 排序。

#### 其他评价方法（按需组合）

- **CRITIC 法**：兼顾变异性和冲突性，适合指标相关性强的场景。
- **灰色关联分析**：适合小样本、非线性。
- **主成分分析 PCA**：降维 + 综合，`2024_C_1` 用 KMO 检验判断适用性（严谨）。

#### C 题评价题创新点

- **自建指标体系**：题目给的是原始数据，评价指标需自行构造（如 2020C"进步幅度"、2024C"城市吸引力综合分"）。指标构造的合理性是评分关键。
- **方法选择论证链**：`2024_C_1` 用 KMO 检验判断是否适用 PCA——**检验前置，不是直接套模型**。

### 3.3 分类与预测（2021C / 2023C）

- **二分类**（2021C 购买意愿）：逻辑回归（基线）→ 随机森林/XGBoost（主力）。
- **多分类**（2023C 婴儿行为三分类）：SVM / 神经网络 / 梯度提升树。
- **必备报告**：准确率、召回率、F1、AUC、混淆矩阵。
- **可解释性**：SHAP 值或特征重要性（国一加分）。
- **数据清洗独立成章**：`2023_C_1 p1` 把清洗结果（剔除 10 个异常值）写进摘要——C 题特色。

### 3.4 回归与关联（2020C / 2022C / 2023C）

- **相关分析**：皮尔逊（线性）/ 斯皮尔曼（单调）/ 卡方（类别）。
- **多元回归**：逐步回归、LASSO 正则化。
- **两级建模**（2022C）：工艺参数 → 结构变量 → 性能，两级回归链。
- **显著性检验**：p 值、置信区间、方差分析。

### 3.5 路径规划（2024C 老外游中国）

- **评价选点**：先对 352 城综合评价，选 TOP50。
- **TSP 建模**：144 小时（6 天）多城市游玩，带时间窗 + 成本约束。
- **算法**：最近邻（初始解）→ 遗传/模拟退火（优化）→ Dijkstra（城际最短路）。
- **多目标**：游玩体验最大化 + 成本最小化 + 时间约束。
- `2024_C_1`：双目标规划 + ε-约束法 + 遗传算法，输出具体路线（广州—安庆—定西—儋州—北京—黄山，141 小时、3680 元）。

### 3.6 专业计算 + 统计检验（2025C — 最新趋势，C 题难度抬升）

- **标准化计算**（2025C 光谱）：SPD → CCT/Duv/Rf/Rg/mel-DER，按 CIE S 026E、IES TM-30-20 国际标准计算。
- **约束优化**：五通道权重优化，日间/夜间双模式。
- **统计检验**：配对 t 检验、重复测量方差分析、Friedman 检验。
- **统计检验分层决策树**（`2025_C_1` 杀手锏）：先检验正态性 → 选择参数/非参数检验 → 事后检验。
- **创新算法**：分层惩罚策略、多重随机重启模拟退火（`2025_C_1`）。

### 3.7 C 题创新点构造（按价值排序）

1. **方法选择论证链**：检验前置 → 分支选择（`2024_C_1` KMO→PCA；`2025_C_1` 正态性→t/非参）。
2. **外部数据 + 文献支撑**：引入题目未给的相关数据或国际标准（2025C 引 CIE/TM-30）。
3. **算法命名化改进**：`2025_C_1` MRSA（多重随机重启模拟退火）+ 收敛性证明。
4. **多场景/多模式拆分**：`2025_C_1` 日间/夜间双模式。
5. **诚实面对负面结果**：`2025_C_2` 报告"优化光照无效"、`2023_C_2` 报告"算法收敛失败"——反直觉但最加分。

### 3.8 C 题避坑（C 题易"水"，重点避坑）

- ❌ 直接套模型不做方法适用性检验（应 KMO/正态性检验前置）。
- ❌ 用 AHP 主观赋权（评委偏好客观赋权，6 篇无一用 AHP）。
- ❌ 数据清洗不写清（C 题必考清洗，清洗规则要在摘要和正文都体现）。
- ❌ 可视化简陋（C 题数据量大，可视化是差异化关键；详见 `distilled_figures.md`）。
- ❌ 同质化（C 题最卷，必须做差异化：外部数据、统计检验、高级可视化）。

## 4. 跨题型通用方法储备（stage 3 模型选型参考）

### 4.1 多目标优化通用方法

| 方法 | 适用 | 论文实例 |
|------|------|----------|
| 加权法 | 目标可量纲统一 | 2022A / 2025C |
| 分层序列法 | 目标有优先级 | 2023_A_1 |
| NSGA-II | 2-3 目标帕累托 | 2022A / 2023_B_2 / 2024_B_2 |
| ε-约束法 | 双目标转单目标 | 2024_C_1 |

### 4.2 灵敏度分析通用做法

- 选 1-3 个关键参数，在 ±20% 范围扰动。
- 画扰动曲线（横轴参数值，纵轴目标值）。
- 报告结论稳定性："主要结论在扰动区间内保持稳定"。
- **加分**：九联灵敏度图（`2023_B_2`）、参数热力图（`2025_C_1`）。

### 4.3 稳健性检验通用做法

- **算法基准测试**（B 题国一利器）：用 Ackley/Rastrigin 等标准函数验证算法收敛性（`2025_B_2`）。
- **交叉验证**（C 题分类必做）：K 折交叉验证，报告均值±标准差。
- **多算法对比**：换一种原理不同的算法复核同一问题，比较结果一致性（`2024_B_2` 93.4%/93.3%）。
- **消融实验**：去掉某模块看性能下降（证明该模块有效）。

## 5. 2026 届（第七届）出题方向预测与备赛

基于前 6 届规律外推（详见赛题蒸馏报告）：

### A 题预测（概率排序）
1. ★★★★★ 新能源/双碳物理建模（电池热管理、光伏冷却、储热材料）— 延续 2020 传热 + 2025 多孔膜能源主线。
2. ★★★★ 智能装备/机器人系统（无人机航迹、AGV 动力学）— 延续 2024 机械臂。
3. ★★★ 生物医学工程物理（血流动力学、药物释放）— C 题母婴/LED 已埋伏笔。
