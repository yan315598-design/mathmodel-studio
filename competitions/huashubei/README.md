## 三题型速查

### A 题 — 物理工程机理建模 + 优化（难度高、竞争小、国一性价比优）

- **主线**：物理定律推导 → 控制方程 → 数值离散 → 目标函数 → 优化算法
- **高频考点**：传热学（2020/2023 两次考查）、电磁/电路、半导体器件、运动学+几何、多物理场耦合
- **国一关键**：物理推导严谨 + 数值结果可解释 + **机理-数据双驱动**（最高级形态）
- **避坑**：纯数据黑箱回归在 A 题难拿高分

### B 题 — 运筹优化 / 组合优化（难度最高、拼代码实力）

- **主线**：问题抽象 → 决策变量 → 目标函数 → 约束 → 算法
- **高频考点**：切割/装箱/生产计划（经典运筹）、VLSI 布局/网络切片（工程系统优化）
- **国一关键**：算法实现质量（求解规模/收敛速度/结果可视化）+ 建模严谨性
- **避坑**：纯理论无代码必败；近年 B 题需先理解领域知识再建模

### C 题 — 数据评价 / 预测分类 / 规划调度（难度低、竞争最卷）

- **主线**：数据清洗 → 特征工程 → 建模 → 评价 → 推广
- **高频考点**：综合评价体系、分类预测、回归+多目标、TSP 路径规划、专业计算+统计检验
- **国一关键**：不是"做出来"而是"做得比别人细致"——权重合理性 + 调参深度 + 可视化 + 洞察
- **避坑**：与数千队同质化；2025C 引入国际标准暗示难度在抬升

## 选题决策三原则（详见 references/huashubei_topic_decision.md）

1. **匹配度优先**：队伍有物理/工科背景 → A；算法/工程背景 → B；统计/经管背景 → C。
2. **避开最卷**：C 题竞争度均值 4.17（最卷），若队伍不强建议避开；A/B 题竞争度 3.0。
3. **难度与价值权衡**：最难题（2024B/2025A/2025B）能做出来即有大奖希望；最易题需更细致才能突围。

## 数据来源声明

- 赛题来源：本地历年赛题语料（第一届2020 ~ 第六届2025）。
- 优秀论文来源：本地历年赛题语料同目录下第四/五/六届 A/B/C 各 2 篇，共 18 篇。
- 蒸馏方法：pdfplumber 全文提取 → 按题型分组深度分析 → 每条结论带论文页码引用。
- 局限：第一届至第三届（2020-2022）无优秀论文，相关写作范式由第四/五/六届外推。
- 不联网：本经验库全部基于本地资料，未引入网络信息。
