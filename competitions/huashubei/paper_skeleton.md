# 华数杯论文骨架（按题型）

> 基于 18 篇优秀论文蒸馏。三题型章节有共性也有差异。

---

## A 题骨架（物理工程机理建模）

```
摘要（1 页，功能五项覆盖，见 abstract_template.md）

1 问题重述
  1.1 问题背景
  1.2 问题重述
  1.3 研究目标

2 问题分析
  2.1 子问题分解
  2.2 数据与附件说明
  2.3 总体技术路线【必配全文思路流程图】
  2.4 各问难点分析（加分，见 2024_B_1 独创"问题解读"）

3 模型假设与符号说明
  3.1 模型假设（4-7 条，物理条件 + 数据分布 + 简化）
  3.2 符号说明（表格化）

4 【基础计算 / 物理量提取 / 机理推导】（A 题特色）
  4.1 几何参数 / 物理常量提取
  4.2 基础机理方程推导（傅里叶定律 / D-H 参数 / RLC 方程等）
  4.3 数值离散化（有限差分 / 龙格-库塔）

5 子问题一：模型建立与求解
  5.1 模型建立【给模型命名】
  5.2 求解算法与参数设置
  5.3 结果（表 + 图）
  5.4 结果解释（中文，物理意义）

6 子问题二：模型建立与求解（同 5 闭环）

7 子问题三/四：模型建立与求解

8 灵敏度、稳健性与误差分析
  8.1 灵敏度分析（扰动曲线）
  8.2 稳健性检验（多算法对比 / 基准测试）
  8.3 误差分析（RMSE / R²）

9 模型评价、改进与推广
  9.1 优点
  9.2 缺点与改进方向
  9.3 推广价值【收尾升华】

参考文献（中英文 10-25 篇）

附录
  附录 A：代码（可运行）
  附录 B：补充图表
  附录 C：详细数据表
```

**A 题关键**：第 4 章（基础机理推导）是 A 题特色，必须有。机理推导的严谨性是 A 题评分核心。

---

## B 题骨架（运筹优化）

```
摘要（1 页）

1 问题重述
  1.1 问题背景
  1.2 问题重述

2 问题分析
  2.1 问题解读（每问单独分析难点，2024_B_1 独创，加分）
  2.2 总体技术路线【必配流程图】
  2.3 算法选择决策树（B 题特色）

3 模型假设与符号说明
  3.1 模型假设
  3.2 符号说明
  3.3 决策变量定义（B 题必单设，明确连续/整数/0-1）

4 子问题一：模型建立与求解
  4.1 模型建立
    4.1.1 决策变量
    4.1.2 目标函数【min/max 明确】
    4.1.3 约束条件【分条列举 + 物理含义解释】
    4.1.4 整合模型
  4.2 模型求解
    4.2.1 算法介绍（伪代码 + 流程图）
    4.2.2 参数设置（表格）
    4.2.3 求解步骤
  4.3 结果与分析（表 + 图 + 解释）

5 子问题二：模型建立与求解（含模型修正/改进）

6 子问题三/四：模型建立与求解（含多目标帕累托）

7 模型的分析与检验【B 题国一加分关键章】
  7.1 灵敏度分析（九联图，2023_B_2）
  7.2 算法基准测试（Ackley 函数，2025_B_2 杀手锏）
  7.3 多算法交叉验证（2024_B_2）
  7.4 收敛性分析

8 模型评价、改进与推广

参考文献

附录（完整可运行代码 + 大规模实例结果）
```

**B 题关键**：第 3.3 决策变量定义、第 7 章模型检验（基准测试）是 B 题国一加分项。

## C 题骨架（数据评价/预测/规划）

```
摘要（1 页，清洗结果前置，C 题特色）

1 问题重述
  1.1 问题背景
  1.2 问题重述

2 问题分析
  2.1 子问题分解
  2.2 数据概况（C 题数据量大，必须描述）
  2.3 总体技术路线【必配流程图】

3 数据预处理【C 题必独立成章，5/6 篇如此】
  3.1 数据清洗（缺失值/异常值/重复值）
  3.2 数据转换（标准化/归一化/编码）
  3.3 特征工程（构造新指标，C 题创新点）
  3.4 探索性分析（分布图/相关性热力图）

4 模型假设与符号说明

5 子问题一：【评价/分类/规划】模型建立与求解
  5.1 方法选择论证（检验前置：KMO/正态性，C 题加分）
  5.2 模型建立
  5.3 求解与结果
  5.4 结果解释（中文，现实含义）

6 子问题二/三/四/五：模型建立与求解

7 灵敏度与稳健性分析【C 题可独立成章，2025_C_2 第 6 章】
  7.1 评价权重灵敏度（权重扰动）
  7.2 分类模型稳健性（K 折交叉验证）
  7.3 统计检验（2025C 新趋势：t/ANOVA/Friedman）

8 模型评价、改进与推广
  8.1 优点
  8.2 缺点与诚实报告负面结果（国一特征）
  8.3 推广价值

参考文献

附录（代码 + 补充图表 + 大数据表）
```

**C 题关键**：第 3 章数据预处理独立成章、第 5.1 方法选择论证（检验前置）、第 8.2 诚实报告负面结果。

## 页数与字数参考（empirical.json 实测）

| 章节 | A 题 | B 题 | C 题 |
|------|------|------|------|
| 摘要 | 1 页 | 1 页 | 1 页 |
| 重述+分析 | 1-1.5 页 | 1-1.5 页 | 1-2 页 |
| 假设+符号 | 0.3-0.5 页 | 0.5 页 | 0.5 页 |
| 建模求解 | 10-18 页（核心） | 12-20 页（核心） | 12-20 页（核心） |
| 检验/评价 | 1-2 页 | 1-2 页（含基准测试） | 1-2 页（含统计检验） |
| 总正文 | 19-30 页 | 20-32 页 | 20-32 页 |
| 附录 | 5-15 页（代码） | 5-20 页（代码+大表） | 5-20 页（代码+大表） |

**样本观察**：部分优秀论文正文和图表较丰富，但页数、图表数和参考文献数均不是官方硬门槛；以完整证据链和可复现性为准。
