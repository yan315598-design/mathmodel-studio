# 华数杯优秀论文共性模式（18 篇蒸馏）

> 来源：第四/五/六届 A/B/C 各 2 篇共 18 篇优秀论文全文蒸馏。结论为样本内观察。
> 引用约定：`年份_题号_篇号 p页码`，如 `2024_A_1 p1`。
> 目标：国家级一等奖。本文每条规律均标注论文出处，可直接作为写作 Checklist。

---

## 模式 1：摘要必须给"模型命名 + 定量结果 + 方法链"

18 篇无一例外，摘要都是评分第一关。国一论文摘要的共同特征：

### 1.1 给每个核心模型起名字

- `2023_A_2 p1`：一次性列出四个模型名（"基于 LBM 的织物整体与单根纤维关系模型"、"综合传热模型"等）。
- `2024_A_1 p1`："基于'可达点'的 A*寻路机器臂抓取模型"——**自创概念被关键词化**。
- `2024_C_1 p1`：方法链命名"KMO 检验→PCA→熵权法→TOPSIS"。
- `2025_C_1 p1`：自创算法"分层惩罚策略"、"多重随机重启模拟退火算法"。

**规律**：命名即占位。评委看摘要时记住"那篇用可达点 A*的"，比记住"那篇用 A*的"强 10 倍。

### 1.2 每个子问题都给定量结果

6 篇 A 题论文摘要全部含数字：最优值、误差、R²、收敛迭代数、完整参数向量。
6 篇 C 题论文摘要全部含数字：评价指标值、排序结果、准确率、p 值。

**反面**：摘要只写"本文建立了 XX 模型，得到了较好结果"——直接出局。

### 1.3 方法链用动词串联

高频动词：建立 / 推导 / 引入 / 采用 / 求解 / 优化 / 构建 / 设计。
标准句式（`2024_A_1 p1`）："首先[绘制零位简图]→建立[空间直角坐标系]→改进[D-H 方法]→推导[正逆运动学方程]→[蚁群算法]求解"。

### 1.4 摘要长度区间

- A 题摘要：400-900 字，国一偏长（`2025_A_1 p1` 含收尾升华段约 900 字）。
- B 题摘要：600-900 字单页满字。
- C 题摘要：550-750 字，国一偏长（`2025_C_1 p1` 把 5 个参数值 + 两种模式最优解 + p 值全塞进摘要）。

### 1.5 收尾升华段（加分项，非必须但国一常见）

仅 `2025_A_1 p1`（6 篇 A 题中唯一）有独立收尾升华段："本文利用机理与数据双轮驱动……二者形成闭环互证；整体结构可推广至其它相分离成孔体系"。
C 题中 `2023_C_1 p1`、`2025_C_2 p1` 也有方法论高度收尾。

## 模式 2：章节推进强调"问题 - 模型 - 结果 - 解释"闭环

### 2.1 每个子问题单独闭环

不能把所有模型集中放在一章（`anti_patterns.md` 第 3 条）。每个主要子问题至少包含：
- 题意重述和变量定义
- 模型建立或算法流程
- 求解设置和参数说明
- 结果图表
- **对结果的中文解释和现实含义**（这是评委最看重的）

### 2.2 章节比例（18 篇稳定区间）

| 章节 | 占比 |
|------|------|
| 摘要+关键词 | 1 页 |
| 问题重述+分析 | 8-15% |
| 假设+符号说明 | 3-5% |
| **模型建立与求解** | **55-70%（核心）** |
| 稳健性/检验/评价 | 10-15% |
| 附录（代码+补充图） | 10-20% |

### 2.3 加分章节（国一标志）

- **独立"问题分析"章 + 全文技术路线图**：`2024_B_2`、`2025_B_2`、`2024_C_1` 均有。
- **独立"模型检验"章**：`2025_B_2 p19-20` 用 Ackley 函数做算法基准测试——国一加分利器。
- **独立"灵敏度分析"章**：`2025_C_2` 专设第 6 章。
- **"问题解读"章（每问单独分析难点）**：`2024_B_1` 独创，逻辑最清晰。

## 模式 3：算法使用贴题，不堆名词

### 3.1 A 题算法选择

- **机理推导优先**：傅里叶定律、热阻串联、D-H 参数、RLC 谐振——先把物理方程写对。
- **数值求解**：有限差分（`2023_A_1` 向后隐式格式）、龙格-库塔（`2025_A_2` 四阶 RK）。
- **优化算法**：黄金分割法（一维）、分层序列法（多目标）、NSGA-II、蚁群（路径）、差分进化（参数辨识）。
- **最高级形态：机理-数据双驱动**（`2025_A_1`）：耦合动力学模型（机理）+ XGBoost（数据）形成闭环互证。

### 3.2 B 题算法选择决策树

```
决策变量少 (≤3) + 可枚举 → 枚举 + 预剪枝 (2025_B_1: O(4^N)→O(N))
决策变量中等 + 非线性 + 单目标 → 商业求解器/SLSQP (2023_B_2)
大规模 + NP 难 → 元启发式 (遗传/模拟退火/粒子群)
多目标 → NSGA-II 或 ε-约束法 + 帕累托前沿
```

**算法融合是国一加分项**：`2025_B_2 p6-7` 模拟退火粒子群融合（PSO 收敛快 + SA 跳出局部最优），并用 Ackley 函数验证收敛次数 145 vs SA 2370 vs PSO 213。

### 3.3 C 题算法选择

- **评价题黄金搭档：熵权法 + TOPSIS**。6 篇 C 题评价类论文**无一篇用 AHP**——评委偏好客观赋权。
- **分类题**：逻辑回归（基线）→ 随机森林/XGBoost（主力）→ SHAP（可解释性）。
- **路径规划**：最近邻（初始解）→ 遗传/模拟退火（优化）。
- **统计检验**（2025C 新趋势）：配对 t 检验、重复测量方差分析、Friedman 检验。

## 模式 4：图表必须承担论证功能（高质量样本共性）

### 4.1 样本中图表较丰富，但证据功能优先于数量

- A 题样本观察：`2023_A_2` 有 19 图，`2024_A_1` 有 27 图 13 表；不据此设数量门槛。
- B 题优秀样本常有较丰富图表（`2025_B_2` 共 34 图），这是样本观察，不是官方门槛。
- C 题：`2025_C_1` 29 图 + 11 表最丰富。

### 4.2 图表三大功能

每张图必须属于以下之一，否则删掉：
1. **说明结构**：技术路线图、算法流程图、物理示意图。
2. **展示拟合/优化/结果**：收敛曲线、帕累托前沿、预测对比、误差图。
3. **比较方案**：柱状图、雷达图、热力图、地图。

### 4.3 图后必须有解释

每张图后 1-3 句，直接回答"从图中得到什么结论"。
标准句式（全 18 篇通用）："由图 X 可见，[变量]随[变量]变化呈现[趋势]，说明[结论]。"

### 4.4 美化要素（区分国一与国二的关键）

- 配色控制在 3-5 种，避免彩虹色。
- 坐标轴必须有名称和单位。
- 多子图统一配色和字号。
- 物理示意图用矢量图（PDF/SVG），不用位图。
- 3D 可视化（`2024_A_1`、`2023_B_2` 3D 散点）是加分项。

详见 `distilled_figures.md`。

## 模式 5：创新点落在"组合 + 解释 + 命名"，不写空泛口号

### 5.1 创新的四种形态（按国一价值排序）

1. **机理-数据双驱动**（最高级，仅 `2025_A_1` 实现）：物理机理模型与机器学习模型互证。
2. **算法融合 + 基准验证**（`2025_B_2` SA-PSO + Ackley 验证）。
3. **模型修正/改进**（`2024_B_1` 查找表修正 HPWL，偏差从 30213 降到 117）。
4. **自定义评价指标**（`2025_B_1` 迁移适宜度指标凸组合加权）。

### 5.2 创新点的表达规范

- 给创新点起名字（如"基于可达点的 A*寻路"、"Adjusted-HPWL"、"迁移适宜度指标"）。
- 在摘要、问题分析、模型建立三处反复出现同一命名（强化记忆）。
- 用对比实验证明创新有效（改进前 vs 改进后的指标差）。

### 5.3 反面

- 写"本文创新性地使用了 XX 算法"——空泛，必须有对比证据。
- 堆砌 Quantum / Boosting / 深度学习名词而不说明为何适合该题。

## 模式 6：诚实面对负面结果（国一的自信表现）

这是区分国一的重要特征。敢于报告"实验未能支持假设"的论文，反而显得严谨：

- `2023_C_2 p1`：问题五"算法收敛失败，本文认为其原因在于原始数据集质量不高，导致误差积累"。
- `2025_C_2 p1`：问题四"实验数据未能支持'优化光照'方案可以改善睡眠质量的假设。相反……完全黑暗的环境是更优的选择"——**忠于数据，得出与题目预期相反的结论**。

**规律**：国一论文有底气报告负面结果，因为前面工作扎实；心虚的论文才需要每个结果都"显著优于"。

## 模式 7：参考文献规范（中英文 + 期刊）

- 国一论文参考文献 10-25 篇，中英文混合。
- `2024_A_1` 参考文献全是学位论文（反例，扣分项）——应优先引期刊论文和国际标准（如 2025C 引 CIE S 026E、IES TM-30-20）。
- 引用应服务于模型选择、算法依据或数据背景，不为凑数量。
- 中文赛默认 GB/T 7714 风格。

---

## 模式 8：完整的可复现性

- 参数来源明确（不能"凭经验取值"）。
- 数据处理流程可复现（清洗规则、特征工程步骤写清）。
- 算法参数表（种群大小、迭代次数、交叉概率等）必须给出。
- 附录代码可运行（`2025_B_1` 预剪枝将 O(4^N) 降至 O(N)，代码可复现）。

---

## 国一 vs 国二的 5 个分水岭（综合 18 篇观察）

1. **摘要**：国一有模型命名 + 定量结果密集 + 收尾升华；国二只有方法列表。
2. **图表**：高质量论文让每张图承担明确论证功能；数量只能作样本观察，不能决定奖项。
3. **创新点**：国一有命名 + 对比验证；国二写"创新性使用"无证据。
4. **机理深度**（A 题）/ **算法实现**（B 题）/ **洞察深度**（C 题）：国一在该题型核心维度明显超越。
5. **诚实度**：国一敢报告负面结果和模型局限；国二每个结果都"显著优于"。
