# CUMCM 内容型建模范式

历史案例只提供候选结构。先用守恒、约束和数据生成机制解释问题，再选择算法。

## 1. 物理机理

- 识别信号：题面给出受力、能量、光路、传播、材料或设备参数，并要求解释机制或优化结构。
- 推荐链：状态变量与坐标系 → 守恒/本构方程 → 参数辨识 → 数值求解 → 工况优化。
- 候选比较：解析模型可解释但近似强；ODE/PDE 更真实但参数和计算成本高；数据驱动适合补偿残差，不应替代已知定律。
- 必做验证：量纲、守恒、解析特例、数值步长收敛、参数敏感性。
- 适用边界：缺少关键机理参数时，明确可辨识性，避免用黑箱拟合伪装机理。
- 案例：`cumcm_2022_A`、`cumcm_2023_A`、`cumcm_2025_B`。

## 2. 几何与运动学

- 识别信号：位置、姿态、曲线、覆盖、碰撞、视线、纯方位或运动时间窗。
- 推荐链：统一坐标 → 几何约束 → 位置递推/轨迹方程 → 速度和事件检测 → 路径或参数优化。
- 候选比较：闭式几何适合规则构型；数值根求解适合隐式约束；离散步进需做步长收敛；优化算法只负责搜索，不代替几何判定。
- 必做验证：距离/链长残差、边界构型、退化情形、连续性、碰撞最小间距。
- 适用边界：柔性、三维或动力效应明显时，刚体平面模型不能直接外推。
- 案例：`cumcm_2022_B`、`cumcm_2023_B`、`cumcm_2024_A`、`cumcm_2025_A`。

## 3. 优化与调度

- 识别信号：决策变量、成本/收益、资源、时间、逻辑、容量或多目标约束清晰。
- 推荐链：决策变量 → 目标函数 → 硬约束 → 基准可行解 → 精确/启发式求解 → 情景鲁棒性。
- 候选比较：线性/混合整数规划有可解释最优性；动态规划适合阶段状态；元启发式适合非凸大规模，但必须有基线和收敛证据。
- 必做验证：约束逐条检查、目标重算、小规模最优对照、随机种子稳定性、不确定参数情景。
- 适用边界：不能把软约束任意加权；实时问题需报告求解时间。
- 案例：`cumcm_2021_C`、`cumcm_2021_D`、`cumcm_2022_E`、`cumcm_2024_B`、`cumcm_2024_C`。

## 4. 统计预测

- 识别信号：历史时序、重复测量、相关关系、未来值、风险或置信区间。
- 推荐链：数据生成过程 → 清洗和泄漏检查 → 探索统计 → 基线模型 → 候选模型 → 时间外/主体外验证 → 不确定性。
- 候选比较：经典回归易解释；树模型处理非线性；神经网络需足够样本；时序模型必须保留时间顺序。
- 必做验证：残差、时间滚动验证、受试者级划分、校准、预测区间、结构突变检查。
- 适用边界：预测相关不等于因果，价格、干预等内生变量需单独处理。
- 案例：`cumcm_2023_C`、`cumcm_2023_E`、`cumcm_2025_C`。

## 5. 评价与排序

- 识别信号：多个对象和指标，需要综合得分、分级或方案优选。
- 推荐链：评价目的 → 指标可测性 → 去冗余与同向化 → 权重依据 → 聚合 → 排名稳定性。
- 候选比较：熵权反映离散度而非重要性；AHP 依赖专家判断；PCA 强调方差；监督学习只有在存在可信标签时才成立。
- 必做验证：权重扰动、指标删除、排序相关、异常对象影响、替代聚合方法对比。
- 适用边界：评价通常是子任务，不要把所有问题都转换成 TOPSIS 排名。
- 案例：结合 `cumcm_2021_C`、`cumcm_2024_E`、`cumcm_2025_E` 的实际主任务使用。

## 6. 网络与路径

- 识别信号：节点、边、连通、流量、传播、最短路、路网或巷道。
- 推荐链：拓扑构造 → 边权物理意义 → 状态传播 → 时变可行性 → 单/多目标路径。
- 候选比较：Dijkstra 适合非负静态边权；A* 需要可采纳启发式；最大流解决容量；时变网络不能直接用静态最短路。
- 必做验证：连通性、流量守恒、路径全程可行、边权单位、关键边扰动。
- 适用边界：空间连续场不能未经说明就简化为图；人群拥堵需容量或排队模型。
- 案例：`cumcm_2024_E`、`cumcm_2025_D`。

## 7. 信号处理

- 识别信号：光谱、波形、峰谷、频域、噪声、编码或传输。
- 推荐链：采样与噪声检查 → 去噪/基线 → 特征或频谱 → 物理反演/编码 → 误差评估。
- 候选比较：滤波需保持有效信号；峰值法直观但对噪声敏感；全局拟合稳定但依赖物理模型；深度网络需要标注和跨设备验证。
- 必做验证：信噪比、频率分辨率、残差结构、标准样品、无损恢复或误码曲线。
- 适用边界：处理参数不能用测试集调优；设备域偏移需重新标定。
- 案例：`cumcm_2022_D`、`cumcm_2025_B`。

## 8. 图像识别

- 识别信号：图片、视频、关键点、目标、动作、类别或异常。
- 推荐链：数据和标注质控 → 几何/纹理/时序特征 → 简单基线 → 候选分类/回归 → 可解释错误分析。
- 候选比较：手工特征样本效率高；树模型适合表格化特征；深度模型依赖数据量；预训练模型需说明迁移方式。
- 必做验证：主体级划分、类别不平衡指标、混淆矩阵、遮挡/噪声鲁棒性、跨设备测试。
- 适用边界：同一对象的相邻帧不能随机分到训练和测试集。
- 案例：`cumcm_2021_E`、`cumcm_2025_E`。

## 9. 仿真模拟

- 识别信号：随机落点、概率事件、离散流程、复杂交互或无闭式解。
- 推荐链：随机变量与机制 → 仿真器校验 → 方差控制/样本量 → 情景实验 → 决策优化。
- 候选比较：蒙特卡罗通用但收敛慢；离散事件适合流程；个体仿真适合异质交互；代理模型适合昂贵仿真。
- 必做验证：解析特例、置信区间、样本量收敛、随机种子复现、极端情景。
- 适用边界：仿真只是在既定假设下生成结果，不能自动证明机制正确。
- 案例：`cumcm_2024_B`、`cumcm_2024_D`。
