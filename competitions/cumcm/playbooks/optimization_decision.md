# 优化决策域 Playbook

证据锚点约定：**论文方法链提取** = 2021-2025 各年 A-E 题获奖论文 25 篇摘要级提取（每题取文件名排序第一篇，方法名取论文自述；提取过程记录为内部审计产物，分发版不含，证据为本文档归纳归属）。本域证据主体为其中 2021-C（原材料订购与运输）、2021-D（连铸切割在线优化）、2022-E（物料生产安排）、2023-C（蔬菜动态定价与补货）、2024-B（生产过程决策优化）、2024-C（农作物种植策略）六题；**我方实验** = 无（国赛未做本地试点，本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域对应"优化与调度"类，推荐链（决策变量 → 目标函数 → 硬约束 → 基准可行解 → 精确/启发式求解 → 情景鲁棒性）与必做验证沿用该文件既有约定。

## 触发条件

- 题面出现决策变量（订购量、生产批量、定价、种植面积、切割方案）与成本/收益/风险目标，约束涉及产能、库存、时段、逻辑或资源上限。
- 常见问链形态：前一问做预测或评价（需求预测、供应商评价），后一问把其输出作为参数进规划——决策是终点，前置模块是输入。
- 数据形态：交易流水/计划表（定价补货类）、工序参数与检测记录（生产决策类）、多年地块收益表（种植策略类）；常有随机性来源（需求波动、检测不确定、气候风险）需显式处置。
- 时间结构常在：多周期滚动（周补货、年轮作）、阶段依赖决策（先检验后生产），阶段间状态传递是建模对象。
- 与仿真/路径规划域的分界：主问是"选多少/怎么排"的决策优化，不是过程演化模拟；随机性只作为目标或约束的参数进入，不主导推演。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面（含 `../distilled_modeling.md` 优化类既有红线的落点）：

1. **多目标不加权不分层直接联立**：目标间冲突时可行域塌缩无解，或权重任意拍定无依据——获奖论文以评价先行定序（2021-C）、风险度量进目标（2024-C）两种方式显式处理。
2. **约束搬运不全**：题面约束逐条核对前就求解，漏列的约束（逻辑互斥、轮作顺序、服务时长）使解只对松弛问题最优，回代原题即不可行。
3. **元启发式裸跑无基线**：遗传/差分进化直接交付解，无小规模精确对照、无收敛曲线、无随机种子稳定性——解质量只剩"跑出来了"。
4. **预测与决策脱钩**：预测模块按拟合误差调参，不看下游库存成本与服务水平；预测"准了"决策照样差（2022-E 获奖动作的反面）。
5. **解不回代检查**：不把解逐条代回约束复算违反量、不重算目标值，求解器返回的"最优"与题面口径的对账缺席。
6. **异常/分支情形漏角**：只建正常流程模型，题面明示的例外情形（切割余料上限、检测分支、极端天气）无方案——分支处理本身就是这些题的采分点（2021-D、2024-B 均单列情形）。
7. **随机性不固定不可复现**：随机优化多次运行结果漂移，不报种子与波动幅度，结果无法复核。
8. **灵敏度摆设化**：扰动不会改变结论的参数做展示，会翻转结论的参数（价格、产能、风险厌恶水平）反而不动——对齐 `../winning_patterns.md` 第 6 条"先选会改变结论的参数"。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面为实现方基于方法链组合结构的归纳（提取记录仅含方法名与链序，无论文自述动机字段）；动作与结构按提取报告转述，我方未复算。

### A1 评价先行：多指标评价作优化前置

- 基线失效：供应商/方案属性是多指标向量（价格、供货能力、稳定性），直接写进目标函数要么加权任意、要么维度爆炸；哪些量进优化、哪些先进排序，无结构依据。
- 机制：先用多指标评价（TOPSIS 类）把对象向量压成有序分数/分级，分级结果作为规划中的优先序或选择约束进入决策——评价解决"怎么比"，规划解决"怎么选"，职责分开。
- 前提/接口：对象属性表完整且可量化；评价指标权重有依据（数据离散度或题面语义）；输出为逐对象分数表，供规划的决策变量定义域或目标系数引用。
- 反例：指标高度相关时评价分数被单一维度主导；把评价分数直接当收益加进目标函数则量纲混乱——分数只定序，不定值。
- 迁移边界：迁移"评价定序、规划定量"的分工结构；指标体系与聚合方式按新题属性重定。
- 证据：论文方法链提取（2021-C）｜source_checked

### A2 需求预测作优化输入的前端模块

- 基线失效：多周期决策（生产安排、补货）需要未来各期需求作参数，直接用历史均值或最近一期订单当需求——趋势与季节性全丢，下游排产/订货量系统性偏差，且偏差随周期数放大。
- 机制：题给历史序列先过时间序列预测（指数平滑族），逐期预测值作为规划模型的参数输入；预测模块单独验证（拟合与外推口径分开），其误差再作为后问灵敏度分析的扰动源。
- 前提/接口：历史序列足够长且口径一致；预测输出逐期进入规划参数位；预测误差分布用于构造后问情景。
- 反例：序列有结构突变（政策变更、疫情段）时全历史平滑预测失真，需分段或加哑变量；预测外推期数远超历史覆盖时是外推不是预测，须单独声明可信度。
- 迁移边界：迁移"先预测、后决策、误差进灵敏度"的管线结构；预测模型按序列形态（趋势/季节/突变）选择。
- 证据：论文方法链提取（2022-E）｜source_checked

### A3 预测参数与决策目标联合调准

- 基线失效：预测平滑参数按拟合误差（MSE 类）调优后就交差，拟合最优不等于决策最优——下游库存成本、缺货损失、服务水平对预测偏差的敏感方向不同，两个口径可能选出不同参数。
- 机制：把下游决策效果（库存-服务水平联合指标、利润）作为预测参数调准的目标或检验口径，用启发式分趋势调参——参数由决策后果驱动，拟合误差降为辅助诊断。
- 前提/接口：下游决策模拟器可复算（给定预测序列能算出成本/服务水平）；调参留出验证期防过拟合；参数-决策对照表进正文。
- 反例：验证期数据少时按决策口径调参同样过拟合；决策模拟本身有随机性时不控制方差，调参信号被噪声淹没。
- 迁移边界：迁移"参数调准口径对齐最终决策目标"的原则；具体联合指标按新题成本结构设计。
- 证据：论文方法链提取（2022-E）｜source_checked

### A4 决策变量离散化 + 决策空间分层搜索

- 基线失效：决策变量天然离散（切割方案、批次组合、地块分配）且组合爆炸，连续松弛后四舍五入的解不可行或远离最优；纯遍历算不动，纯元启发式又无最优性证据。
- 机制：先把问题写成整数规划定清变量与约束，再用分层搜索策略——小规模枚举做精确基准，大规模用启发式规则（按优先序贪心）或元启发式（遗传/差分进化）搜索，两者结果对照报告差距。
- 前提/接口：决策变量可明确取值域；整数规划式先落纸（变量、目标、约束三表）；启发式与枚举在同一小规模算例上对齐口径。
- 反例：变量取值域连续量硬离散化（如任意实数订购量）引入人工误差，应先判变量真实离散性；约束非线性强时整数规划式写不全，纯启发式须配多起点。
- 迁移边界：迁移"规划式先行、分层搜索、小规模对照"的结构；搜索算法按问题规模与非凸程度选择。
- 证据：论文方法链提取（2021-D、2024-C）；"小规模精确基准对照"结构源自 ../distilled_modeling.md 必做验证约定，非论文动作直引｜source_checked

### A5 抽样方案由功效函数反推

- 基线失效：检验/抽检类子问的样本量直接沿用题给数量或经验拍定，"抽多少"无推导——两类错误概率与样本量的关系不可见，后续决策（是否检测、检测几件）的置信水平无从论证。
- 机制：写出检验的功效函数，把样本量与第一/第二类错误概率的解析关系导出，按题给风险要求反解所需样本量；抽样方案从假设变成推导结论，检测分支的期望利润模型直接复用该结果。
- 前提/接口：明确原假设、备择假设与可接受错误水平；分布族已知（二项/正态类）；输出样本量进入后续期望计算与成本核算。
- 反例：分布假设不成立（次品率极小时正态近似失效）时功效函数失真；错误水平本身无题面依据时反推出的样本量只是循环论证。
- 迁移边界：迁移"样本量是推导量不是拍定量"的纪律；检验类型与分布按新题数据形态选择。
- 证据：论文方法链提取（2024-B）｜source_checked

### A6 状态概率的贝叶斯序贯更新

- 基线失效：产品状态概率（合格率、次品率）用单点估计一次定死，检测结果这类新信息无法利用——多阶段决策（先抽检、再决定是否全检）在第二阶段还在用第一阶段的旧信念，决策规则与信息价值脱节。
- 机制：以共轭先验（Beta 类）描述状态概率分布，每批检测结果进似然更新后验，后验期望进各分支的期望利润计算；决策树每个信息节点挂当前后验，阶段间信念演进可追溯。
- 前提/接口：先验来源可辩护（历史数据或无信息先验）；似然与抽样机制对齐（有放回/无放回）；输出后验分布供期望模型与后续阶段引用。
- 反例：先验强且数据少时结论被先验主导，须做先验敏感性；抽样非独立（同批次相关）时更新公式高估信息量。
- 迁移边界：迁移"信念随信息更新、决策挂后验"的结构；先验-似然组合按新题的状态空间重定。
- 证据：论文方法链提取（2024-B）｜source_checked

### A7 风险度量进目标函数

- 基线失效：多年期/多情景决策只优化期望利润，收益分布的尾部（歉收年、需求崩塌）被平均掩盖——期望最优的方案在坏情景下可能不可接受；用方差惩罚则度量无风险语义且对上下偏差不对称。
- 机制：把条件风险价值（CVaR 类，坏情景尾部期望损失）作为独立目标或约束进入规划，与利润目标构成双目标——决策者可沿"利润-风险"前沿选择，而非单点；置信水平作为可调参数。
- 前提/接口：情景集合或收益分布可估（历史数据或仿真）；CVaR 的线性化表达与原规划兼容；输出有效前沿或风险约束下的最优解表。
- 反例：情景分布由小样本估计时尾部本身不准，CVaR 值随置信水平剧烈波动；情景覆盖不含真实极端事件时风险约束是假安全。
- 迁移边界：迁移"期望之外显式定价尾部风险"的结构；风险度量与置信水平按新题风险语义选择。
- 证据：论文方法链提取（2024-C）｜source_checked

### A8 精确算法与元启发式交叉验证

- 基线失效：单一元启发式（遗传/模拟退火/粒子群）的解没有最优性参照——解好解坏无从评价，收敛与否只看迭代曲线饱和，换个种子结果漂移。
- 机制：缩小规模构造可枚举算例跑精确解作基准，正式规模上双算法（如差分进化与遗传）交叉验证、多起点重跑报分布；解质量用"与小规模最优的差距 + 跨算法一致性 + 种子稳定性"三重证据支撑。
- 前提/接口：存在可缩小的子问题（子集地块、单周期）；两算法共享同一目标与约束实现；收敛判据与运行预算显式报告。
- 反例：缩小后的算例失去原问题结构（约束耦合被切断）时基准失效；两算法共享同一编码错误时交叉验证给出一致的错解——先做解析特例再谈交叉。
- 迁移边界：迁移"基准-互核-稳定三重解质量证据"的结构；基准构造与算法对按新题规模选择。
- 证据：论文方法链提取（2024-C 差分进化+遗传混合算法；交叉验证与多起点结构见 2025-A——属仿真路径域动作，此处引为同构证据；跨题观察：智能优化算法出现于 25 篇中 8 篇）｜source_checked

### A9 情景化灵敏度围绕结论稳定性

- 基线失效：优化题只交最优解不给稳健性——参数（价格、产量、概率）是估计值，最优解对其敏感则结论脆弱；无扰动分析的"最优"在评审处等于未验证。
- 机制：先指认会改变结论的参数（目标系数、右端项、随机参数），按扰动依据做单因素或情景分析，报告结论是否翻转；与 A7 风险度量配合时，灵敏度沿风险-利润前沿做。
- 前提/接口：扰动范围有依据（历史波动、估计误差、题面允许范围）；输出为参数-目标/解的变化表与结论翻转标记。
- 反例：只扰动不会改变结论的参数是摆设；扰动幅度无依据时"稳健"结论不可信；离散决策变量下解跳变（解结构切换）比目标值变化更是结论信号。
- 迁移边界：迁移"选会翻结论的参数、报翻转与否"的纪律；扰动设计按新题参数语义选择，对齐 `../winning_patterns.md` 第 6 条。
- 证据：论文方法链提取（2024-C；2022-E 参数-服务水平联动同思路）｜source_checked

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 约束遗漏/解不可行 | 解逐条代回约束复算违反量，违反计数入结果表（对应翻车点 2/5） |
| 解质量无证据 | 小规模精确对照 + 双算法互核 + 多种子稳定分布（A8） |
| 目标失真 | 目标函数用解重算，与求解器报告值对账；多目标时给前沿而非单点（A7） |
| 预测-决策脱钩 | 预测参数按决策口径调准并留验证期；预测误差进情景分析（A2/A3） |
| 情形漏角 | 分支/异常情形清单与题面逐条核对表，每情形有处置方案（对应翻车点 6，A5/A6 分支） |
| 样本量/信念无据 | 功效函数反推样本量；先验敏感性与更新链路可追溯（A5/A6） |
| 结论脆弱 | 会翻结论参数的灵敏度分析，翻转与否显式报告（A9） |
| 不可复现 | 随机种子、迭代次数、收敛判据写进附录；关键结果多起点复跑 |

## 写作重点

- **决策链叙事**：摘要按"预测/评价 → 规划建模 → 求解 → 灵敏度"的问链写，每个前置模块显式声明输出去向（进哪个参数位），不写成独立小作文。
- **建模透明**：变量、目标、约束三表先行，逐约束标注题面出处——评审核对建模完整性靠这张表，不靠正文段落。
- **解质量证据进摘要**：与小规模最优的差距、算法间一致性、种子稳定性择要写入摘要，"遗传算法求解"六个字不构成解质量主张。
- **分支与情形成表**：检验分支、异常情形、极端情景的处置单独列表，每行有进入条件和方案——这些是本题采分点，藏在正文段落里等于没写。
- **灵敏度围绕结论**：报告哪个参数变多少会翻转结论，而不是罗列扰动图；方案切换点（离散解跳变）单独指出。
- **数字对账**：摘要关键数值（最优目标值、灵敏度阈值、样本量）与正文表、求解输出逐一对账后再交稿，对齐 `../winning_patterns.md` 第 8 条。

舍弃记录：候选池一条不单列——"TOPSIS 多指标评价"在 2021-C 中是 A1 评价先行结构的实现件而非独立迁移面（评价定序的具体算法按新题指标形态选择，单列则五要素与 A1 大面积重复），并入 A1 机制；"动态规划记忆化搜索"（2021-D、2024-B）为求解器实现细节，其迁移价值已由 A4（分层搜索）与 A6（序贯信念）覆盖，不单列。
