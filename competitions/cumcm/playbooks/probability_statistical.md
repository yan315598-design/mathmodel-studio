# 概率/统计建模域 Playbook

证据锚点约定：**论文方法链提取** = `analysis/lit_survey/cumcm_paper_methods.md`（2021-2025 各年 A-E 题获奖论文 25 篇摘要级提取）。本域证据基础最薄，仅两题：2023-E（黄河水沙监测预测）、2024-D（深弹命中概率）——条目数按证据定，从少。**我方实验** = 无（本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域对应"统计预测"类（时序演化与不确定性），必做验证（残差、时间滚动验证、预测区间、结构突变检查）沿用该文件既有约定；命中概率类兼涉"仿真模拟"的解析特例验证。

## 触发条件

- 任务核心是概率结构或时序演化本身：求概率/期望的解析表达（命中概率、传输期望）、水文气象量的多尺度演化分析与预测（水沙关系、趋势与突变）。
- 数据形态：长历史时序（年/月粒度、含季节性与丰枯周期）或题给概率/几何参数——前者靠结构分解建模，后者靠概率推导计算。
- 典型问链：时序类先诊断结构（趋势、突变、周期）再预测外推；概率类先建概率表达再优化参数（定深、引信参数）——诊断与推导是主体，机器学习不是默认工具。
- 与机器学习/数据分析域的分界：主问是分布/概率/时序结构的推断，不是判别或预测任务的样本建模；题给数据小或无数据（参数题），统计结构推导重于数据驱动。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面：

1. **全程单趋势拟合掩盖变点**：整段历史一条回归线，水沙关系的年代际变化被平均——突变年份两侧关系不同，拟合优度尚可但外推全错（2023-E 获奖论文以突变检验 + 分段拟合为结构）。
2. **季节与趋势混同建模**：原始序列直接对时间回归，季节项、趋势项、残差纠缠——残差自相关严重、预测区间失效（获奖论文先做结构分解再建模）。
3. **概率题不建几何/物理结构**：命中/成功当伯努利单一概率处理，忽略目标区域几何与落点分布的空间结构——概率是分布 over 几何区域的积分，与参数（定深、落速）的依赖关系无从表达（2024-D 获奖论文以联合密度 + 三重积分建模）。
4. **积分限不随情形切换**：几何相对关系（目标层与引爆深度的位置组合）不同时积分区域不同，一套积分限硬套全部参数组合——部分情形下积错区域（获奖论文分类推导各情形）。
5. **预测交点值不交区间**：外推结论只报预测值，无区间与不确定性——时序外推的置信随步长衰减不可见（对齐 `../distilled_modeling.md` 统计预测类"预测区间"必做验证）。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面为实现方基于方法链组合结构的归纳（提取记录仅含方法名与链序，无论文自述动机字段）；动作与结构按提取报告转述，我方未复算。

### A1 突变/变点检验先于建模

- 基线失效：环境时序存在年代际转折（水沙关系变化）时，整段拟合把转折前后两种机制平均成一条线——拟合数字不差，但机制失真，转折后段的外推用错了机制，且"平均线"对任何一段都不适用。
- 机制：先用变点诊断（累积距平定位候选点 + 突变检验确认显著性），确认变点后分段建模；变点本身作为环境演化的结论之一交付（何时变、变向哪），不只是预处理。
- 前提/接口：序列长度足以分段（每段有可估样本量）；检验方法的前提（独立性/分布）核对或声明；输出变点时刻表供分段建模与预测解释引用。
- 反例：序列短、噪声大时检验功效不足，伪变点与真变点难分——须多方法互证；变点成因（工程拦截、气候）题面可考时，成因解释比统计显著性更有说服力。
- 迁移边界：迁移"先诊断结构再建模，变点是结论不是噪声"的顺序；诊断方法按序列长度与形态选择。
- 证据：论文方法链提取（2023-E 累积距平 + M-K 检验 + 分段最小二乘）｜source_checked

### A2 时序结构分解与季节建模

- 基线失效：趋势、季节、多周期成分混在原始序列里，单一模型（直接回归或单阶差分）抓得住其中一个就抓不住其余——残差携带未建模结构，预测区间与滚动验证双双失效。
- 机制：序列按尺度分解处理——季节分解（季节-趋势-残差分层）、小波分析定位显著周期尺度，趋势与季节结构显式化后再对残差建模；季节项进预测模型（SARIMA 类），预测按结构重组。
- 前提/接口：序列覆盖足够多个周期；分解参数（季节周期长度、小波尺度）有物理解释（丰枯周期、汛期结构）；残差诊断（自相关、正态性）通过后模型才可用。
- 反例：序列长度不足两个周期时季节结构不可辨识，硬分解是拟合噪声；周期长度拍定（不由数据定位）时季节项错位，预测系统性偏移。
- 迁移边界：迁移"按尺度分层、结构显式建模、残差干净才算完"的顺序；分解方法与周期设定按新题序列形态选择。
- 证据：论文方法链提取（2023-E 季节分解 + 小波分析 + SARIMA）｜source_checked

### A3 几何概率建模：分布 × 空间结构的积分

- 基线失效：命中/拦截类问题把结果当单一概率值处理——落点/散布的空间分布与目标区域几何的耦合被抹掉，概率对决策参数（定深、落速）的依赖关系无法表达，优化无从下手。
- 机制：落点/深度写成随机变量的联合分布（正态类），命中事件对应几何区域上的概率积分（重积分按区域与密度表达）——概率成为参数的函数，对参数求极值即最优策略；积分区域由几何关系逐情形确定。
- 前提/接口：分布假设有依据（散布特性、误差来源）；几何区域与坐标系定义清晰；输出概率-参数函数表，接数值优化（A5 前置）。
- 反例：散布参数在小样本或题给近似下估计，其误差直接进概率结论，须做散布参数敏感性；变量间独立假设（纵向/横向散布）不成立时联合密度形式要改。
- 迁移边界：迁移"事件概率 = 分布 over 几何区域的积分"的建模位；分布族与区域几何按新题物理重推。
- 证据：论文方法链提取（2024-D 联合正态密度 + 三重积分）｜source_checked

### A4 参数情形的分类推导

- 基线失效：概率积分的区域边界随参数组合切换（引爆深度与目标层的相对位置、触发条件的有无），一套积分表达覆盖全部组合时——部分情形下积分区域与事件定义不符，算出的"概率"对应的是另一个事件。
- 机制：按几何/逻辑相对关系把参数空间划分情形，逐情形写出事件对应的积分区域与积分限，各情形的极值/结论分开给，参数空间的结论图拼接成全景；情形边界（临界参数值）单独求出。
- 前提/接口：划分准则互斥完备；逐情形推导可复查；边界参数值的归属声明（含/不含临界值）。
- 反例：情形数组合增长时先做等价类合并；临界值附近概率对参数敏感（区域突变），优化落点若在临界附近须做边界敏感性分析。
- 迁移边界：迁移"参数空间先划分、逐情形推导、边界单独求"的结构（与仿真/路径域 A2 同构）；划分准则按新题几何/逻辑关系重划。
- 证据：论文方法链提取（2024-D 分情形推导）｜source_checked

### A5 数值积分与数值优化收口

- 基线失效：概率积分无闭式（区域复杂、密度非初等）时硬找解析式卡死或近似失真；概率-参数函数无解析极值时网格搜参数——精度受网格限制且极值点定位粗糙，最优参数的位数撑不起结论。
- 机制：积分用数值方法（离散求积）在统一口径下计算，概率-参数函数以函数形式供数值优化调用求极值；积分精度与优化精度的匹配检查（积分误差小于极值定位精度需求），关键量随离散精度的收敛报告。
- 前提/接口：积分口径全链一致（同网格/同求积式）；优化在参数可行域内做，极值点回代概率函数复核；收敛证据进验证节。
- 反例：积分误差与极值搜索噪声同量级时优化器"找到"的是数值噪声的峰——先压积分误差再做优化；概率面多峰时单起点优化漏解，须多起点或先扫描。
- 迁移边界：迁移"数值积分统一口径 + 函数化进优化 + 精度匹配检查"的收口结构；求积与优化方法按新题函数形态选择。
- 证据：论文方法链提取（2024-D 数值优化；2023-E 数值积分同构）｜source_checked

## 图表组合

按四层证据组织图组：

- **结构层**（问题长什么样）：序列全景图（时序 + 水平/趋势参考线 + 缺测标注）；几何/概率结构示意（坐标系、目标区域、散布分布形态，A3）；参数-情形空间划分图（A4）。
- **机制层**（机制为何这样设计）：变点诊断图（累积距平曲线 + 检验统计量，A1）；结构分解分层图（季节/趋势/残差，A2）；概率积分区域示意图（逐情形区域与密度叠加，A3/A4）。
- **结果层**（结论证据）：分段拟合对照图（变点前后分别拟合，A1）；预测值与区间带（外推段区间随步长展宽，A2）；概率-参数函数曲线与极值标记（A5）；逐情形结论表（A4）。
- **可信边界层**（哪里不可信）：滚动验证误差曲线（分步长退化，A2）；散布/分布参数敏感性（A3）；情形边界敏感性（A4）；积分/优化精度收敛证据（A5）。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性边框/背景色块；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 变点漏检/伪变点 | 多方法互证（距平定位 + 检验确认）；分段前后残差对照（A1） |
| 结构建模不全 | 残差自相关与白噪声检验；时间滚动验证分步长报误差（A2） |
| 分布假设失真 | 散布参数敏感性；分布拟合优度检验（A3） |
| 情形积分错位 | 逐情形区域图与推导对照；临界参数附近边界敏感性（A4） |
| 数值精度不足 | 积分/优化收敛曲线；极值点回代复核（A5） |
| 外推可信度不明 | 预测区间随步长的展宽报告；域内拟合与外推误差分开（A2） |

## 写作重点

- **结构诊断先行叙事**：时序类摘要先给结构结论（趋势、变点、周期）再给预测，"先诊断后建模"的顺序本身是方法贡献；概率类摘要先给事件-区域-分布的建模结构再给数值。
- **区间与点值并报**：所有预测/估计结论带区间或误差口径，点值裸报在本域不可信；外推段的区间展宽写进结论。
- **分段与分情形成表**：变点分段、参数情形的划分准则、逐段/逐情形结论、边界归属全部成表——可复查性是本域评审重心。
- **假设的物理辩护**：分布假设、独立性假设、变点成因给出物理/水文/军事语义的解释，纯统计显著性不单独构成结论。
- **参数依赖讲透**：概率-参数函数的形态（单调性、峰值、临界切换）是优化结论的机制支撑，摘要报极值参数及其邻域稳健性，不只报最大概率值。
- **数字对账**：概率值、区间界、变点年份等关键数与正文表逐一对账（对齐 `../winning_patterns.md` 第 8 条）。

舍弃记录：候选池一条不单列——"回归分析 + 最小二乘拟合"（2023-E 前置动作）为通用统计件，其分段使用的价值已由 A1（变点先行 + 分段建模）覆盖，单列则五要素与 A1 大面积重复；"灰色关联分析"类评价动作（2022-C/2023-C 均见）属机器学习/数据分析域 A4 关联轨候选件，本域两篇提取记录中不构成独立方法链主干，不入库。
