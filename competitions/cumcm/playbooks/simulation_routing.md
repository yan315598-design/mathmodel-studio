# 仿真/路径规划域 Playbook

证据锚点约定：**论文方法链提取** = 2021-2025 各年 A-E 题获奖论文 25 篇摘要级提取（提取过程记录为内部审计产物，分发版不含，证据为本文档归纳归属）。本域证据主体为其中 2022-D（气象报文卫星通信）、2023-D（圈养湖羊空间利用）、2025-A（无人机烟幕遮蔽）、2025-D（矿井突水逃生）四题；**我方实验** = 无（本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域对应"仿真模拟"与"网络与路径"两类，必做验证（解析特例、置信区间、样本量收敛、随机种子复现 / 连通性、流量守恒、路径全程可行）沿用该文件既有约定。

## 触发条件

- 任务核心是过程推演或网络流动：随机/演化过程求概率与期望（传输次数、损失期望）、空间过程仿真（水流漫延、烟幕遮蔽）、网络上的路径与调度（逃生路线、空间分配）。
- 数据形态：题给规则/参数 + 需自建的仿真器或图模型；常无现成数据集，验证靠解析特例与模拟互核。
- 典型问链：先建过程/网络模型（能算），再优化策略（怎么调）——模型可计算是优化可比选的前提；或全题就是"证明 + 计数 + 验证"的离散结构推导。
- 空间结构常见：巷道网、栅格空间、观测几何——空间要么离散成图，要么作为连续几何判别进仿真。
- 与优化决策域的分界：随机过程或网络演化本身是建模对象，不是给优化供参数的模块；与几何/物理建模域的分界：主问是过程/流动/路径，不是单一物理量的机理推导。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面：

1. **只交模拟数不交公式**：仿真器跑出结果就交卷，无解析推导对照——实现逻辑错误（事件顺序、边界处理）在纯模拟里不可见，结论只有数字没有机制（2022-D 获奖论文以推导 + 模拟双轨为结构）。
2. **情形空间漏角**：参数组合落入不同几何/逻辑分支（报文格式组合、水流分岔），只对部分分支推导或模拟——结论在未覆盖分支上静默失效（获奖论文均做分类讨论穷尽）。
3. **仿真无方差证据**：蒙特卡洛结果只报单次值，不给样本量收敛与置信区间——随机波动与结论差异不可区分（对齐 `../distilled_modeling.md` 仿真类必做验证）。
4. **静态网络算时变问题**：边权/连通性随过程演化（巷道漫淹、路段封闭）时用静态最短路一次算完——路径中段不可行，逃生方案形同虚设（对齐 `../distilled_modeling.md` 网络类"时变网络不能直接用静态最短路"）。
5. **混合决策空间直接联搜**：离散分配（谁遮蔽谁、哪只羊进哪栏）与连续参数（投放入点、时刻）耦在一个空间里搜，搜索维度高且结构混杂，收敛慢且易早熟（2025-A 获奖论文分层处理）。
6. **过程规则自定不自检**：仿真规则（分流比例、传播速率、遮蔽判定）自行设定后直接产出结论，无守恒/边界情形复核——规则错则全盘错且不可见。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面为实现方基于方法链组合结构的归纳（提取记录仅含方法名与链序，无论文自述动机字段）；动作与结构按提取报告转述，我方未复算。

### A1 解析推导与程序仿真双轨互证

- 基线失效：纯模拟交付只有效字无机制——事件顺序、边界处理的实现错误不可见；纯推导交付则公式错误无独立通道暴露——两轨各自的单点故障在对方轨道上是显性的。
- 机制：解析轨先推公式（计数、期望、传播关系），仿真轨独立实现过程模拟，两轨在同一算例对账，差异定位到推导或实现的错误源；正式结论由解析轨给机制、仿真轨给数值证据。
- 前提/接口：两轨实现相互独立（不共享中间推导）；对账算例从简单到复杂分级（先特例后全题）；差异解释逐条记录。
- 反例：仿真规则本身简化过度（忽略题面某机制）时两轨"一致地错"——规则假设清单要先与题面核对；组合爆炸类问题解析式可能推不全，只能局部对账。
- 迁移边界：迁移"推导给机制、仿真给数值、独立对账"的双轨结构；对账粒度按新题复杂度定。
- 证据：论文方法链提取（2022-D）｜source_checked

### A2 情形分类穷尽论证

- 基线失效：参数与几何条件组合落入不同逻辑分支（格式组合、几何相对关系），统一公式强行覆盖或只模拟常见分支——分支切换处的积分限、计数式、判别条件不同，覆盖不全则结论在边界处静默出错。
- 机制：先枚举分支变量（离散组合）或几何退化关系（连续参数的区间划分），逐情形推导或建模，各情形结论拼成全空间覆盖；分支清单与题面条件逐条对照，完备性显式声明。
- 前提/接口：分支划分准则互斥且完备（划分式写出）；逐情形结果表进正文；分支边界处单独核验（连续量在边界两侧衔接）。
- 反例：分支数随变量数组合增长，枚举前先做对称性/等价类合并；连续分支的边界（相切、恰好在临界值）本身是高概率出题点，不能当测度为零跳过。
- 迁移边界：迁移"先划分支、逐情形推导、完备性声明"的结构；分支准则按新题的参数与几何结构重划。
- 证据：论文方法链提取（2022-D 分类讨论证明；2024-D 五情形推导同构，见概率统计域）｜source_checked

### A3 蒙特卡洛期望进优化目标

- 基线失效：决策后果含随机损失（死亡、伤残、损耗）时无确定性目标函数可写——期望损失要经过随机过程演化才显现，确定性优化框架接不住。
- 机制：损失过程建成随机模拟（概率事件逐次实现），期望损失由大样本平均估计，估计量作为优化目标的评价函数——随机性从"障碍"变成目标的组成成分；样本量收敛证据先行。
- 前提/接口：随机事件概率题给或可假设（假设声明）；单次评估的方差受控（或用共同随机数便于方案间比较）；期望估计的置信区间随方案表报告。
- 反例：不同方案用不同随机流则方案间比较混入抽样噪声，应共随机数；小概率高损失事件抽样稀疏，期望估计不稳定，需尾部加密采样；模拟进优化内环时算量爆炸，考虑代理模型。
- 迁移边界：迁移"随机后果 → 模拟估计期望 → 期望进目标"的结构；损失过程与采样设计按新题风险语义重定。
- 证据：论文方法链提取（2023-D）｜source_checked

### A4 分层优化解耦混合决策空间

- 基线失效：离散分配变量与连续参数变量混在一个搜索空间，元启发式的交叉变异算子对两类变量语义不匹配——搜索在混合空间里低效且早熟，好结构（分配方案）配差参数或反之。
- 机制：按变量性质分层——先解离散分配层（组合结构，可用枚举/匹配类方法在小规模上做准），再在固定分配下解连续参数层（低维连续优化），层间可迭代反馈；每层用与其结构匹配的求解器。
- 前提/接口：分配层与参数层目标可分解（参数层最优值作为分配层评价函数可调用）；层间迭代次数与收敛判据报告；两层解合成后回代完整目标复算。
- 反例：层间强耦合（参数可行性反过来否决分配）时分层漏掉联合最优，须给层间反馈或耦合约束前移；分配层规模大时其内部枚举同样爆炸，分层不豁免组合爆炸。
- 迁移边界：迁移"按变量性质分层、层间反馈、合成复算"的结构；层次划分按新题决策变量结构重定。
- 证据：论文方法链提取（2025-A 先任务分配后参数）｜source_checked

### A5 几何/物理条件转布尔判别函数

- 基线失效：遮蔽、可见、连通这类条件以自然语言表述时无法进数值搜索与仿真循环——"烟幕挡住视线"不落成可计算的判别式，搜索算法与仿真器都没有可执行的可行性语义。
- 机制：把条件写成几何/物理量的布尔函数（视线-烟幕相交判别、位置-区域包含判别），判别函数成为仿真的事件触发器与优化的可行性约束；条件边界（相切、临界时刻）由判别函数的零点定位。
- 前提/接口：判别所需的几何量（位置、边界、方向）可由状态变量算出；判别函数对时间/参数连续或分段；输出布尔序列或事件时刻表。
- 反例：几何对象有厚度/容差时判别边界模糊（恰在边界上的判定规则要显式）；判别函数不连续处事件触发漏检，循环步长要自适应；多维条件复合时先化简再判别，不然算量失控。
- 迁移边界：迁移"条件语言化 → 判别函数化 → 进搜索/仿真"的结构；判别式按新题几何/物理条件重写。
- 证据：论文方法链提取（2025-A 遮蔽布尔判别）｜source_checked

### A6 时变网络动态重路由

- 基线失效：网络状态随过程演化（巷道逐步漫淹、路段封闭）时静态最短路一次算完——路径后段在走到之前已被淹没，方案不可执行；且淹没进程与人员移动是耦合过程，拆开算失真。
- 机制：把状态传播（漫延/封闭过程）建成网络演化模型，边权/可用性随时间更新；路径决策与过程推进同步——按当前与预测状态计算可行路径，事件触发重路由；全程可行性（每段通过时刻该段可用）显式核验。
- 前提/接口：过程演化模型先行（速率、分流规则）；时间离散粒度与过程速率匹配（粒度过粗漏掉封闭窗口）；输出路径-时刻表及全程可行性核验列。
- 反例：过程速率不确定时单一速率方案脆弱，须做速率情景对照；人群多路径并行时容量约束（通道吞吐上限）要建模，否则方案在瓶颈处失效；重路由过于频繁则方案不可执行，触发阈值要定。
- 迁移边界：迁移"状态传播与路径决策同步、全程可行性核验"的结构；过程模型与重路由触发规则按新题演化机制重定。
- 证据：论文方法链提取（2025-D 漫延仿真 + 实时最短路）｜source_checked

## 图表组合

按四层证据组织图组：

- **结构层**（问题长什么样）：网络拓扑/空间结构图（节点、边、区域划分，边权物理意义标注）；过程机制示意（演化规则、事件触发关系）；参数与假设对账表（题给 vs 自定，自定项标依据）。
- **机制层**（机制为何这样设计）：双轨结构图（解析轨与仿真轨的对账点，A1）；分支划分树（情形空间覆盖图，A2）；分层优化架构图（层间反馈流向，A4）；判别函数结构（条件到几何量的映射，A5）。
- **结果层**（结论证据）：方案对照表（策略、目标值、全程可行性）；解析 vs 仿真的对账表（A1）；时变过程快照图（关键时刻网络状态与路径位置叠加）；期望损失的收敛曲线与置信区间（A3）。
- **可信边界层**（哪里不可信）：样本量/离散粒度收敛曲线；随机种子稳定性（关键结论多次复跑分布）；速率/概率参数的情景敏感性；自定规则假设的影响对照（改规则结论变多少）。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性边框/背景色块；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 实现逻辑错 | 解析特例对账（简单算例两轨一致才放行，A1） |
| 情形漏角 | 分支清单与题面条件逐条对照表 + 边界衔接核验（A2） |
| 随机波动误判 | 样本量收敛曲线 + 置信区间 + 种子复现（A3） |
| 时变可行性失守 | 路径-时刻表逐段可用性核验；离散粒度敏感性（A6） |
| 分层丢联合最优 | 合成解回代完整目标；与不分层小算例对照（A4） |
| 判别边界模糊 | 判别函数连续性检查 + 边界情形单独复核（A5） |
| 规则自定失真 | 规则假设清单与题面核对；关键规则变化的影响对照 |

## 写作重点

- **双轨叙事**：摘要按"解析建模给机制、程序仿真给数值、两轨对账"写，只报模拟数不报公式的结构在本域不可信。
- **假设对账表**：自定的过程规则、概率、速率逐项列表标依据（题给/常识/假设），假设的影响在可信边界层量化——自定参数不留清单是本域最大失分点。
- **情形覆盖显式**：分支划分式与完备性声明进正文，逐情形结果表可查；边界情形（临界参数）单独讨论。
- **可行性证据**：路径/方案交付必附全程可行性核验（每段通过时刻可用），只给"路径长多少"不给"能否走通"是半成品。
- **收敛证据摘要化**：蒙特卡洛置信区间、种子稳定性、粒度收敛的结论句进摘要或验证节，随机结果的表述带区间不带点值。
- **空间图交付过程**：演化过程用时间快照序列图呈现（图内标注纪律下叠加路径与状态），过程可视是本域评审理解方案的最快通道。

舍弃记录：候选池一条不单列——"BFS 广度优先搜索定漫延范围"（2025-D）为图遍历标准件在 A6 过程模型内的实现构件，无论文自述的失效对照可锚定独立五要素，并入 A6 机制叙述；"多起点变步长搜索"（2025-A）为通用求解策略，其证据价值已被优化决策域 A8（解质量三重证据）覆盖，不重复入库。
