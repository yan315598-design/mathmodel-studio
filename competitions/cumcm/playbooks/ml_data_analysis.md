# 机器学习/数据分析域 Playbook

证据锚点约定：**论文方法链提取** = `analysis/lit_survey/cumcm_paper_methods.md`（2021-2025 各年 A-E 题获奖论文 25 篇摘要级提取）。本域证据主体为其中 2021-E（中药材鉴别）、2022-C（古代玻璃成分分析与鉴别）、2025-C（NIPT 时点优化与胎儿异常判定）、2025-E（姿态识别体能测）四题；**我方实验** = 无（本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域对应"统计预测""评价与排序""图像识别""信号处理"四类的数据侧合集，必做验证（受试者级划分、类别不平衡指标、数据泄漏检查、校准）沿用该文件既有约定。

## 触发条件

- 任务是判别/分类/预测（类别鉴别、产地判别、风险判定、成绩预测），数据是题给测量表（光谱、成分、生化指标、关键点序列），而非可写出的物理骨架。
- 数据形态有强先验可利用：成分数据（各行总和受限）、比例数据（区间量）、光谱信号（散射与噪声）、重复测量（同一主体多时点）——预处理变换是否踩中数据生成机制，直接决定后续模型上限。
- 常见问链分层：先"哪些变量/成分有关联"（统计检验），再"能否鉴别/预测"（分类回归模型），后问可能是决策优化（检测时点选择）——统计与学习各司其职。
- 类别结构常不均衡（风化/未风化、异常/正常样本量悬殊），且主体重复采样普遍——划分口径与指标选择是第一设计决策。
- 与几何/物理建模域的分界：无可绕过的机理骨架，数据的统计结构就是全部信息来源；与概率/统计建模域的分界：主问是判别/预测任务而非概率分布建模或时序演化机理。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面（含 `../distilled_modeling.md` 既有红线的落点）：

1. **成分/比例数据直接进欧氏统计**：行列和受限的成分数据不做变换就做相关、聚类、降维，闭合效应制造伪相关；获奖论文以成分数据专用变换入场（2022-C），这是该题方法链的第一块砖。
2. **同主体样本跨集泄漏**：重复测量/多时点数据按行随机划分，同主体样本同时进训练与测试集，指标虚高（对齐 `../distilled_modeling.md` 图像识别类"同一对象相邻帧不能随机分"红线）；划分单元必须与主体对齐。
3. **类别不平衡只报准确率**：少数类（异常、风化）占比低时准确率被多数类主导，分类器学成"全预测多数类"还指标好看；混合矩阵与少数类指标缺席。
4. **多重检验不校正**：成百上千个变量逐个检验，家族错误率失控，"显著"结果里假阳性堆积；获奖论文显式做校正（2025-C）。
5. **预处理参数拍定**：滤波窗宽、平滑阶数、变换参数直接用默认或随手设，无选择依据、无对下游任务的影响检查——预处理是隐藏的超参数，比模型参数更早过拟合；在测试集效果上反复调参则是管线级泄漏（参数选择只能在训练折内做、选定后全管线固定，见验证设计）。
6. **单模型裸跑无横评**：一个分类器跑完就交，"为什么用它"无从回答；获奖论文以多分类器同口径横评择优为标配动作（2021-E）。
7. **黑盒交付无误差分析**：只报总指标不拆混淆矩阵，哪类错、错在哪、错多少不知——判别类题的下游使用（鉴别流程）依赖误差结构而非总精度。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面为实现方基于方法链组合结构的归纳（提取记录仅含方法名与链序，无论文自述动机字段）；动作与结构按提取报告转述，我方未复算。

### A1 数据形态先验变换入场

- 基线失效：成分数据（闭合约束）与比例数据（区间量）直接进以欧氏距离/线性运算为内核的统计与模型——闭合效应制造伪相关，比例量的界约束被无视，谱数据的散射与噪声明蔽化学信号；后续模型在错误表示上学到的"规律"部分是表示 artifact。
- 机制：按数据生成机制选变换——成分数据用对数比变换族（CLR 类）解除闭合约束、比例数据用 logit 类拉到实数域、光谱用平滑加归一化（SG+SNV 类）压散射与基线漂移；变换后空间中常规统计才恢复本义。
- 前提/接口：判定数据形态（成分/比例/谱/计数）先于选模型；变换参数记录在案；输出变换空间的数据集与变换式一并交付，下游模型声明工作空间。
- 反例：数据含零值时对数比变换需要替换策略（小量替换或非对称变换），替换引入的偏差要说明；变换不可逆或逆变换放大尾部误差时，结果解释须回原空间验证。
- 迁移边界：迁移"先认数据形态、再选表示变换"的顺序；具体变换按新题数据的生成机制选择。
- 证据：论文方法链提取（2022-C CLR、2021-E SG+SNV、2025-C logit）｜source_checked

### A2 降维 + 度量选择配套

- 基线失效：光谱/成分变量数远超样本数，直接进分类器过拟合；而降维只做 PCA 不配度量，判别类任务要的是类间可分性不是总方差方向——两个经典错位叠加。
- 机制：降维（PCA 类）先压维保留主结构，度量上按任务语义补齐——类别鉴别配判别型度量或散度类指标，聚类配与数据形态匹配的距离；降维后空间中做聚类与分类，主成分的载荷解释进结果（哪些波段/成分承载结构）。
- 前提/接口：变换（A1）先于降维（成分数据在 CLR 空间做 PCA 才有意义）；保留维数由累积贡献与下游任务交叉定；输出降维空间坐标与载荷表。
- 反例：无监督降维方向与判别方向错开时，降维反丢判别信息——须做"降维前后分类性能对照"；载荷解释牵强（成分与波段对应关系不成立）时不要硬解释。
- 迁移边界：迁移"变换→降维→度量配套"的顺序；降维方法与度量按新题任务语义选择。
- 证据：论文方法链提取（2021-E PCA + SID 谱散度）｜source_checked

### A3 多分类器同口径横评择优

- 基线失效：单分类器交付时"为什么用这个模型"只有一句套话；不同分类器的归纳偏置（线性边界/实例距离/概率独立假设/树结构）适配的数据结构不同，不比不知道——且判别类题的模型选择本身就是问链一环。
- 机制：候选分类器族（判别分析/近邻/朴素贝叶斯/决策树类）在同一划分、同一指标口径下平行训练评估，性能与适用性（样本量、可解释性、类别结构）综合择优，横评表进正文。
- 前提/接口：划分与指标全候选统一；逐候选报混淆矩阵不只报单指标；择优理由写成决策记录（性能+结构理由），不只比小数点。
- 反例：候选间性能差异在划分扰动范围内时，"最优"不显著，应报告多次划分的分布而非单次排名；少数类指标不进横评口径时择优偏向多数类。
- 迁移边界：迁移"候选族横评 + 结构理由择优"的论证链；候选族按新题样本量与数据结构组配。
- 证据：论文方法链提取（2021-E 决策树/KNN/朴素贝叶斯/LDA 横评）｜source_checked

### A4 统计关联与判别模型双轨分工

- 基线失效：问链里"哪些变量相关/有差异"与"能否鉴别"是两类问题——只跑分类器答不了关联子问（无检验语义），只做检验交不了鉴别任务（无预测能力）；混在一个模型里两头都说不清。
- 机制：统计轨（卡方检验/相关分析/灰色关联类）回答变量级关联与组间差异，模型轨（树模型/分类器）交付判别能力；两轨结论互证——关联轨给模型的特征以统计语义，模型轨给关联以预测能力证据。
- 前提/接口：检验的适用条件（期望频数、分布假设）逐项核对；模型特征重要性回接检验结论；两轨在同一数据版本上跑。
- 反例：关联显著不等于判别可行（单变量差异小但多变量联合可分，反之亦然），两轨结论冲突时要分析不是回避；多重检验问题在关联轨仍需校正（A6）。
- 迁移边界：迁移"检验管关联、模型管判别、结论互证"的分工结构；检验族与模型族按新题变量类型选择。
- 证据：论文方法链提取（2022-C 卡方检验 + 决策树）｜source_checked

### A5 混合效应模型处理重复测量/面板结构

- 基线失效：同一主体多时点/多批次数据被当作独立样本进普通回归——主体内相关使标准误被低估、检验虚假显著，个体差异混进残差，"平均效应"的置信区间不可信。
- 机制：线性混合效应模型把主体差异放进随机效应（随机截距/斜率），固定效应估总体趋势、随机效应吸收主体内相关；似然比检验比较嵌套模型定随机结构，主体级聚类划分评估外推。
- 前提/接口：主体标识字段完整；变换（A1）先行（比例型响应在 logit 空间建混合模型）；输出固定效应表 + 随机效应方差分量，供后问决策优化引用。
- 反例：主体数少（面板宽而短）时随机效应方差估计不稳；随机结构过度复杂（多维随机斜率）在样本量不支持时收敛失败——从随机截距起步逐项加项并检验。
- 迁移边界：迁移"相关结构进随机效应、趋势进固定效应"的建模位；随机结构按新题重复机制设计。
- 证据：论文方法链提取（2025-C）｜source_checked

### A6 多重检验校正

- 基线失效：高通量变量逐个检验（批量指标、基因组标记）时不校正，单独看每个检验水平合理、合起来假阳性期望随检验数线性增长——"发现"的清单被假阳性污染，下游基于它建模型等于在噪声上盖楼。
- 机制：按检验族统一校正（FDR 类控制错误发现率），校正前后显著集对照成表；显著性阈值与校正方法声明，进入结论的变量集以校正后为准。
- 前提/接口：检验族边界定义清楚（哪些检验算一个家族）；检验间相关性强时校正方法保守性不同，方法选择有依据；输出校正后变量清单供建模继承。
- 反例：家族划太大（把探索性与验证性检验混一族）时校正过度、真信号被压掉；变量高度相关时 FDR 解释要谨慎（相关检验的有效检验数小于名义数）。
- 迁移边界：迁移"批量检验必配家族级校正"的纪律；校正方法按检验数与相关性结构选择。
- 证据：论文方法链提取（2025-C FDR）｜source_checked

### A7 信号事件检测进特征管线

- 基线失效：原始关键点/传感器序列直接进回归，噪声与缺测点污染特征、事件边界（起跳/落地、突变时刻）无法确定——事件时刻这类物理上有明确含义的量被数值噪声淹没，特征失去任务语义。
- 机制：预处理（滤波 + 插值补缺）后做事件检测（一阶微分的极值/阈值定位起止时刻），事件分割的窗口内拟合轨迹（多项式类）提取运动学特征，特征再进统计/模型层——事件检测是特征工程的语义锚。
- 前提/接口：滤波参数的选择在训练折内完成、选定后全管线固定（纪律见翻车点 5 与验证设计）；事件判据的阈值在训练数据上标定并报告；输出事件表（时刻 + 类型）与特征表衔接后续建模。
- 反例：事件密集或幅度小（浅动作）时阈值检测漏检/误检，需局部自适应判据；插值跨度大时事件时刻的插值误差不可忽略，误差要随事件表报出。
- 迁移边界：迁移"滤波→事件定位→窗口特征→建模"的管线顺序；事件类型与特征定义按新题任务物理重定。
- 证据：论文方法链提取（2025-E 一阶微分检测 + 多项式拟合）｜source_checked

按四层证据组织图组：

- **结构层**（问题长什么样）：数据形态与生成机制表（成分/比例/谱/重复测量判定，A1 变换依据）；主体-时点结构图（重复采样模式、划分单元）；类别分布与不平衡度表。
- **机制层**（机制为何这样设计）：变换前后数据结构对照图（CLR 前后相关结构、滤波前后信号）；降维空间散点（按类别着色 + 载荷标注）；混合模型结构图（固定/随机效应位）；管线流程图（预处理→事件→特征→模型）。
- **结果层**（结论证据）：分类器横评表（多指标 + 混淆矩阵，A3）；关联检验表（校正前后对照，A4/A6）；固定效应与方差分量表（A5）；预测性能的划分口径标注（主体级/时点级）。
- **可信边界层**（哪里不可信）：主体级 vs 行级划分的指标对照（泄漏量化）；类别不平衡下的逐类指标；预处理参数敏感性曲线；样本量边界（少数类/主体数对结论稳定性的影响）。

**图内标注纪律**（数据图 Type 3 强制，与 README 一致）：图内不放图名与结论文字，图名和结论写进 caption；保留轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处且正文有对应论证句）；不放图题、结论句、大段说明、数据来源注、装饰性边框/背景色块；多面板各 panel 允许不超过六个中文字符当量的短标签；技术路线图/流程图等示意图的标题条豁免。

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 表示层失真 | 变换前后数据结构对照；成分数据在变换空间做统计并回原空间解释（A1） |
| 数据泄漏 | 划分单元=物理主体；主体级 vs 行级双口径指标对照（对应翻车点 2） |
| 类别不平衡误导 | 混淆矩阵 + 逐类指标进横评口径；少数类零预测触发复核（A3） |
| 假阳性堆积 | 检验族校正，校正前后显著集对照（A6） |
| 重复结构误用 | 随机结构嵌套检验 + 主体级外推评估（A5） |
| 预处理过拟合 | 参数训练折内选择、测试集只用一次；参数敏感性曲线 |
| 事件检测误差 | 事件表带阈值与误差说明；漏检/误检的抽检复核（A7） |
| 单次划分偶然性 | 多次划分的指标分布报告，不只报单次排名（A3） |

## 写作重点

- **表示先于模型**：摘要与问题分析先讲数据形态判定与变换选择，再讲模型——评审从变换是否踩中数据机制判断对题目的理解深度。
- **双轨结论互证**：关联检验与判别模型的结论对照写（哪些变量统计显著、模型是否用到、是否一致），冲突处分析原因——比单轨结论可信得多。
- **指标口径显式**：所有性能数字标注划分口径（主体级/行级、几折、校正前/后），无口径的数字不进摘要。
- **误差分析成节**：混淆矩阵拆解（哪类错向哪类、错样本的共同特征）单独成节，鉴别流程的使用建议基于误差结构给出。
- **变量解释回领域**：载荷、特征重要性、显著变量回到化学/医学/运动学语义解释，与领域常识冲突处显式讨论。
- **局限写样本边界**：主体数、少数类样本量、数据覆盖范围对结论外推的限制具体化，不写"样本有限"套话。

舍弃记录：候选池两条不单列——"K-means/R-Q 型聚类作前置分层"（2022-C、2024-E 时段聚类同构）在提取记录中为描述性/前置动作，摘要级提取无基线失效对照可锚定五要素，并入结构层数据形态叙述与触发条件的问链描述；"梯度提升改进决策树"（2022-C）为 A3 横评候选族的实现件，不单列。另有一条候选"预处理参数带证据选择"（滤波窗宽训练折内选定、全管线固定）起初拟独立成条，因提取层只见预处理动作链顺序，连动作链组合结构都缺，归纳失效面的依据不足，按 README 红线不独立入库——其纪律内容并入翻车点 5 与验证设计"预处理过拟合"行。
