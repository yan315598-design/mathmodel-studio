# 域级 Playbook 层（CUMCM）

## 定位

`../distilled_modeling.md` 回答"这个赛题风险属于哪类、优先走什么路线"；本层回答"**这个域里获奖论文具体做了什么动作、基线为什么不够**"。两者是分层关系：先按内容型范式分类命中本层，再用动作清单补充 stage 3 候选生成，**不替代缺口驱动选型**。

- 本层是**新增层**：不覆盖 distilled_modeling / distilled_figures 等任何既有蒸馏文件。
- 消费方：stage 1 选题命中提示（该题属哪个域）、stage 3 选型（动作清单作为候选生成输入之一）、stage 5 图表组合参考、stage 8 写作侧重。

## 域命名与映射纪律

本层五域按**国赛题型分布**分组（25 篇获奖论文方法链提取的题型统计：优化决策 8 题、几何/物理建模 6 题、机器学习/数据分析 5 题、仿真/路径规划 4 题、概率/统计建模 2 题），每域锚定 `../distilled_modeling.md` 九类内容型范式的一类或数类，不另起范式名。跨域题（如"预测进优化"问链）按主问所属域命中，前置模块动作可跨域引用。

> 题型统计按 25 篇全量计数；下表"证据基础"仅列动作实际引用的题目（21 篇）。余下 4 篇（2021-C 试验设计、2022-B 无源定位、2023-B 测线布设、2024-E 交通管控）已计入题型统计，但其方法与相邻题同构、未形成独立动作锚点，故不在证据基础中单列。

## 六节格式契约（每份 playbook 必须齐）

1. **触发条件**：什么题目特征/数据形态适用本域。
2. **常见翻车点**：必须来自实证（论文方法链提取中获奖动作所超越的常规套路反面），不写通用套话。
3. **惊艳动作清单**（核心节）：每条五要素——基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；每条标注**证据来源**（论文方法链提取）与 review_status（proposed / source_checked / locally_tested）。
4. **图表组合**：该域四层证据（结构/机制/结果/可信边界）各画什么；遵守文末图内标注纪律。
5. **验证设计**：验证动作与该域风险一一对应。
6. **写作重点**：该域摘要/正文侧重。

## 证据纪律（红线）

- 答不出"基线在哪失效"的动作不进 playbook。
- 不写配额语言（"至少 N 个动作/翻车点"）；条目数按证据定，动作数不足就少写。
- 不搬论文数值/原句；方法名与结构按提取报告转述。
- 本层证据全部为论文摘要级方法链提取（国赛无本地实验），所有条目 review_status 一律 source_checked：已核对提取来源，我方未复算论文算法；不出现 locally_tested 与 proposed 条目。
- 尚无机制复核与机制记录入库（`../cases/` 无 mechanism_reviews.json，与华为杯机制记录库相互独立）；后续若做机制复核再按该库格式补登记。

## 图内标注纪律（所有 playbook 图表节共用）

对齐优秀论文/期刊惯例，数据图（Type 3）**图内不放图名与说明文字，图名和结论写进 caption**：

- **保留**：轴标签（含单位）、刻度与刻度标签、图例、多面板标号 (a)(b)(c)、必要参考线与关键点标记（全文 ≤3 处，且每处在正文有对应论证句）。
- **不放**：图题（matplotlib 的 suptitle / 单面板 set_title）、结论句、大段说明文字、数据来源注、装饰性边框/背景色块。
- **示意图豁免**：技术路线图/流程图/框架图的标题条是版式组成部分，不受本条约束（走 figqa `--allow-box-labels` 通道；该参数只豁免示意图盒内文字，不关闭 figure_lint R8）。若示意图仍被 figure_lint R8 检出（如 matplotlib 直出示意图），用 `--allow-infigure-title` 逃生门。
- **panel 短标签**：多面板图各 panel 允许 ≤6 个中文字符当量的轴含义短标签（如 "ROC"、"残差"），超出部分移入 caption。
