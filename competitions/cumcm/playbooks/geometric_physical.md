# 几何/物理建模域 Playbook

证据锚点约定：**论文方法链提取** = `analysis/lit_survey/cumcm_paper_methods.md`（2021-2025 各年 A-E 题获奖论文 25 篇摘要级提取）。本域证据主体为其中 2021-A（FAST 主动反射面）、2022-A（波浪能装置）、2023-A（定日镜场）、2024-A（舞龙队）、2025-B（外延层厚度）五题——国赛 A 题谱系以"物理机理建模 + 智能优化求解"为主干；**我方实验** = 无（本文件不出现 locally_tested 条目）。全部条目为 source 层：已核对提取来源，我方未复算论文算法，不搬数值与原句。风险语言对齐 `../distilled_modeling.md`：本域对应"物理机理"与"几何与运动学"两类，推荐链（状态变量与坐标系 → 守恒/本构方程 → 参数辨识 → 数值求解 → 工况优化 / 统一坐标 → 几何约束 → 轨迹方程 → 事件检测 → 参数优化）与必做验证沿用该文件既有约定。

## 触发条件

- 题面给出物理对象与参数（反射面、浮子、透镜、螺线队列、薄膜），要求解释"量怎么变"或优化"结构/参数怎么调"；机理可由几何关系、守恒律或本构方程写出。
- 数据形态：题给参数表 + 需自行推导的解析关系（无现成数据集）；或物理量的时序/空间采样，服务于参数辨识与模型校验。
- 典型问链：先建几何/物理量计算模型（面积、功率、位置、厚度），再以此为评价函数进优化（结构参数、运动参数寻优）——机理模型是入场券，优化是终点。
- 事件结构常见：碰撞、遮挡、干涉、接触这类由几何条件触发的时刻/位置需精确定位。
- 与机器学习/数据分析域的分界：本题存在不可绕过的机理骨架，数据的角色是校验与辨识，不是替代物理；与仿真/路径规划域的分界：主问是机理量建模与参数优化，不是过程演化推演或网络流动。
- 命中本域后仍走缺口驱动选型主链，本清单只补充 stage 3 候选生成与 stage 5/8 呈现动作，不替代选型。

## 常见翻车点

本域我方无实验，以下来自论文方法链提取中获奖动作所超越的常规套路反面（含 `../distilled_modeling.md` 两类既有红线的落点）：

1. **坐标系与量纲不统一**：对象在不同子系统各用一套坐标（主索节点用球坐标、反射光线用直角坐标），变换关系不写出，几何量算错且错得沉默。
2. **理想化假设不核界**：小角度、刚体、双光束近似等条件直接沿用不检查——题给参数超出近似适用域（高反射率下双光束干涉失真）时系统性偏差，获奖论文以机理修正动作补界（2025-B）。
3. **数值格式与步长不收敛检查**：微分方程用低阶格式硬积、几何量用粗网格硬算，精度无证据；获奖论文显式做步长/样本量收敛验证（2022-A RK4、2021-A 蒙特卡洛）。
4. **评价量与题面准则口径不一**：自建评价函数（偏差度量、效率定义）与题面规定的准则定义有出入，优化结果对的是自家口径——优化越用力错得越远（2021-A RMS、2023-A 截断效率均以题面定义为准构造）。
5. **隐式量反演初值随意**：待求量（膜厚、极角、碰撞时刻）藏在方程里，迭代法初值不当发散或收敛到错根，无收敛判据与多初值检查（2025-B、2024-A 均为迭代反演结构）。
6. **事件判定靠图读不建模**：碰撞、进入遮蔽区这类事件时刻只在可视化里目测，无判别函数与求根过程，精度与可复现性双缺（2024-A 碰撞检测、2025-A 遮蔽判别为显式子模型）。
7. **解析与数值各说各话**：推导了闭式关系又另跑数值，两者不对账——解析式的符号错误与数值实现的逻辑错误互相掩盖，双轨失去交叉验证价值。
8. **优化器替代机理判定**：几何可行性（不碰撞、不遮挡）交给罚函数软约束在优化里硬扛，不在几何层判清楚——可行域结构不明时优化器大量时间消耗在不可行区（对齐 `../distilled_modeling.md` 几何类"优化算法只负责搜索，不代替几何判定"）。

## 惊艳动作清单

每条五要素：基线在哪失效 → 机制 → 前提/接口 → 反例 → 迁移边界；证据来源与 review_status 逐条标注。失效面为实现方基于方法链组合结构的归纳（提取记录仅含方法名与链序，无论文自述动机字段）；动作与结构按提取报告转述，我方未复算。

### A1 统一坐标系 + 变换矩阵显式化

- 基线失效：形变/位姿/传播问题中对象横跨多个参照系（球面主网、馈源舱、入射方向），不做统一变换则各子系统几何量没有公共度量，交角、投影、偏差都算不出或算错。
- 机制：全局只定义一个基准坐标系，所有对象的位姿/形变用旋转矩阵与平移向量显式描述，任意两点/两向量的几何关系都在同一系下计算；变换矩阵进正文，可逐项复查。
- 前提/接口：对象位姿参数（角度、节点坐标）题给或可递推；输出统一坐标下的几何量表，供评价函数与优化器直接引用。
- 反例：三维形变大幅偏离基准构型时线性化变换（小角近似）失效，需完整旋转矩阵；坐标变换链路长时误差累积，中间量的传递误差要估阶。
- 迁移边界：迁移"一个基准系 + 显式变换"的纪律；坐标系选择与变换形式按新题对象几何重定。
- 证据：论文方法链提取（2021-A）｜source_checked

### A2 评价量从题面准则构造为可计算目标

- 基线失效：题面给的是准则性表述（"调节后反射面与理想面偏差小""聚光效率高"），不落成可计算的数量函数就没有优化目标——"效果好"无法度量，调参与寻优无从下手。
- 机制：把题面准则逐字翻译成数量泛函（如逐点偏差的均方根、有效聚焦能量占比），定义域、聚合方式、参考基准全部显式；该函数同时服务评价与优化，两用同一实现。
- 前提/接口：准则的数学定义可从题面唯一确定（歧义处声明选择及理由）；输出为标量评价函数，接优化器目标位与结果表评价列。
- 反例：聚合方式选择不同（逐点 RMS 对峰值偏差、对平均偏差）会给出不同最优构型，口径不声明则结果不可比；评价函数实现与题面定义有出入时，优化收敛越好人偏越远。
- 迁移边界：迁移"准则先翻译成泛函、评价与优化同源"的结构；泛函形式按新题准则重推。
- 证据：论文方法链提取（2021-A RMS 评价、2023-A 截断效率）｜source_checked

### A3 蒙特卡洛算无闭式几何量

- 基线失效：不规则区域或比例量（曲面交集面积、镜场截断占比）无解析公式，网格离散化在曲边界处系统偏差且随分辨率改进代价陡增——精度与代价都不可控。
- 机制：把几何量改写为随机试验的期望（随机投点的落入比例 × 总度量），蒙特卡洛估计随样本量收敛且误差可量化；样本量收敛曲线单独验证后正式使用。
- 前提/接口：落入判定有明确的布尔判别函数（点在区域内/光线被截断）；估计量无偏（采样分布覆盖全域）；输出估计值与置信区间一并报告。
- 反例：判定函数有边界歧义（点恰在边界）时估计有偏；小概率事件（占比极小的区域）直接采样方差巨大，需重要性采样或分层采样；收敛慢时把它放进优化内环会拖垮求解——应做代理或离线预表。
- 迁移边界：迁移"无闭式量改期望估计 + 收敛证据先行"的结构；采样设计与方差控制按新题几何形态选择。
- 证据：论文方法链提取（2021-A 交集面积、2023-A 截断效率）｜source_checked

### A4 机理微分方程组建模 + 数值格式选择与步长收敛

- 基线失效：多体/振荡系统的动力学（浮子-振子耦合）写不出闭式解，低阶格式（显式欧拉类）在振荡主导的问题上能量漂移、相位失真——解"算出来了"但物理上不对。
- 机制：由守恒/牛顿定律写二阶常微分方程组，选与问题刚性匹配的数值格式（四阶龙格-库塔类），步长减半做收敛检查，稳定输出前不进优化环。
- 前提/接口：初值与参数题给完整；格式与步长的收敛证据（关键量随步长的变化表）先行；输出时序进能量/功率积分（A5）与优化评价（A2）。
- 反例：系统刚性显著时显式格式需极小步长，应换隐式格式而非硬减步长；只对单个量做收敛检查可能漏掉相位累积误差，关键物理量要多指标查。
- 迁移边界：迁移"机理方程 + 格式匹配 + 收敛先行"的顺序；方程组与格式按新题动力学结构选择。
- 证据：论文方法链提取（2022-A）｜source_checked

### A5 能量/功率的数值积分口径统一

- 基线失效：优化目标是时间平均功率或总功，瞬时量算出后没有解析积分，用离散求和口径不声明（左端点/梯形/步长）则不同模块的"总功"不可比，目标值随离散方式漂移。
- 机制：先定积分口径（梯形公式类）与积分窗（周期倍数），全部能量/功率统计用同一口径实现；口径与步长联动声明，进优化前固定。
- 前提/接口：积分窗覆盖整周期或足够长（瞬态衰减后）；口径写进实现并被评价函数与优化器共用。
- 反例：积分窗不是周期整数倍时平均值带系统偏差；瞬态段未剔除时目标值依赖初始条件，优化解被瞬态污染。
- 迁移边界：迁移"统计口径先定、全链共用"的纪律；积分方式与窗口按新题时间结构重定。
- 证据：论文方法链提取（2022-A）｜source_checked

### A6 隐式量反演的迭代法 + 收敛判据

- 基线失效：待求量（薄膜厚度、精确极角、事件时刻）以隐式关系定义（方程根、积分反解），网格查表精度受网格限制、插值又引入二次误差——要高精度时两条路都不够。
- 机制：把隐式关系整理成不动点/求根问题，用牛顿迭代或逐步逼近法求解，初值由粗网格/物理直觉给出，收敛判据与迭代次数显式报告；精度由判据控制而非网格。
- 前提/接口：函数在解附近性态良好（导数可算或单调性可证）；初值策略声明（粗解提供）；输出解与残差（代入原方程的偏差）一并给。
- 反例：多根问题迭代收敛到错根，须先做根的存在性与区间分析再选初值；导数接近零处牛顿法发散，退回区间收缩法更稳；残差不报则"收敛"无证据。
- 迁移边界：迁移"粗解定初值 + 迭代提精度 + 残差自证"的结构；迭代法与判据按新题隐式关系性态选择。
- 证据：论文方法链提取（2025-B 牛顿迭代反演、2024-A 逐步逼近极角）｜source_checked

### A7 理想模型的机理修正 + 独立机制交叉印证

- 基线失效：教科书模型（双光束干涉）在题给条件下（高反射率多次反射不可忽略）有系统性偏差，直接用则反演结果整体偏移——偏差源头可指认但模型不修正。
- 机制：先用理想模型走通全链路，再按其失效机理做定向修正（补入多光束干涉项），修正前后结果对照；并用另一条独立机理路径（不同物理原理的同类量计算）交叉印证修正后的值。
- 前提/接口：失效条件可由题给参数判别（反射率量级）；修正项有推导出处；交叉印证路径与主路径机理独立（不能共享同一近似假设）。
- 反例：修正与主模型共享同一错误假设时交叉印证双双失效；失效条件不成立时修正项是负资产（引入复杂度无精度增量），须先判界再修正。
- 迁移边界：迁移"理想模型走通 → 失效界判别 → 定向修正 → 独立交叉"的顺序；修正机理与印证路径按新题物理重推。
- 证据：论文方法链提取（2025-B）｜source_checked

### A8 事件检测独立建模

- 基线失效：碰撞、越界、进入遮蔽这类事件与轨迹计算混在一起，事件时刻只能从离散轨迹里目测或粗插值——精度无保证、复现困难，且优化中无法把事件当约束/目标。
- 机制：把事件条件写成显式判别函数（间距-时间关系、布尔遮蔽条件），事件时刻转化为判别函数的零点/切换点，用求根或二分定位到所需精度；判别函数可复用于优化的可行性检查。
- 前提/接口：事件条件有几何/物理闭式表达；判别函数对时间/参数连续或分段连续；输出事件时刻及其对参数的依赖关系表。
- 反例：轨迹离散步长内含多次事件切换（密接触往复）时零点定位漏检，需步长自适应；判别函数不连续处二分可能收敛到非事件点，须先做连续化或分段处理。
- 迁移边界：迁移"事件条件函数化、时刻求根定位"的结构；判别函数按新题几何/物理条件重写。
- 证据：论文方法链提取（2024-A 碰撞检测、2025-A 遮蔽布尔判别——后者属仿真路径域动作，此处引为同构证据）｜source_checked

### A9 解析闭式先行 + 数值互核

- 基线失效：几何量（弧长、交角、位置）既可解析推导也可数值计算，只交一路则符号推导错误（解析路）或实现逻辑错误（数值路）无从暴露；纯数值结果还失去参数依赖的结构洞察（优化需要的变化率无从谈起）。
- 机制：先推闭式或半闭式关系（螺线弧长、正弦定理关系），数值实现后与解析式在可算点对账，差异在数值精度内才放行；解析式同时提供优化所需的梯度结构或约束形式。
- 前提/接口：存在可解析的子问题（特例、局部、低维截面）；对账点选非退化情形；两路实现相互独立（不共享推导中间量）。
- 反例：全题无非解析成分时不需双轨，硬做是浪费；解析式在退化点（零交角、重合位置）失效，对账点要避开退化点并单独讨论退化情形。
- 迁移边界：迁移"能解析先解析、数值对账、解析供梯度"的结构；解析范围按新题几何可解性划定。
- 证据：论文方法链提取（2024-A 螺线方程+数值逼近、2022-A 微分方程推导+数值求解）｜source_checked

## 验证设计

验证动作与域风险一一对应：

| 域风险 | 对应验证 |
|---|---|
| 坐标/量纲错 | 量纲逐项检查表；变换矩阵正交性复算（A1） |
| 口径失真 | 评价函数定义与题面准则逐条对照表（A2） |
| 数值精度无据 | 步长/样本量收敛曲线，关键量多指标检查（A3/A4） |
| 假设超界 | 近似条件量级判别 + 修正前后对照（A7） |
| 反演错根/发散 | 根区间分析、多初值对照、残差报告（A6） |
| 事件漏检 | 判别函数连续性检查、步长自适应、事件复算（A8） |
| 解析/数值错位 | 双路对账点表，差异在精度内放行（A9） |
| 优化不可行区 | 几何可行性在判定层前置，优化解逐条件复算（对应翻车点 8） |

## 写作重点

- **推导可复查**：坐标变换、方程建立、闭式推导逐式进正文，每式标注依据（题面条件/物理定律/几何关系）——本域评审逐式查推导，跳步即失分。
- **口径声明前置**：评价泛函、积分口径、收敛判据的定义在结果出现前给出，读者拿着定义看后面所有数字。
- **物理量纲贯穿**：结果表达回物理语言（构型、效率、厚度），量与单位全程一致；摘要报关键物理量与最优参数，不报算法迭代细节。
- **双轨对账入表**：解析 vs 数值、修正前 vs 修正后的对照成表，差异与精度量级并排——这是本域"模型正确"的主要证据形态。
- **收敛证据进附录摘要化**：步长/样本量收敛表进附录，结论句引用其要点；机理假设的适用界写进局限（哪类工况下模型失效、失效后向哪个方向偏）。
- **可视化服务几何直觉**：构型对照、事件时刻、遮挡关系用图形交付（遵守图内标注纪律），几何结论一张图胜过一段文字。
