# CUMCM 图表证据链

图表按“提出证据、展示结果、验证可信度”组织，不按数量凑版面。每张图必须在正文解释一个结论。

| 任务 | 最小图表组合 | 必须回答的问题 |
|---|---|---|
| 物理机理 | 结构/坐标示意 + 状态曲线 + 误差或敏感性图 | 方程描述了什么，数值是否守恒，参数变化是否合理 |
| 几何运动 | 几何构型 + 轨迹/时空图 + 临界状态图 | 约束是否满足，何时触发碰撞/覆盖/遮蔽 |
| 优化调度 | 决策结构图 + 甘特/布局/策略图 + 基线对比 + 收敛图 | 解是否可行，比基线好多少，算法是否稳定 |
| 统计预测 | 分布/时序探索 + 预测与区间 + 残差 + 校准/误差分组 | 数据有什么规律，预测是否泛化，哪里会失败 |
| 评价排序 | 指标相关图 + 权重说明 + 排名/分级 + 稳定性图 | 指标是否重复，排名是否随权重小变而翻转 |
| 网络路径 | 拓扑图 + 状态传播图 + 路径对比 | 图如何构造，路径在全过程是否安全可行 |
| 信号处理 | 常规：原始与处理后信号 + 特征标注 + 拟合残差；引入修复机制时：基线失效图 + 机制部分有效图 + 闭环图（同一数据同一口径） | 处理是否保真（常规）；为什么非要该机制、缺口是否补上（机制引入时） |
| 图像识别 | 样本与标注 + 特征/关键点 + 混淆矩阵 + 错例 | 数据是否可信，模型混淆哪些类别，原因是什么 |
| 仿真模拟 | 机制流程 + 样本云/分布 + 收敛 + 情景比较 | 随机性如何设定，样本数是否足够，策略是否稳健 |

## 强制检查

- 坐标、单位、图例、样本量和统计口径齐全。
- 颜色不承担唯一编码；打印成灰度仍可区分。
- 预测图标明训练/验证边界，误差图保留零线。
- 优化图同时展示可行性和目标值，不只画算法收敛。
- 灵敏度图标明扰动范围和其他参数是否固定。
- 任何“提高、降低、稳定”都在图注或正文给出量化幅度。
