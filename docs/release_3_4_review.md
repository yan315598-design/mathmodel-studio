# v3.4.0 同步前审查

> 历史记录：本文件对应 v3.4.0 发布前审查，不作为当前 v3.4.1 版本说明。

本文件记录v3.4.0同步前的软件与指令审查范围；审查后已完成Codex、Claude Code与ZCode三个入口的本地同步。这里的历史检查记录不证明跨题模型发现效果。详细本地日志与改动指纹由维护工作区保留，不加入运行时默认上下文。

## 本轮范围

合并Stage 3重复步骤、按假设生成候选、合理训练预算、关键行为证据与子问范围；统一文献预算；信号域以物理错位生成条件候选。修正会覆盖新规则的活动调用者，包括评分、引用桥、案例入口、宿主交互与状态模板。未新增阶段、审批、数据库、强制消融矩阵或研究Agent。

## 已修复的实际问题

- 新循环与旧九步并列、主观评分示例可能替代实验；合并为三项可回退动作。
- 文献新profile被旧每阶段次数/篇数配额及Stage 3禁止检索覆盖；预算归literature_scout，引用桥只管真实性和格式。
- 主模型必须外源依据、候选至少三种、换源默认优先、无标签只能域适应、零类强制阻断等限制与开放研究不一致；改为证据及条件驱动。
- 完成度与表示/实现混淆；限定证据范围，保留未知和负结果，不用用户拍板替实验。
- 历史refine后新pass仍被门禁拦截；按最新追加评分判定，同时保留历史schema检查。
- 证据描述的斜杠被误判路径、列表与显式路径对象缺文件漏检；兼容描述与图编号，递归检查可识别产物路径，目录和空显式路径不充当文件证据。
- Windows默认GBK使图表列表特殊字符输出失败，分发检查显式传递UTF-8环境，README提供当前会话设置；不宣称默认GBK已全面兼容。
- 文献卡长度只作字符估算，历史Q档只是论文被引量档位，不冒充期刊分区；服务权限与额度以当前响应为准。
- 交互选项“暂不选”被写入正式选择；按真实选择分支，不跳过阶段或伪造用户理由。

## 兼容性与减重

保留state schema 3.2、评分键、六类checkpoint、experiments-1/2、CLI和图表接口。旧工作区无需整库迁移；重新过Stage 3移交时按证据补记研究字段，未知不升pass，已答checkpoint不重问。by_subproblem可选，notes也可表达范围。

SKILL主入口只更新版本；研究规则按需加载。Stage 3、引用桥与信号playbook合并重复文字；公式代码映射按任务需要复用验证记录，无控制方程不强制新表。图表、附件与输出链不作新增能力宣称。

## 验证与边界

完整离线回归：通过753，失败0；其后定向回归（含版本、文档链接、文献、门禁、主张路径及知识工作流）：通过66，失败0；UTF-8运行时分发检查：通过5，失败0。定向回归包含一次OpenAlex连通性检查，但不覆盖配额、认证变更、全部外部引擎或全文获取。其他Python版本、真实宿主重载、跨题新旧skill对照未运行。文献profile为Agent策略，不是自动计数或调参平台。

机器门禁核验字段、最新verdict和可识别路径，不理解所有自然语言主张，不强绑定所有选择与证据，也不证明科学有效。未随包提供的scibox能力与归档runtime仍不可当作当前可用功能；可选GIS/视频/3D等后端及绘图历史边界见 `docs/upgrade_acceptance.md`。本轮未修改渲染能力，不重做图像视觉验收。
