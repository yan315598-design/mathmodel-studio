# 华数杯全国大学生数学建模竞赛 LaTeX 模板 (精简版)

自写单文件模板, 干净室实现 (未参考第三方模板源码), 可随 skill 以 MIT 许可分发。

## 用法

```bash
xelatex main.tex   # 连编两遍
# 或走 skill 渲染链:
python scripts/render_paper.py --competition huashubei --workspace <paper_workspace>
```

## 结构

- 首页: 题目信息行 + 摘要 (无独立封面; 华数杯通行做法)
- 正文: 问题重述 / 分析 / 假设与符号 / 建模求解 / 灵敏度 / 评价
- 参考文献: GB/T 7714 顺序编码制手写示例
- 附录: listings 代码

## 注意

- 华数杯各届通知对封面字段、页边距、摘要字数等细节略有调整, 投稿前按当年通知核对修改
- 若当年要求独立封面/承诺书, 在摘要区前自行插入 `titlepage`
- 占位字段: `[论文标题]` `[题号]` `[参赛队号]` `[学校名称]` 等, 全文检索替换
