# 问题重述快速卡

> 0.7.4 新增：Stage 8 §1 问题重述的 30 分钟快速卡。写前扫一遍, 写后逐项核对。

---

## 结构（2 小节）

```
1. 问题背景
   3-5 句: 领域趋势 1 句 → 具体场景与数据资源 2-3 句 → 本文任务定位 1 句。

2. 问题描述（任务分解）
   按 Q1/Q2/Q3 逐问重述, 每问 2-3 句: 要做什么 + 约束/输入是什么 + 交付物是什么。
```

## 硬性要求

| 项 | 标准 |
|---|---|
| 字数 | 600-1200 字（1-2 页） |
| 抄题 | **禁止大段抄题**; 也禁止 1 句话糊弄（信息密度过低） |
| 任务重述句式 | 用"本文围绕……"“题目要求在给定……条件下……”等自己的语言 |
| 与问题分析的边界 | **重述不写方法**: 不出现模型名/算法名/求解策略, 那是 §2 的事 |
| 交付物明确 | 每问的输出形式（排序/方案/预测值/评价结论）写清 |

## 可套句式（每节最多用 1 次, 用后改写）

- 本文围绕【竞赛 X 题】提出的【核心问题】, 以【数据资源】为基础展开研究。
- 题目要求在给定【约束】条件下, 对【对象】进行【预测/优化/评价】, 并给出【交付物】。
- 在此基础上, 问题【N】进一步要求【增量任务】, 其关键在于【核心矛盾】。

## 写后自查（yes/no）

1. 两小节齐全, 字数在 600-1200?
2. 每问都重述到, 无遗漏?
3. 无整段照抄题面?
4. 全节无模型名/算法名（方法留给 §2）?
5. 阅读者不看原题也能明白每问要交什么?
6. 句式与 §2 问题分析无复制粘贴（两节边界干净）?
